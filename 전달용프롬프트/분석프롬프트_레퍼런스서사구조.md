# 분석 프롬프트 — 레퍼런스 작품의 서사 구조 분석

> **본 문서를 받은 Claude에게**:
> 본 문서는 *너에게 주어지는 작업 지시서*다. 사용자(노스)는 본 문서 + *분석 대상 작품 파일*을 함께 입력한다. 너는 본 문서의 §0~§5를 정독한 후, 입력된 작품을 §3의 4축 위계에 따라 분석하고, §4의 산출물 템플릿에 따라 마크다운 문서로 결과를 작성한다.

---

## §0. 작업 개요

### 0.1. 분석 목적

본 작업의 목적은 **노스포비아 프로젝트의 *대응 지침 설계 표준 (patterns/대응지침_설계.md)*을 보강하기 위한 *서사 패턴 발굴***이다.

대응 지침 설계 표준은 *현재 v1.0 상태*이며, *형식적 뼈대*(4막 구조·번호 체계·사이드 끼임·시점 모듈·검열 처리)는 다루지만 *서사 구조의 정점 자리*(반전·다층 매체·톤 균열 등)는 부분적으로만 다룬다. 본 분석은 *실제 한국 인기 작품의 서사 구조를 정밀 관찰*해 *대응 지침 설계 표준이 놓친 자리를 발견*하는 입력 자료를 생산한다.

### 0.2. 너의 역할

- **본 세션의 작업 단위**: 한 작품의 분석.
- **너는 *발견자*다**. *대응 지침 설계 표준을 수정·제안*하지 않는다. *원작품에서 발견되는 서사 패턴*만 *기술*한다. 표준과의 *연결·처방*은 *후속 통합 단계*에서 다루어진다.
- **너의 자유**: 본 문서의 §3 분석 차원에 *없는 패턴*이 발견되면 §4의 *자유 관찰란*에 기술한다. 템플릿 너머의 자리를 *포착하는 것이 권장*된다.

### 0.3. 입력·출력

| 항목 | 내용 |
|---|---|
| **입력** | 본 문서 + 분석 대상 작품의 텍스트 파일 (사용자가 별도로 첨부) |
| **출력** | 마크다운 분석 문서 1개. §4 템플릿 준수. 저장 경로는 §5 참조. |

## §1. 노스포비아 세계관 — 핵심 미학 요약

본 절은 *분석 시점의 미학적 기준점*이다. 너는 *원작품을 분석할 때 *노스포비아 미학을 강요하지 않는다*. 그러나 *원작품의 어느 자리가 *노스포비아 미학과 정합하거나 *대립*하는지*를 분석 중 의식해, *대응 지침 설계 표준 보강에 어떻게 활용될 수 있을지* 자유 관찰란에 기록한다.

### 1.1. 프로젝트 정체

**노스포비아**는 *방송 그 자체가 괴이 현상*이라는 컨셉의 ARG형 호러 버추얼 스트리밍 프로젝트의 *세계관 명칭*이다. (참고: *노스포비아 본체*는 사상체 `Aj-06-SP-0341`을 가리키며 세계관과는 다른 층위.) 시청자는 단순 관전자가 아닌 *Level IG(Investigator) 탐사자*로 호명된다.

### 1.2. 미학 3원칙

| 원칙 | 정의 |
|---|---|
| **표면/본질 이중 구조** | 모든 등장 요소가 *외부에 제시하는 얼굴*과 *실제 정체/동기*로 분리. 균열의 *암시 방식*이 연출의 정교함을 결정. |
| **모호함의 디폴트** | 명료한 답과 모호한 답 사이에서 *모호함*이 디폴트. 시스템은 명확하되 *내용*은 모호. |
| **APMB 정합** | 초상현상관리국(APMB)의 위험등급(Ks/Bh/Aj/Ni/Ka)·변칙성(MT/AK/FG/AH/EV/SP)·보안 인가 등급(CF/RS/SC/TS/KL)과 정합. |

### 1.3. 대응 지침 설계 표준의 *5대 원칙* (요약)

| 원칙 | 정의 |
|---|---|
| **서사 우선** | *항목 단위 작성*이 아닌 *서사 → 플롯 → 번호*의 순서. |
| **형식 위장** | 서사 구조를 가지되 *서사 구조 자체*가 외부에 노출되지 않게. 천 단위 구획·자릿수 패딩 등 *작가용 라벨*을 외부에 드러내지 않음. |
| **유동 분량** | 사상체마다 분량·톤·연출의 자유. 고정 항목 수·고정 번호 구획 강제 X. |
| **부분 검열 한정** | 대응 지침 본문에서 *전체 검열*(한 항목 전체가 [기밀 분류])은 *없음*. 부분 검열만 허용. |
| **추론 표적 분포** | 사상체 윤곽을 1층(표면, 60%) / 2층(항목 간 대조, 30%) / 3층(절대 비공개, 10%)으로 의식적 분포. |

### 1.4. 대응 지침의 *매체적 본질*

- 대응 지침은 *일반 소설과 다른 매체*. *시간축의 사건 진행*이 아닌 *번호 순서의 조건 분기 진행*.
- 독자는 *관찰자 + 잠재적 행위자*의 두 위치를 동시에 점유. 호명체(*~하십시오*)와 보고체(*~로 보고된다*)의 교차 사용이 이 두 위치를 동시 환기.
- *위반의 결과는 명시하지 않음*. 사례·양상·가능성으로 우회.

## §2. 분석 대상 장르의 정의

본 분석의 대상 장르는 **한국형 격리픽션·나폴리탄·규칙괴담의 합금**이다. 세 장르의 특징을 짧게:

| 장르 | 공포의 원천 | 형식의 역할 | 독자의 위치 |
|---|---|---|---|
| **격리픽션 (SCP계)** | 형식의 권위 | 임상적 어조와 분류 체계 | 분류에 *포섭되는 자* |
| **나폴리탄** | 형식의 부재 | 의미의 미결정 (모호함) | 의미를 *완성하는 자* |
| **규칙괴담** | 형식의 모순 | 규칙 간 충돌, 위반 시 결과 미명시 | 규칙을 *따르려고 시도하는 자* |

분석 대상 작품들은 이 셋의 *어느 비율로 합금*되어 있는지, *어느 자리에서 한 장르가 다른 장르로 전환*되는지가 *서사 구조 분석의 중요 자리*다.

## §3. 분석 차원 — 4축 위계

본 분석은 *11차원 균등 분석*이 아닌 **4축 위계**를 사용한다. 너의 *분석 시간·정밀도·분량 배분*은 이 위계에 따라 조정된다.

### 3.1. 주축 — *서사 구조* (분량 50%)

본 작업의 *핵심 표적*. 다음 세부 항목을 정밀 관찰:

#### (a) 막 구조

- 작품이 *몇 막*으로 구성되는가?
- 각 막의 *진입 조건*은 무엇인가? (= 작품이 *한 막에서 다음 막으로 어떻게 넘어가는가*)
- 각 막의 *분량·밀도*는 어떻게 차등되는가?
- 막 전환이 *번호 차수로 노출*되는가, *내용의 상황 전제 변화*로 위장되는가?

#### (b) 번호 진행

- 번호가 *연속*인가, *비연속(점프)*인가? 점프가 있다면 *어떤 자리*에서 발생하는가?
- 번호 형식이 *자릿수 패딩*(예: §001)을 가지는가, *자연 진행*(§1)인가?
- 분기 호출(*X일 경우 Y번으로*)이 *몇 회* 등장하는가?
- 분기 호출의 *조건절*이 *명료*한가, *모호*한가?

#### (c) 사이드 끼임

- 메인 진행 중 *짧은 부속 변형*(파생 번호형)이 있는가?
- *조건 분기로 끼어든 별도 단편*(플롯 점프형)이 있는가?
- 사이드의 *복귀*는 어떻게 이루어지는가? (사전 안내 / 사후 안내 / 부재)
- 사이드와 메인의 *연동 유형*은? (독립형 / 보강형 / 분기형)

#### (d) 매체 전환

- 작품이 *단일 매체*(예: 지침서)인가, *다층 매체*인가?
- 다층 매체라면, *어느 자리에서 어떤 매체로 전환*되는가?
- 매체 전환이 *작품의 정점 자리*에 위치하는가?

#### (e) 반전·정점 메커니즘

- 작품의 *정점 자리*는 어디인가?
- 정점이 *반전 구조*인가? (예: 독자가 따라온 지침이 *실제로는 다른 의도*임이 사후 폭로)
- 반전이 *작품 전반의 정보를 *재해석*하게 만드는가*?
- 반전 메커니즘이 *나폴리탄적*인가, *규칙괴담적*인가, *격리픽션적*인가, *합금*인가?

### 3.2. 보조축 1 — *시간 처리* (분량 15%)

- 작품 내부의 *시간 흐름*이 어떻게 처리되는가? (선형 / 비선형 / 정지 / 압축)
- *시제*가 어떻게 사용되는가? (현재형의 *상시 위협* / 과거형의 *기록 회상* / 미래형의 *예고*)
- *시간차 효과*가 존재하는가? (예: 사건 발생과 인지 사이의 지연)
- *작품의 시간*과 *독자의 읽기 시간*이 어떻게 관계 맺는가?

### 3.3. 보조축 2 — *규칙·금기의 작동 방식* (분량 15%)

- 규칙·금기가 *몇 개* 명시되는가?
- *위반 시 결과*가 *명시*되는가, *암시*되는가, *완전 부재*인가?
- 규칙 간 *모순*이 있는가? 모순의 *해소 자리*가 작품 내에 있는가?
- *작가의 권위*와 *규칙의 신뢰성*은 어떻게 관계 맺는가? (규칙이 정직한가 / 기만적인가 / 모호한가)

### 3.4. 보조축 3 — *화자·시점* (분량 15%)

- 작품의 *일차 화자*는 누구인가? 화자가 *명시*되는가, *익명*인가?
- *시점 전환*이 있는가? 있다면 *어느 자리에서 누구의 시점으로* 전환되는가?
- *호명되는 청자*는 누구인가? *호명의 어조*는?
- 화자가 *복수*인 경우, 그들 사이의 *관계*(상하·동등·적대)는?
- *호명체*(~하십시오)와 *보고체*(~로 보고된다)의 사용 비율은?

### 3.5. 주변축 — *자유 관찰* (분량 5%)

위 4축에 *명시되지 않은 자리*에서 발견되는 *주목할 패턴*. 다음 예시 자리들이 *주변축 후보*이나, 자유 관찰란은 *예시에 한정되지 않는다*:

- 포맷·매체 의장 (지침서·매뉴얼·채팅로그·녹취록 등)
- 위협의 형상 (구체적 신체 묘사 / 추상 / 부재)
- 인물 처리 (개인화 / 익명화 / 집단화)
- 정서적 거리·톤 변조
- 여백·모호함의 양 (검열·생략·암시의 비율)
- 문체·문법·리듬

## §4. 산출물 템플릿 (엄격 준수)

분석 결과는 *다음 템플릿을 그대로 사용*해 마크다운으로 작성한다. 절·소절·표 형식을 *수정하지 않는다*. *내용*만 채운다. 빈 자리가 있으면 *"해당 없음"* 또는 *"식별 불가"*로 명시.

```markdown
---
문서: 서사구조분석_<작품명>
버전: v1.0
분석 일자: <YYYY-MM-DD>

분석 대상: <작품 파일명>
```

## §7. 작업 시 *지켜야 할 자리*

- **인용 분량 제한**: 원문 인용은 *분석 논점당 1~2 문장 단위*. 전체 인용 합계가 원문의 *5% 이내*. 긴 인용이 필요한 자리는 *위치 참조 + 요약*으로 대체.
- **수정 제안 금지**: *대응 지침 설계 표준의 구체적 수정 제안*은 *§7의 시사 항목*에 *가능성 진술*에만 머문다. *어떻게 수정해야 한다*는 처방 작성 X.
- **노스포비아 미학의 강요 금지**: 원작품을 *노스포비아 미학으로 평가*하지 않는다. 원작품의 *자체 미학*을 *발견*하고, *노스포비아 미학과의 관계*는 *§7 시사*에서만 짧게 다룬다.
- **자유 관찰의 적극 활용**: 4축에 *없는 자리에서 발견되는 패턴*은 *분석의 진짜 자산*. §6 자유 관찰란을 *적극* 활용.
- **모호함의 보존**: 작품의 *모호한 자리*를 *해석으로 닫지 않는다*. *모호함이 무엇을 향하고 있는지*는 기술하되 *모호함의 답을 제시하지 않는다*.
