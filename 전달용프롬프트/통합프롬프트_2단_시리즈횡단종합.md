# 통합 프롬프트 — 2단 시리즈 횡단 종합

> **본 문서를 받은 Claude에게**:
> 본 문서는 *너에게 주어지는 작업 지시서*다. 사용자(노스)는 본 문서 + *서로 다른 시리즈의 1차 통합본 여러 개 + 단독 작품 분석*을 함께 입력한다. 너는 본 문서의 §0~§6을 정독한 후, 입력된 자료들을 횡단 종합해 §4의 산출물 템플릿에 따라 마크다운 문서로 결과를 작성한다.

---

## §0. 작업 개요

### 0.1. 작업의 위치

본 작업은 노스포비아 프로젝트의 *대응 지침 설계 표준 보강*을 위한 분석 파이프라인의 **2단계 — 시리즈 횡단 종합**에 해당한다. 전체 파이프라인:

```
[0단] 작품별 개별 분석 (완료)
[1단] 시리즈별 1차 통합 (완료)
[2단] 시리즈 횡단 종합 ← 본 작업
[3단] 대응 지침 설계 표준 v2.0 갱신
```

### 0.2. 작업의 본질 — *시리즈 횡단*

본 작업은 *시리즈 내부의 통합*이 아니라 *시리즈 사이의 종합*이다. 1단의 시리즈 통합본들은 *각자 자체 패턴 체계*를 가지지만, *시리즈 간 공통점*과 *시리즈 간 차이점*은 *2단에서만 보인다*. 너는:

- *서로 다른 시리즈*가 *공유하는 메타 패턴*을 발굴
- *시리즈 간 차이의 *체계적 구조*를 정리
- *대응 지침 설계 표준 보강*의 *최종 입력 자료*로서 *분류·정렬*된 패턴 체계를 산출
- *3단(표준 갱신)*에서 *바로 사용 가능*한 *분류 라벨*과 *우선순위*를 제안

### 0.3. 너의 역할

- **너는 *분류자·정렬자*다**. 1단의 *패턴 추출자* 위치에서 한 단계 더 추상. *시리즈별 패턴 카탈로그*를 *횡단 분류 체계*로 재구성하는 작업.
- **너의 자유**: 1·2단의 분석에 *없는 메타 패턴*이 *횡단 시점에 발견*되는 경우 §4의 *횡단 차원의 새 발견* 절에 기술. *시리즈 간 비교에서만 발견되는 자리*는 *권장된다*.
- **대응 지침 설계 표준의 *수정 제안 진입*: 1·2단과 달리 본 2단에서는 *구체적 수정 제안*이 *허용*된다**. 단 *시사 → 제안*으로의 격상 시 *근거의 명시*가 요구된다. *어느 시리즈의 어느 패턴이 어떻게 표준의 어느 자리를 어떻게 갱신할지*를 *3단 갱신 작업이 바로 사용 가능한 형식*으로.

### 0.4. 입력·출력

| 항목 | 내용 |
|---|---|
| **입력** | 본 문서 + 시리즈 1차 통합본 + 단독 작품 분석 (입력 자료 종류가 *균질하지 않음*) |
| **출력** | 마크다운 횡단 종합 문서 1개. §4 템플릿 준수. 저장 경로는 §6 참조. |

## §1. 입력 자료의 *비균질성 인지*

본 2단의 입력 자료는 *형식과 깊이가 다르다*:

| 자료 종류 | 형식 | 깊이 |
|---|---|---|
| **시리즈 1차 통합본** | 1단 산출물 템플릿 | 시리즈 차원 (작품 분석의 한 단 추상) |
| **단독 작품 분석** | 0단 작품 분석 템플릿 | 작품 차원 (시리즈 통합을 거치지 않음) |

너는 *이 비균질성을 의식*하고, *비교 시 부당한 가중치를 부여하지 않는다*:

- 시리즈 통합본의 *패턴*과 단독 작품의 *패턴*을 *동등한 무게*로 비교하지 말 것
- 단독 작품의 *결정적 자리*는 *시리즈 통합본의 결정적 자리*와 *동등하게* 다룰 수 있되, *시리즈 차원의 발견과는 별도 자리*로 분류
- 횡단 비교의 *결정적 패턴*은 *최소 2개 자료에서 출현*해야 함. *1개 자료에서만 보이면* 시사적 자리로 분류

## §2. 노스포비아 세계관과 대응 지침 설계 표준 (재게재)

- **추론 표적 분포** — 1층(60%) / 2층(30%) / 3층(10%)

## §3. 횡단 종합의 *5가지 작업*

### 3.1. *메타 패턴 발굴* (주 작업)

서로 다른 시리즈에서 *공유되는* 패턴을 식별. *시리즈 통합본의 §2 시리즈 공통 패턴*들을 *횡단 비교*해, *둘 이상의 시리즈에서 동시 출현*하는 자리를 *메타 패턴*으로 명명·정의.

메타 패턴 = *장르의 공통 자산*이 될 가능성이 가장 높은 자리.

### 3.2. *시리즈 간 차이의 체계화*

같은 자리에서 *시리즈마다 다른 처리*를 보이는 경우, *그 차이의 체계*를 추출:

- *축*: 어떤 차원에서 시리즈가 달라지는가
- *극*: 차이의 두 극단은 무엇인가
- *위치*: 각 시리즈가 그 축 위에서 어디에 위치하는가

예: *호명체 비율 축*에서 *수색연합 60%*과 *낙원 95%*가 두 극단이고, 새로운 시리즈는 그 사이 어디에 위치하는지.

### 3.3. *횡단 차원의 새 발견*

시리즈 단위로는 보이지 않고 *횡단 시점에 보이는* 자리:

- 한국형 장르가 *서양 SCP 컨벤션*과 *어떻게 차별*되는가의 *공통 패턴*
- *작품 간 인용·언급·상호 참조*의 자리 (시리즈 간 연결)
- *장르 진화*의 방향성 (어떤 자리가 발달하고 어떤 자리가 퇴조하는가)
- *노스포비아 미학과의 정합·대립의 패턴화*

### 3.4. *분류 체계 구축*

위 작업들의 결과를 *3단 갱신이 바로 사용 가능한 분류 체계*로 정렬:

- **카테고리 1: 표준에 *이미 있는 자리*의 *보강 자료*** — 기존 절의 *세부 강화*
- **카테고리 2: 표준에 *없는 자리*의 *신설 후보*** — 새 절·새 원칙·새 도구
- **카테고리 3: 표준의 *기존 원칙과 충돌*하거나 *예외*인 자리** — 5대 원칙의 *재검토 후보*
- **카테고리 4: 노스포비아 미학과 *대립*하는 자리** — 표준 갱신에서 *배제할 자리*

### 3.5. *우선순위 제안*

3단 갱신 작업이 *모든 자리를 한 번에 처리*할 수 없으므로, *우선순위*를 제안:

- **우선 1**: 갱신 시 *결정적 개선*이 예상되고 *작업 비용이 작은* 자리
- **우선 2**: 갱신 시 *큰 개선*이지만 *작업 비용이 큰* 자리
- **우선 3**: *부수 개선*. 후속 갱신으로 미룸 가능.

각 제안에 *우선순위 라벨* 부착.

## §5. 작업 시 *지켜야 할 자리*

- **인용 분량**: 1단 통합본·작품 분석의 *재인용*은 *제안당 1~2 문장*. 총 인용 분량이 입력 자료 합계의 *7% 이내*.
- **수정 제안 허용 (1·2단과 차이)**: 본 2단에서는 *구체적 수정 제안*이 *허용된다*. §6의 4 카테고리는 *제안의 격상* 자리. 단 *근거의 명시*가 필수.
- **표준 절 라벨의 *직접 인용*: §2.4의 표준 라벨을 *원문 그대로* 인용. *임의 변형 금지*. 3단 작업이 *기계적 매핑*을 가능하게.
- **노스포비아 미학의 *판정자 역할***: 1·2단과 달리, 본 2단은 *어떤 패턴이 노스포비아에 도입될지/배제될지*를 *명시적으로 판정*. §6.4 배제 자리가 그 자리.
- **우선순위의 *균형***: §6의 모든 제안에 우선순위 라벨 부착. *우선 1·2·3의 비율*이 *균형 잡혀야* (한쪽으로 몰리지 않음). 우선 1이 너무 많으면 *실제 갱신이 불가능*해짐.
- **과대 일반화 회피**: *2개 시리즈에서 출현*하는 패턴을 *장르 본질*로 단정하지 말 것. 입력 자료가 *3개 시리즈*에 한정되므로 *시사적 자리*는 그렇게 명명.
