## §4. 결정 위임 — *작업 진입 전 결정해야 할 2가지*

다음 세션의 너는 *작업 시작 전*에 사용자에게 다음 2가지를 *반드시 확인*하라.

### 4.1. 결정 자리 1 — doc-init-draft 스킬 갱신 여부

§2.3의 *시스템 갭*을 어떻게 처리할지.

**옵션 a) 스킬 갱신 후 /doc-init** (이전 세션 추천)
- 사전 조건에 `patterns/대응지침_설계.md` 추가
- 작업 단계 §3의 *대응 지침 작성 부분*을 v2.0 표준에 정합하게 갱신
- 비용: 1세션. 효과: 이후 모든 사상체 자동 적용.

**옵션 b) 스킬 미갱신, 명시적 입력**
- /doc-init 호출 시 v2.0 표준을 별도 입력으로 첨부
- 1037 재배치 때와 동일 흐름
- 비용 적음. 단 매번 수동.

**옵션 c) 사전 조건만 부분 갱신**
- 사전 조건 목록에 v2.0 참조 한 줄만 추가. 작업 단계 본문은 그대로
- 가장 가벼우나 효과 약함

### 4.2. 결정 자리 2 — 새 사상체 작업 단위

raw 폴더에 2개 파일 존재. 어느 단위로 작업할지.

**옵션 a) 터널 괴담을 단독 /doc-init**
- `/doc-init @docs/raw/터널_괴담_콘셉.md 랜덤`
- 새 사상체 1건 집중. v2.x 검증에 최적
- 콘셉1.md는 후속 작업으로

**옵션 b) 콘셉1을 단독 /doc-init**
- 터널 괴담이 더 최근에 작성/열림이므로 사용자 의도 확인 필요

**옵션 c) 두 파일 통합 /doc-init**
- 인자 없이 호출. 두 파일이 한 사상체로 통합 분석됨
- 두 파일이 *서로 다른 컨셉*이면 *부적합*

## §5. v2.0 표준의 *현장 검증 우선 자리* (새 사상체에서 검증할 것)

1037 재배치에서 *검증되지 못한 자리*들. 새 사상체 작업 시 가능하면 *이 자리들을 의식적으로 도입*해 검증하라.

### 5.1. 시점 모듈 §3001+ 도입 시의 §1 진입 호명 흐름
1037은 시점 모듈 미도입. 새 사상체에서 *차단 구역 인원·회수 처치 구역 인원 등의 시점 모듈*을 의식적으로 도입하면 §3001+/§5001+/§7001+ 차수 자리가 처음 검증됨.

### 5.2. 사이드 3유형 + 호출 어휘 4종의 실제 작동
1037은 사이드 미도입. 새 사상체에서 *분기형 + 플롯 점프형 사이드 1~2개*를 도입하면 호출 어휘 4종이 처음 검증됨.

### 5.3. 5막 변종 또는 다른 시간차 양태
1037은 (4) 시간 정지. 다른 양태(다일자 누적·단일 일자 분할·응축 비선형)의 사상체에서 검증.

### 5.4. 5종 음각 환기 도구함 중 미검증 3종
1037은 부분 검열 + 번호 결번 2종만. *메타 균열·자모 깨짐·수치 ???* 3종은 미검증. 매체체에 따라 도입 검토.

### 5.5. 시리즈 차원 자원
1037은 단일 사상체. *시리즈 횡단 정형구·옴니버스 결합 4유형·3층 시리즈 분산*은 미검증. 향후 시리즈 설계 자리.

## §9. *주의 자리* — 새 세션이 빠지기 쉬운 함정

### 9.1. v2.0의 *결정적 자리는 변경 금지*

다음은 v1.0에서 v2.0으로 *보존된 자리*. *새 사상체 작업 중에도 변경 금지*:

- 호출 어휘 4종 (조건 분기·메인 플롯 점프·사이드 복귀·시점 모듈 진입)
- 사이드 끼임 두 형식 (파생 번호형·플롯 점프형)
- 사이드 3가지 연동 유형 (독립형·보강형·분기형)
- 시점 모듈 홀수 차수 (§3001/§5001/§7001)
- 4막 구조 (1막 진입 이전 / 2막 조우 / 3막 사후 / 4막 비상)
- 호명체 어미 변형 가이드 (경어 명령형)
- 부분 검열 표기 + 전체 가림 금지
- 번호 체계 자릿수 패딩 없음 + 연속 진행

### 9.2. *5대 원칙 명칭 유지*

v2.0의 5대 원칙 명칭(서사 우선·형식 위장·유동 분량·부분 검열 한정·추론 표적 분포)은 *명칭 변경 금지*. 단 *정의 확장*은 허용 (v1.0 → v2.0에서 이미 일부 확장됨).

### 9.3. *§7.6 배제 자리 4항목 회피*

- 권위자 사적 관계의 본문 상세 노출 (서명체 한 줄까지만 허용)
- 적측의 권위 매체 전유 (디폴트 배제, 사이드 예외)
- 직설적 인터넷 어휘 (완곡 자조로 변환)
- 완전 주관 의존 분기 어휘 (부분 주관 의존은 허용)

### 9.4. *형식 위장 원칙*

대응 지침 본문에 *4막 라벨·천 단위 차수·"이제 비상 절차"* 같은 *서사 구조 자체의 노출* 금지. 막 전환은 *상황 전제로 위장*.

### 9.5. *답변 분할 권장*

직전 세션에서 *긴 답변이 반복 중단*되는 오류 발생. 다음 세션에서도 동일 위험. 권장:

- 긴 표·코드 블록을 *한 응답에 다 넣지 말 것*
- 복잡한 응답은 *짧은 단위로 분할*해 사용자에게 전달
- 문서 작성 시 *Edit 도구로 누적 작성*이 안전 (직전 세션에서 검증됨)

---

## §10. 직전 세션의 *답변 중단 자리* — 인계

직전 세션은 다음 자리에서 답변이 두 번 중단됨:

1. *doc 명령어 시스템 폴더 트리 출력 중*
2. *결정 자리 1·2의 옵션 표 작성 중*

두 자리 모두 *마크다운 표 + 코드 블록의 조합*에서 발생. 다음 세션은 *동일 자리에서 답변을 분할*해 진행.

본 §4의 결정 자리 2개를 *사용자에게 표 없이 짧은 옵션 목록으로* 전달하는 게 안전. 표가 필요하면 *별도 응답으로 분리*.

---

## §11. 사용자 자칭과 협업 모델

- 사용자는 자칭 *노스*. 친근한 톤이되 결정권은 사용자에게 위임.
- 결정은 사용자, 너는 옵션 제시 (2~4개). 한 응답에서 1~3개 결정 지점만 처리.
- 미정 영역을 너의 의견으로 메우지 말 것.
- 확정 영역은 손대지 않음. 노스포비아 본체 설정(`Aj-06-SP-0341`)·식별 코드 체계·표면/본질 이중 구조는 절대 손대지 않음.
- 작업 후 자기 점검 3가지: 표면/본질 이중 구조 유지 / 모호함 균형 / 사용자 결정 권한 침해 여부.

## §12. 본 문서의 처리

본 문서(`세션전달_v2x_새사상체작업.md`)는 *세션 전달 목적의 일회용 자료*. 다음 세션이 §8 절차를 시작하고 사용자 결정을 받은 후에는 *작업 진입의 입력으로 사용*되었으므로 *역할 종료*. 사용자가 직접 삭제하거나 `archive/`로 이동 가능.
