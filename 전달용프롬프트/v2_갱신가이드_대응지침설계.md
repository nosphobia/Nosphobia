# 대응지침_설계 v2.0 갱신 가이드

> **본 문서를 받은 Claude에게**:
> 본 문서는 *너에게 주어지는 갱신 작업 지시서*다. 사용자(노스)는 본 문서 + *횡단종합 보강자료* + *v1.0 현행본*을 함께 입력한다. 본 가이드 §0~§5를 정독한 후, §3의 갱신 작업 매핑표에 따라 v2.0을 신규 작성한다. v1.0의 *5대 원칙은 보존*하되 *재해석·확장 허용*, v1.0의 *절·소절은 갱신·신설 가능*.

## §0. 가이드의 위치

### 0.1. 작업의 위치

```
[0단] 작품별 개별 분석 — 완료 (10개 자료)
[1단] 시리즈별 1차 통합 — 완료 (2개 통합본)
[2단] 시리즈 횡단 종합 — 완료 (보강자료 1개, 30개 갱신 제안)
[3단] 대응지침_설계 v2.0 갱신 ← 본 가이드가 지시하는 작업
```

### 0.2. 본 가이드의 *작성자 위치*

본 가이드는 *v1.0의 공동 작성자 세션*에서 작성되었다. 따라서:

- *v1.0의 *설계 의도*가 어디에 있는지* 본 가이드 작성자는 인지
- *횡단종합 보강자료의 30개 제안* 중 *어느 것이 v1.0의 의도와 정합하고 어느 것이 충돌하는지* 본 가이드가 *사전 판정*해 너에게 위임
- 너(v2.0 작성 세션)는 *맥락 손실 없이* 본 가이드의 판정에 따라 작업

### 0.3. *v2.0의 변경 범위*

- **변경 범위**: *중폭* — 카테고리 1·2·3의 *우선 1·2 자리*까지 반영. 우선 3은 *v2.1 이후로 미룸*.
- **5대 원칙 보존 + 재해석 허용**: 5대 원칙의 *명칭*은 유지하되, *내용·범위·예외*는 갱신 가능.
- **갱신 방식**: *신규 작성*. v1.0의 텍스트를 그대로 복사하지 않고 *재구성*. 단 v1.0의 *결정적 자리*(분류 표·호출 어휘 4종 등)는 *내용 보존하며 위치 조정 가능*.
- **v1.0의 처리**: v2.0 완성 후 v1.0은 `patterns/archive/대응지침_설계_v1.0.md`로 이동.

### 0.4. 너의 역할

- **너는 *갱신 작성자*다**. 보강자료의 *발견자*나 *분류자* 위치가 아닌 *최종 통합 작성자*. 본 가이드의 *판정*에 따라 *v2.0 본문을 직접 작성*.
- **너의 자유**: 본 가이드가 *판정하지 않은 미세 자리*는 너의 판단에 위임. 단 *5대 원칙*과 *v1.0의 결정적 자리*는 보존.
- **너의 한계**: 본 가이드의 *우선순위 결정·배제 결정·재해석 방향*은 *변경하지 말 것*. 변경이 필요하면 *작업 시작 전 사용자에게 확인*.

## §1. v1.0 → v2.0의 *주요 변경 방향*

v2.0의 *결정적 변경 방향*을 한 곳에 정리. 너는 작업 시 이 방향을 *상시 인지*.

### 1.1. *5대 원칙의 *유지·재해석·확장**

v1.0의 5대 원칙은 *명칭 유지*. 단 *내용 재해석*:

| 원칙 | v1.0 위치 | v2.0 변경 방향 |
|---|---|---|
| **서사 우선** | 보존 | 변경 없음 |
| **형식 위장** | 보존 | *시리즈 차원의 형식 위장*(매체 다층화의 3종 양태) 추가 |
| **유동 분량** | 보존 | *유동 매체* 차원으로 확장 (매체 다양화도 사상체별 자유) |
| **부분 검열 한정** | 보존 | *5종 음각 환기 도구함*으로 확장 (번호 결번 등 추가) |
| **추론 표적 분포** | 보존 | *공간 분포 + 시간 분포 동시 적용* 명시 |

5대 원칙의 *명칭 자체*는 변경 X. *재해석*은 각 원칙의 정의 문단을 *확장*하는 방식.

### 1.2. *새 차원의 도입 — 시간축 처리*

v1.0이 *부재시킨 차원*. v2.0에 신설:

- **§2.5 신설 — 시간축 처리** (보강자료 제안 2.1)
- 작품 내부 시간 + 문서 외부 시간의 이중 시간축
- 4종 시간차 양태: 다일자 누적 / 단일 일자 분할 / 응축 + 비선형 / 시간 정지

### 1.3. *세 장르 비율의 *한국형 변종 명시**

v1.0 §1.4의 *임상적 어조*가 *임상 + 일상 톤 동거*로 한국형 변종 명시 (보강자료 제안 1.1).

### 1.4. *호명체/보고체 2축 → 3축 확장*

v1.0 §1.4·§5.4의 *2축*이 *3축(+ 비격식체)*으로 확장. 호명체 비율 95~70% 디폴트 + 30% 이하 예외 명시 (보강자료 제안 1.2 + 3.1).

### 1.5. *검열 5종 도구함 신설*

v1.0 §5.6의 *부분 검열 한정*이 *5종 음각 환기 도구함*으로 확장:

1. 부분 검열 (기존)
2. 번호 결번 (신규)
3. 메타 균열 (신규)
4. 인물/정보 부재형 군림 (신규)
5. 자모 깨짐·송신 실패 (신규)
6. 수치 ??? 표기 (신규)

(보강자료 제안 1.3 + 2.2 + 3.2)

### 1.6. *시점 위치 3종 분류 신설*

v1.0 §4.4 시점 모듈의 *위치 분류* 신설:

1. 외부 매체의 호명 청자 (귀하) — 디폴트
2. 조직체 1인칭 복수의 일원 (본 연합)
3. 1인칭 회상자 (나는 ~했다)

(보강자료 제안 2.3)

### 1.7. *옴니버스 결합 4유형 분류 신설*

v1.0의 *사이드 3유형(독립형·보강형·분기형)*은 *항목 차원*. v2.0에 *시리즈 차원의 옴니버스 결합 4유형*을 신설:

- 독립형 / 누적형 / 반향형 / 층위형

이 4유형은 *항목 차원의 사이드 3유형과 별도 분류*. *2단 분류 체계* 명시. (보강자료 제안 2.4)

### 1.8. *공간 = 의례 위계 분류 도입*

v1.0 §3.3 1막 진입 이전에 *공간 분류* 추가. 한국형 7종 의례 공간 카탈로그를 *권장 자원*으로 명시 (보강자료 제안 2.5). 단 *비위계 공간*도 가능함을 명시 (배제하지 않음).

### 1.9. *위반 결과 4종 우회 양태 명시*

v1.0 §2.4의 *위반 결과 미명시*가 *4종 우회 양태*로 확장:

1. 반복 정형구 (시리즈 횡단 환유 카운터)
2. 변주형 완곡어법
3. 사례 누적형
4. 결과 완전 부재형

(보강자료 제안 1.4 + 3.3)

### 1.10. *배제 자리의 *명시적 차단**

보강자료 §6.4의 *배제 자리 4개*를 v2.0 §7 안티 패턴에 *명시적 항목*으로 추가:

- 권위자 사적 관계의 본문 상세 노출 (배제)
- 적측의 권위 매체 전유 (디폴트 배제, 예외 허용)
- 직설적 인터넷 어휘 (배제, 완곡 자조로 변환)
- 완전 주관 의존 분기 어휘 (배제)

(보강자료 §6.4)

## §3. 갱신 작업 매핑표 — *보강자료 제안 ↔ v2.0 변경*

## §4. 작성 시 *지켜야 할 자리*

### 4.1. *5대 원칙의 *재해석 범위**

5대 원칙 각각의 *정의 문단*은 다음 자리만 *확장*:

- **서사 우선**: 변경 없음
- **형식 위장**: *시리즈 차원의 형식 위장*(매체 다층화 3종 양태) 1 문단 추가
- **유동 분량**: *유동 매체* 차원 1 문단 추가. 사상체별 *매체 다양화 자유* 명시.
- **부분 검열 한정**: *5종 음각 환기 도구함*으로 확장. *부분 검열은 그 중 1종*임을 명시.
- **추론 표적 분포**: *공간 분포 + 시간 분포 + 시리즈/옴니버스 분산*의 *3차원 분포* 명시.

5대 원칙의 *비율*(60/30/10)·*비율의 권장 범위*는 v1.0 그대로 유지.

### 4.2. *v1.0의 결정적 자리 — 보존 필수*

다음은 v1.0의 *결정적 자리*. v2.0에서 *내용 변경 금지*:

- 호출 어휘 4종 (§5.2): 조건 분기·메인 플롯 점프·사이드 복귀·시점 모듈 진입
- 사이드 끼임 두 형식 (§4.3): 파생 번호형 + 플롯 점프형
- 사이드 3가지 연동 유형 (§4.3): 독립형·보강형·분기형
- 시점 모듈 홀수 차수 (§5.1): §3001/§5001/§7001
- 4막 구조 (§4.1): 1막 진입 이전 / 2막 조우 / 3막 사후 / 4막 비상
- 호명체 어미 변형 가이드 (§5.4): 경어 명령형
- 부분 검열 표기 (§5.6): `█`, `[데이터 말소]`, `[기록 보류]`

### 4.3. *신설 절의 *내용 작성 방침**

신설 절을 작성할 때:

- **분량**: 1~3 문단 + 표 1개 (필요 시) + 짧은 예시 1개 (필요 시). 과도한 분량 회피.
- **인용 출처**: 보강자료의 §·작품명을 *작성 시점에 직접 인용*. 예: *"(보강자료 §2.6 + 〈해피 에브리데이 마트〉 §2.2)"*.
- **자기 충족성**: 신설 절이 *원작품을 모르는 독자*도 이해 가능해야 함. 원작품 인용은 *짧은 1~2 문장*에 한정.
- **노스포비아 응용 명시**: 각 신설 절 끝에 *노스포비아 미학과의 정합 + 응용 방향* 1~2 문장.

### 4.4. *v1.0 → v2.0의 *변경 흔적 명시**

v2.0 §0.5 *변경사항* 절에 *v1.0 대비 변경 자리*를 표로 정리. 독자가 *어디가 새 자리인지* 즉시 식별 가능하게.

### 4.5. *3시리즈 사례 인용의 *균형**

### 4.6. *과대 일반화 회피*

## §7. 가이드의 한계 — 정직한 자기 공개

본 가이드의 한계:

- **가이드 작성자의 *v1.0 편향***: 본 가이드는 *v1.0 공동 작성자* 위치에서 작성됨. 따라서 *v1.0의 결정적 자리 보존* 권고에 *비대칭적 가중치*가 있을 가능성. v2.0 작성 세션이 *명백한 개선 자리*에서 *v1.0 보존을 우회*할 수 있음 — 단 *5대 원칙과 §4.2의 결정적 자리*는 보존 권고가 강함.

- ***보강자료 §8의 한계*가 그대로 전이**: 보강자료가 *3시리즈 표본*에 의존했고 *과대 일반화 위험*이 있는 자리는 v2.0에서도 *시사적 명명*으로 유지. 단 *3시리즈 표본 자체가 부족*한 자리(예: 공간 카탈로그·옴니버스 공식)에 대해서는 *v2.0이 *시사적 명명을 명시*하되 *결정적 단정 회피*.

- ***우선 3 보류*가 *v2.0의 한 자리를 약화*시킬 가능성**: 우선 3 제안(예: 매체 다층화 3종 양태)을 v2.0에서 보류하면 *제안 2.7의 신설 절이 부재*해 *형식 위장의 시리즈 차원 도구함*이 약화될 가능성. v2.1에서 보강 필요.

- ***v2.0 작성 시점에 *원작품 직접 확인*이 부재**: 보강자료가 *2단계 추상*에 머무는 자리는 v2.0에서도 *원작품 직접 확인 부재* 상태로 작성됨. 특히 *예시 신설*(§10.11~§10.15) 자리에서 *원작품 직접 인용*이 필요한 경우 *짧은 인용*에 한정.
