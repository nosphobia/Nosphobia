# 통합 프롬프트 — 1단 시리즈 통합

> **본 문서를 받은 Claude에게**:
> 본 문서는 *너에게 주어지는 작업 지시서*다. 사용자(노스)는 본 문서 + *동일 시리즈에 속한 여러 작품 분석 자료*를 함께 입력한다. 너는 본 문서의 §0~§6을 정독한 후, 입력된 분석 자료들을 통합 분석해 §4의 산출물 템플릿에 따라 마크다운 문서로 결과를 작성한다.

---

## §0. 작업 개요

### 0.1. 작업의 위치

본 작업은 노스포비아 프로젝트의 *대응 지침 설계 표준 보강*을 위한 분석 파이프라인의 **1단계 — 시리즈별 1차 통합**에 해당한다. 전체 파이프라인:

```
[0단] 작품별 개별 분석 (완료)
[1단] 시리즈별 1차 통합 ← 본 작업
[2단] 시리즈 횡단 종합
[3단] 대응 지침 설계 표준 v2.0 갱신
```

### 0.2. 작업의 본질 — *분석의 분석*

본 작업은 *원작품 분석*과 본질이 다르다. 입력은 *원작품*이 아니라 *원작품 분석 자료 여러 개*다. 너는:

- 분석 자료들이 *공통으로 발견한 패턴*을 *시리즈 패턴*으로 명명·정의
- 분석 자료들이 *서로 다르게 발견한 자리*를 *시리즈 내부 변주*로 정리
- 시리즈 *전체*에서만 보이는 *시리즈 차원의 새 패턴*을 발굴
- *대응 지침 설계 표준 보강 시사*를 *시리즈 차원에서 통합·신설*

### 0.3. 너의 역할

- **너는 *패턴 추출자*다**. 작품 분석 단계의 *발견자* 위치보다 한 단계 추상. *작품에서 발견된 자리들을 *시리즈 차원의 도구함*으로 만드는* 작업.
- **너의 자유**: 분석 자료에 *없는 패턴*이 *통합 시점에 발견*되는 경우 §4의 *시리즈 차원 새 발견* 절에 기술. 작품 단위로는 보이지 않던 자리가 *통합 시점에 보이는 것*은 *권장된다*.
- **수정 제안 금지**: 작품 분석 단계와 동일. 대응 지침 설계 표준의 *구체적 수정 제안*은 하지 않는다. *시사*는 *가능성 진술*에 머문다.

### 0.4. 입력·출력

| 항목 | 내용 |
|---|---|
| **입력** | 본 문서 + 동일 시리즈에 속한 작품 분석 자료 여러 개 (3~5개 추정) |
| **출력** | 마크다운 통합 분석 문서 1개. §4 템플릿 준수. 저장 경로는 §6 참조. |

## §1. 노스포비아 세계관 — 핵심 미학 요약 (재게재)

본 절은 작품 분석 프롬프트 §1과 동일. 통합 분석 시점에 *기준점*으로 재확인.

### 1.1. 프로젝트 정체

**노스포비아**는 *방송 그 자체가 괴이 현상*이라는 컨셉의 ARG형 호러 버추얼 스트리밍 프로젝트의 *세계관 명칭*이다. *노스포비아 본체*(사상체 `Aj-06-SP-0341`)와는 다른 층위.

### 1.2. 미학 3원칙

| 원칙 | 정의 |
|---|---|
| **표면/본질 이중 구조** | 모든 등장 요소가 *외부에 제시하는 얼굴*과 *실제 정체/동기*로 분리. |
| **모호함의 디폴트** | 명료한 답과 모호한 답 사이에서 *모호함*이 디폴트. |
| **APMB 정합** | 위험등급(Ks/Bh/Aj/Ni/Ka)·변칙성(MT/AK/FG/AH/EV/SP)·보안 인가 등급(CF/RS/SC/TS/KL)과 정합. |

### 1.3. 대응 지침 설계 표준의 *5대 원칙* (요약)

- **서사 우선** — 서사 → 플롯 → 번호의 순서
- **형식 위장** — 서사 구조가 외부 노출되지 않게
- **유동 분량** — 사상체별 분량·톤·연출의 자유
- **부분 검열 한정** — 전체 검열(=[기밀 분류]) 사용 X
- **추론 표적 분포** — 1층(60%) / 2층(30%) / 3층(10%)

## §2. 입력 자료 — *작품 분석 자료의 구조*

입력되는 각 작품 분석 자료는 다음 구조를 따른다 (작품 분석 프롬프트의 산출물 형식):

```
§0. 작품 메타
§1. 한 줄 요약
§2. 주축 분석 — 서사 구조 (2.1 막 / 2.2 번호 / 2.3 사이드 / 2.4 매체 / 2.5 반전 / 2.6 결정적 자리)
§3. 보조축 1 — 시간 처리
§4. 보조축 2 — 규칙·금기의 작동 방식
§5. 보조축 3 — 화자·시점
§6. 자유 관찰란
§7. 대응 지침 설계 표준 보강 시사점
§8. 인용 출처
```

너는 *위 8개 절의 정보를 모두 활용*해 시리즈 통합을 수행한다. 단 *원작품 자체는 입력되지 않는다*. 작품의 *실제 본문이 필요한 자리*는 분석 자료의 §8 인용에 의존.

## §3. 통합 분석의 *4가지 작업*

본 통합 분석은 다음 4가지 작업을 *균형 있게* 수행한다.

### 3.1. *공통 패턴 추출* (주 작업)

여러 분석 자료에서 *반복 발견되는* 패턴을 식별하고, 다음 형식으로 정의:

- **패턴명** — 시리즈 차원에서 이 패턴을 가리킬 *명명*
- **정의** — 패턴의 본질
- **출현 작품** — 어느 작품들에서 어떻게 출현했는가 (분석 자료 § 인용)
- **변주의 범위** — 작품마다 어떻게 다르게 나타났는가
- **기능** — 이 패턴이 *작품에서 어떤 효과*를 내는가

### 3.2. *시리즈 차원의 새 발견*

작품 단위에서는 *보이지 않고* 시리즈를 *통째로 볼 때 비로소 보이는* 자리:

- *시리즈 진화* — 회차가 거듭되며 *변화한 자리*
- *인물 누적* — 작품 간 *공유 인물*의 누적 효과
- *세계관 두께* — 작품들이 *합쳐져 형성되는* 세계관의 윤곽
- *옴니버스 결합* — 작품 간 *결합 방식*(독립형/누적형/반향형/층위형 중 어느 것?)

### 3.3. *시리즈 내부 변주*

같은 시리즈 안에서도 작품마다 *다른 자리*. 이 *변주의 폭*이 *시리즈의 표현 가능 범위*를 정의:

- 작품마다 다른 *장르 비율*
- 작품마다 다른 *분량 차등*
- 작품마다 다른 *시점 구조*
- 작품마다 다른 *반전 메커니즘*

### 3.4. *대응 지침 설계 표준 보강 시사 — 통합과 신설*

작품 분석 자료의 §7 시사들을:

- **통합**: 여러 작품의 *동일·유사 시사*를 *한 개의 시리즈 차원 시사*로 압축
- **신설**: 시리즈 통합 시점에 *새로 발견되는* 시사 추가

## §5. 시리즈 진화·인물 누적·세계관 두께 (보조)

### 5.1. 시리즈 진화

회차가 거듭되며 *변화한 자리*. 작품의 *발표 순서가 명확한 경우*에만 작성. 불명이면 "식별 불가" 명시.

### 5.2. 인물 누적

시리즈 내 *공유 인물*의 누적 효과. 한 작품에서 등장한 인물이 다른 작품에서 *어떻게 다시 다뤄지는가*.

### 5.3. 세계관 두께

작품들이 합쳐져 형성되는 *세계관의 윤곽*. 시리즈 외부에서 가져온 *세계관 설정*은 별로 없으나, *작품들 사이의 빈자리*에서 *세계관이 함의*되는 자리.

### 5.4. 옴니버스 결합 유형

본 시리즈가 *옴니버스로서 어떤 결합 유형*에 가까운가? 다음 4유형 중 *주력 + 보조* 형식으로:

- 독립형 (단편들이 완전 독립)
- 누적형 (시간순·심도순으로 누적, 뒤로 갈수록 전제 정보가 늘어남)
- 반향형 (단편들이 서로를 암묵 참조, 함께 읽어야 의미 발생)
- 층위형 (서로 다른 시점·매체·등급이 층위로 묶임)

## §5. 작업 시 *지켜야 할 자리*

- **인용 분량 제한**: 분석 자료에서의 인용은 *패턴당 1~2 짧은 인용*. 분석 자료의 §8 인용을 *재인용*할 때 *원작품 위치 표기를 유지*. 통합본의 인용 총 분량이 분석 자료 합계의 *10% 이내*.
- **수정 제안 금지**: 작품 분석 단계와 동일. 시사는 *가능성 진술*에만.
- **노스포비아 미학의 강요 금지**: 시리즈의 *자체 미학*을 발견하는 것이 우선. 노스포비아 미학과의 정합은 *§6 시사*에서만 짧게 다룸.
- **과대 일반화 회피**: *3~4개 작품에서만 보이는 패턴*을 *시리즈 본질*로 단정하지 말 것. 출현 작품 수가 *시리즈 작품의 절반 이하*인 경우 *시사적 패턴*으로 명명.
- **각 작품의 *결정적 자리* 보존**: 분석 자료의 §2.6 *결정적 자리*들이 *통합 시점에 묻혀버리지 않도록*. 결정적 자리는 *시리즈 패턴의 발현 사례*로 *재참조*.
