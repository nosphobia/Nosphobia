# 시리즈 횡단 종합 — 대응 지침 설계 표준 보강 자료

## §0. 종합 메타

- **입력 자료 종류**:
  - 시리즈 통합본:
    - 〈괴이현상 실종자수색연합〉(이하 *수색연합*) — 4작품(낙원/크루즈레인/해피마트/소래성당)의 1단 통합
    - 〈초자연현상처리반〉(이하 *처리반*) — 5작품(귀하/암흑색맹/탈출작전 1·2·3)의 1단 통합
  - 단독 작품 분석:
    - 〈호텔 비다 시리즈〉(이하 *호텔비다*) — 김재이 작가의 5파일 단일 시리즈. 시리즈 단위이나 *1단 통합본을 거치지 않은 작품 차원 분석*
- **종합 대상의 총 분량**: 약 95,800자 (수색연합 24,700 + 처리반 50,114 + 호텔비다 21,000)
- **종합 대상의 *비균질성 인지*에 따른 가중치 조정 방식**:
  - 시리즈 통합본 2개는 *시리즈 차원의 추상*을 거친 자리이므로 *시리즈 간 비교의 기둥*으로 사용
  - 호텔비다는 *작품 차원 분석*이므로 *시리즈 통합본의 패턴과 동등한 무게로 비교하지 않음*. 단 작품 자체가 *5파일 시리즈*이고 *명시적 비교 시점*을 분석 내부에 가지므로(*〈해피 마트〉·〈낙원〉과의 호명체 비율 곡선*), *제3시리즈로서의 한 표본*으로 *조심스럽게* 횡단 비교에 진입
  - *최소 2개 자료 출현* 패턴만 메타 패턴으로 격상. *1개 자료에서만 보이면* §7 자유 관찰로 분류
- **본 종합본의 *3단 갱신 작업 대상*인 표준 버전**: `patterns/대응지침_설계.md` v1.0

## §1. 종합의 한 줄 정체

본 종합본은 *3시리즈(수색연합·처리반·호텔비다)의 횡단 비교*에서 *한국형 행정 문체 호러 옴니버스의 *시리즈 차원 메타 패턴 11개*와 *시리즈 간 차이의 5축*을 발굴해 *대응 지침 설계 표준 v1.0의 §1~§11에 대한 30개 구체적 갱신 제안*을 산출하는 *3단 갱신 작업의 직접 입력 자료*다.

## §2. 메타 패턴 — *서로 다른 시리즈가 공유하는 패턴* (주 작업)

3시리즈 모두 또는 시리즈 통합본 2개에서 공통 출현하는 패턴들. 메타 패턴당 1개 소절. *호텔비다는 단독 작품 분석이므로 *가중치를 낮춰* 인용*하되, *시리즈 통합본 2개에서 출현한 패턴*이 호텔비다에서도 *변종으로 확인*되는 경우 *시리즈 횡단 안정성*의 근거로 사용.

### 2.1. *행정적 완곡구의 의례화* — 위반 결과의 정형구 후렴

- **정의**: 위반 시 결과(=주로 사망·신체 변형)를 *직설 어휘로 표현하지 않고*, *행정·기관의 사후처리 진술* 또는 *완곡 정형구*로 우회·환유. 정형구가 작품 내 *반복 후렴*으로 작동하며, 시리즈에 따라 *동일 표현 반복형*과 *완곡어법 차등 변주형*의 두 변종이 존재.
- **출현 시리즈**:
  - *수색연합* §2.1: *"귀하의 가족에게는 장례비 및 상당액의 위로금이 지급됩니다"*가 〈크루즈/마트/성당〉 3작품에서 *완전히 동일한 표현*으로 *시리즈 합산 20회 이상 반복*. 시리즈 차원의 *환유 카운터*.
  - *처리반* §2.4: 위반 결과의 *명시 부재 + 사이드/지문/사후 회수로 우회 시연*. 〈탈출작전 1〉의 *사망 확인. 이쪽은 실패했습니다*(part 1-2 사이드), 〈암흑색맹〉의 *최초의 암흑색맹과 네 마디 이상 대화하지 말랬는데*의 결과 회피, 〈탈출작전 3〉의 *결번 비기재로 봉인*. 〈귀하〉의 *위반 결과 거의 전면 부재*까지 — *우회 매체가 시리즈 내부에서 작품마다 다르게 다양화*.
  - *호텔비다* §4: *직원의 일신에 해가 되는 요청일 경우 반드시 거절하세요*(공통 7번) + *해당 직원은 팔의 부상으로 퇴사하였음*. *사망 어휘 부재 + 직원 사례 누적의 정형 표현 + 부당 요청 목록의 환유*가 *수색연합 정형구와 동일한 자리에서 작동*. 〈호텔비다〉가 단독 작품임에도 *시리즈 통합본 2개의 메타 패턴을 그대로 확인*시킴.
- **변주의 범위**:
  - *동일 정형구 반복형* (수색연합 3작품): *시리즈 횡단으로 환유 카운터*가 누적
  - *완곡어법 차등 변주형* (수색연합 〈낙원〉): *그다지 유쾌하지 않은 / 좋지 않은 / 지극히 어려운*의 *분포형*
  - *사례 누적형* (호텔비다 + 처리반 〈탈출작전 1·2〉): *동료의 사후 처리 사례*가 *현재 위협의 환유*
  - *결과 완전 부재형* (처리반 〈탈출작전 3〉·〈귀하〉): *결번 비기재 + 미명시*가 *완전 우회*
- **장르 차원의 의미**: *한국형 행정 문체 호러*의 *가장 강력한 공통 자산*. 3시리즈 모두에서 출현하므로 *과대 일반화 위험 낮음*. 단 *형태*는 시리즈마다 4종으로 분기됨.
- **노스포비아 미학과의 관계**: *모호함의 디폴트* 원칙과 정합. *부분 검열 한정* 원칙의 *환유적 변종*. *완벽 정합*.

### 2.2. *집단 단수 화자* — 조직체의 1인칭 복수 자칭

- **정의**: 일차 화자가 *개인이 아닌 조직체*(*본 연합 / 당사 / 본국 / 호텔 비다*)로 일관 호명되는 화자 구조. 익명이되 *조직 명칭으로 식별되는 익명*. 작품 내 작성자는 *조직 일반*으로 좁혀지지 않거나, 좁혀지더라도 *대표자의 서명*을 통해 *조직 권위의 대표자*로만 노출.
- **출현 시리즈**:
  - *수색연합* §2.2: *본 연합 / 저희*의 1인칭 복수 자칭 일관. 〈낙원〉이 *조직체 단일 권위 95% 우세*, 〈해피 마트〉가 *조직체 60% / 보고체 30% / 채팅체 10%*로 권위 분산.
  - *처리반* §2.1 + §3.1: 〈귀하〉의 *당사(=초자연현상처리반)* + 〈암흑색맹〉의 *처리반 부서명 위계*(대응제거적출·관측기록사무·구출처리복원·예측예지예언·고난부활승천). 5작품 합산으로 *처리반의 부서 명단이 옴니버스 차원에서만 완성*.
  - *호텔비다* §5: *호텔 비다 = 단일 조직체* + *정주원 총지배인·이도윤 부총지배인·최은수 부서장*의 *4중 인격 권위*. 〈해피 마트〉의 *이태호 대장*과 유사하되 *4명 이상의 권위 인격*.
- **변주의 범위**:
  - *권위의 견고함*: 수색연합 〈낙원〉(95%) ↔ 호텔비다(30%) ↔ 처리반 〈탈출작전 3〉(0%, 외부 단절)
  - *조직 와해 그라데이션*: 수색연합은 *연합의 점진적 와해 연표*가 시리즈 횡단으로 함의(§3.6), 처리반은 *공식 권위의 5단 진화 곡선*(외부 위장 → 내부 분열 → 외부 단절, §3.5), 호텔비다는 *직원의 인간/비-인간 미결정*으로 *조직 정체성 자체가 모호*.
- **장르 차원의 의미**: *한국형 장르의 공통 자산*. 3시리즈 모두에서 출현. 〈SCP재단〉의 *기관 화자*와 유사하나 *조직의 인격화·와해 가능성*이 *한국형 변종*의 자리.
- **노스포비아 미학과의 관계**: *표면/본질 이중 구조*와 깊이 정합. APMB(*초상현상관리국*)가 본 메타 패턴의 *직계 후손*.

### 2.3. *호명체-보고체-비격식체의 *3축 교차** — 2축에서 3축으로의 확장

- **정의**: 직원/매뉴얼 작성자의 *공식 호명체*(*~하십시오/~바랍니다/귀하*)와 *조직 보고체*(*~로 보고됨/~확인됨*), 그리고 *현장 인물의 비격식 구어체·욕설·이모티콘·자필 메모*가 *한 작품 안에서 교차*. *대응 지침 설계 표준 v1.0이 다루는 2축 교차*가 시리즈 차원에서 *3축으로 확장*됨이 발견.
- **출현 시리즈**:
  - *수색연합* §2.3: 호명체 비율 *60~95%*. 〈낙원〉 95% / 〈크루즈/소래〉 70% / 〈해피 마트〉 60%. 〈해피 마트〉의 *대원 카톡방 텍스처*가 *비격식 채팅체의 본격 진입*.
  - *처리반* §2.3: 호명체 *90% → 0%*의 비단조 곡선. *씨발 / 좆같은 / 모질아*가 *공포의 정점에서 비명을 대체*하고 *통신로그 매체에 진입*. 〈탈출작전 3〉의 *답안체 70% + 보고체 30% + 호명체 0%*가 *3축 교차의 극단*.
  - *호텔비다* §5: 호명체 30% / 보고체 5% / 회상체(1인칭 과거) 50% / 채팅체 15%. *씨발*이 *직원 비격식체에 등장*하며 *주해성 1인칭 회상*이 *제3·제4 어법*을 본격 도입.
- **변주의 범위**:
  - *비격식의 출처*: 수색연합 = *대원 카톡방*, 처리반 = *학생 욕설 + 답안체*, 호텔비다 = *주인공 1인칭 + 채팅방 단체 톡*
  - *호명체 비율의 양극*: 수색연합 95%(〈낙원〉) ↔ 처리반 0%(〈탈출작전 3〉) ↔ 호텔비다 30%. *시리즈 횡단으로 *호명체 비율 감소 곡선*이 관찰*되나 작가가 다르므로 *형식 진화 방향*으로 단정 X.
- **장르 차원의 의미**: *한국형 장르의 공통 자산*. 3시리즈 모두에서 출현. 표준 v1.0의 *2축*(호명체/보고체)이 *3축*(+ 비격식체)으로 확장될 필요성이 시리즈 횡단으로 확립.
- **노스포비아 미학과의 관계**: *친근한 호스트가 균열에서 무엇이 되는가*의 자리. 변형 가능. 단 *비격식의 종류*가 시리즈마다 다르므로 *노스의 톤 결정*은 별도 작업.

### 2.4. *다층 매체 적층* — 사이드의 본격 발달과 매체 위계

- **정의**: 단일 매체(지침서·매뉴얼·답안지) 외피 안에 *공식 보고체 각주 / 사적 채팅 댓글 / 권위자 메모(서명체) / 데이터 표(실종자 명단) / 시간차 갱신*의 *복수 보조 매체*가 끼어들어 *2~5층의 매체 위계*를 형성.
- **출현 시리즈**:
  - *수색연합* §2.6: 매체 층 수 *2~5층*. 〈낙원〉(외전) 2층 / 〈해피 마트〉(본편) 5층. *외전 = 단순 / 본편 = 복잡*의 경향.
  - *처리반* §3.4: 5작품 = *5종 매체체의 단일 매핑*(매뉴얼체/산문체/통신로그체/대본체/답안체). *옴니버스 = 매체 실험의 장*.
  - *호텔비다* §2.4: 6층 (5층 + 외부 1층). *외부 1층 = 파일 분리 그 자체*가 *메타-매체 분리*. *한 파일 안의 다층 직조가 아닌 5개 파일의 분리로 다층화*하는 *본 시리즈의 가장 독창적 자리*.
- **변주의 범위**:
  - *매체 다층화의 *물리적 분리 정도***:
    - *파일 내부 다층* (수색연합 〈해피 마트〉·처리반 〈암흑색맹〉) — 한 문서 안에 5종 매체체 직조
    - *파일 분리 다층* (호텔비다) — *5개 파일이 각각 별도 매체*. 독자가 *읽기 순서 추론*
    - *시리즈 분리 다층* (처리반 5작품 = 5종 매체체) — *시리즈 옴니버스 차원에서 매체 도구함 전시*
  - *위계 규약*: 수색연합 = *고유명사 = 사이드 전용*, 호텔비다 = *손글씨 추가 = 권위자 사적 보강*, 처리반 = *Remove/Retrieve 명명이 외부 양태 표지*

## §3. 시리즈 간 차이의 체계화

같은 자리에서 시리즈마다 다른 처리를 보이는 경우. *축 5개*로 정리.

### 3.1. 축 1 — *호명체/보고체/비격식체의 비율 분포*

- **두 극단**: *호명체 95% 극단(행위자 강제 고정)* ↔ *호명체 0% 극단(권위 단절·매체 잔존)*
- **시리즈 위치**:
  - *수색연합 〈낙원〉*: 호명체 95% — *행위자 강제 고정의 극단*. 외전의 응축성.
  - *처리반 〈귀하〉*: 호명체 90% — 매뉴얼체 단층. 〈낙원〉과 유사하나 단층 매체.
  - *수색연합 평균*: 60~70% — *조직체 권위 + 보고체·채팅체 진입 허용*의 균형.
  - *호텔비다*: 30% — *주해성 1인칭 회상이 50%*로 본문 압도. *권위가 외부 매체로 내부화*.
  - *처리반 〈탈출작전 3〉*: 0% — *호명체 완전 부재가 시리즈 종착점*. 답안체 70%로 잔존 사료.
- **축의 *의미***: *호명체 비율 = 행위자 강제 고정의 강도 = 권위의 견고함*. 비율이 높을수록 *읽기 = 행하기*의 직접성 강화, 낮을수록 *외부 매체의 잔존 사료*적 거리감. 표준 v1.0의 *§5.4 호명체 어미 일관성*은 *95~70% 구간*을 가정하나, *30% 이하 구간*에서는 *어미 일관성보다 매체 위계 직조*가 우선됨.

### 3.2. 축 2 — *매체 다층화의 *물리적 분리 정도**

- **두 극단**: *단일 파일 내 단층 매체* ↔ *시리즈 차원의 매체 도구함 전시*
- **시리즈 위치**:
  - *처리반 〈귀하〉*: 1층 단층 — *매뉴얼체 단일 + 분절 레이아웃*
  - *수색연합 〈낙원〉*: 2층 — *본문 + 각주 1회*
  - *수색연합 〈해피 마트〉*: 5층 — *본문 + 보고 + 채팅 + 메모 + 실종자 명단*. 단일 파일 다층의 정점.
  - *호텔비다*: 6층 = *5층 + 외부 1층* — *5개 파일이 별도 매체로 분리*. 파일 분리 다층의 유일 사례.
  - *처리반 5작품*: *5종 매체체의 단일 매핑* — *옴니버스 차원의 매체 도구함 전시*. 시리즈 차원 다층의 최대 확장.
- **축의 *의미***: *매체 다층화 = 권위의 분산·시간의 두께·시리즈 확장 잠재력*. 표준 v1.0이 *단일 파일 내 다층*만 가정하나, *파일 분리*·*시리즈 분리* 양태가 시리즈 횡단으로 발견. *사상체 문서 시리즈*가 설계될 경우 본 축의 *3종 양태*를 의도적으로 분배 가능.

### 3.3. 축 3 — *결번·점프의 비율*

- **두 극단**: *결번 0%(연속 자연 진행)* ↔ *결번 60% 이상(작품의 절반이 봉인)*
- **시리즈 위치**:
  - *호텔비다*: 0% — *순수 자연 진행, 단일 평탄*. 각 파일마다 자체 번호 체계.
  - *수색연합 평균*: 1~5% — *해피 마트의 8-1-1 결번 1개*, *소래 성당의 §10·§11 결번 2개*
  - *처리반 〈탈출작전 3〉*: 55% — *case 11편 중 6개 결번*
  - *처리반 〈탈출작전 2〉*: 64% — *14편 중 9개 결번* (시리즈 최고치)
- **축의 *의미***: *결번 비율 = 음각 환기의 강도 = 권위의 의도적 봉인*. 결번이 많을수록 *형식적 결손이 검열의 새 형식*. 표준 v1.0의 *§5.6 부분 검열 한정*이 *결번 = 제5종 검열*을 명시 추가 가능. *결번 비율 5~30% 구간이 권장 자리*로 추정(0%는 음각 환기 부재, 60% 이상은 답안지 잔존 사료적 극단).

### 3.4. 축 4 — *시간축의 *압축·확장·정지**

- **두 극단**: *공간 정지 + 외부 누적 5년* ↔ *작품 시간 < 읽기 시간 (확장)*
- **시리즈 위치**:
  - *수색연합 〈소래 성당〉*: 외부 시간 5년 누적(2025~2029) — *외부 시간 누적의 본격 노출*. 시리즈 최대 누적.
  - *수색연합 〈크루즈레인〉*: 20년 시간차(2006 운행 중지 ~ 현재)
  - *호텔비다*: 14시간 응축 + 비선형 — *짧은 시간의 매체 분리에 의한 비선형 재배치*
  - *처리반 한국총력고등학교 시퀀스*: 1시간 43분 단일 일자 분할 — *시퀀스 결합 = 시각 슬롯 분할의 표지*
  - *처리반 〈귀하〉·〈암흑색맹〉*: 작품 시간 < 읽기 시간 — *분절 레이아웃·활자 축소 하강에 의한 확장*
- **축의 *의미***: *시간 처리 = 시리즈 결합 양태의 표지*. 다일자 누적(수색연합) / 단일 일자 분할(처리반 시퀀스) / 응축 + 비선형(호텔비다)이 *각자 다른 시리즈 결합 양태*. 표준 v1.0이 *시간축 처리 절을 부재*시키므로 신설 필요(§6.2 시사 5 참조).

### 3.5. 축 5 — *권위자의 *복수화 정도와 와해 양태**

- **두 극단**: *단일 익명 기관 권위* ↔ *4명 이상의 인격화된 권위 + 와해 진행*
- **시리즈 위치**:
  - *처리반 〈귀하〉*: 단일 *당사* — 인격화 최소
  - *수색연합 〈낙원〉*: 연합 조직체 단일 권위 95% — 인격화 최소(이태호 1회 각주만)
  - *수색연합 〈해피 마트〉*: 이태호 + 다수 대원 — 인격망 폭발
  - *호텔비다*: 정주원·이도윤·최은수·제명 + 동료망 — 4중 인격 + 사적 관계의 본문 진입
  - *처리반 5작품 횡단*: 부서 명단 + 5단 권위 진화 곡선 — *옴니버스 차원의 권위 와해 시연*
- **축의 *의미***: *권위자 복수화 = 조직 권위의 한국형 변종 강도*. 시리즈가 진행될수록 권위가 *인격화 → 와해*의 곡선을 그리는 경향. 표준 v1.0의 *§2.3 독자의 두 위치 동시 점유*가 *권위자의 위치 동시 점유*로 확장 가능(다수 권위자의 시점 모듈).

## §4. 횡단 차원의 새 발견

시리즈 단위에서는 보이지 않고 *3시리즈를 횡단*해야 보이는 자리.

### 4.1. *한국형 장르 옴니버스 결합 4유형의 *동시 작동*과 시리즈마다 다른 *주력 조합**

표준 v1.0이 *옴니버스 결합 유형*을 명시 분류하지 않으나, 시리즈 통합본 2개 모두 *§5.4 옴니버스 결합 유형*을 *주력 + 보조의 조합*으로 분류. 횡단 비교:

- *수색연합*: 주력 = *층위형 + 반향형* / 보조 = *누적형 + 독립형* (4유형 모두 동시 작동)
- *처리반*: 주력 = *층위형 + 반향형* / 보조 = *누적형*(시퀀스 한정) / *독립형 부재*
- *호텔비다*(단독 작품이나 5파일 시리즈): *층위형*(5파일 = 5층) + *반향형*(파일 간 사후 회수)

*수색연합 §3.5의 발견*("4유형이 다른 층위에서 동시 작동하는 혼종 옴니버스")이 *처리반·호텔비다에서도 확인*되며 *시리즈 횡단의 안정적 발견*으로 격상. 표준 v1.0의 *§4.3 사이드 3가지 유형(독립형/보강형/분기형)*에 *옴니버스 결합 4유형*을 *별도 분류 차원*으로 추가 가능. *사이드 = 항목 차원 / 옴니버스 = 시리즈 차원*의 *2단 분류 체계*.

### 4.2. *부서명·인물명·정형구의 *옴니버스 분산 노출** — 시리즈 차원에서만 완성되는 정보

처리반 §3.1의 발견(*부서 명단이 작품마다 부분 노출되며 전체 명단은 어느 한 작품에도 없음*)이 *수색연합·호텔비다에서도 변종으로 출현*:

- *수색연합*: *시리즈 횡단 공유 인물군*(이태호·고지헌·양지혜)이 *작품마다 분산 출현*. 시리즈 차원에서 *연합의 와해 연표*가 함의(§3.6).
- *호텔비다*: *직원·고객의 인간/비-인간 미결정*이 *5개 파일 합산에서만 식음료부 12번 한 줄로 형식적 시인*. *시리즈 정보가 작품마다 분산 노출*.
- *처리반*: *행정 정형구 / 부서 명단 / 시퀀스 시각 스탬프*의 3종이 *옴니버스 분산 노출*.

이는 *옴니버스 차원에서만 완성되는 정보 = 추론 표적 3층의 자리*임을 시사. 표준 v1.0의 *§3.2 추론 표적 3층 분포(1층 60% / 2층 30% / 3층 10%)*가 *작품 단위*에 한정될 때, *시리즈/옴니버스 차원*에서는 *3층이 옴니버스 분산 노출로 분포*되는 변종이 가능. 즉 *3층 = 한 작품의 부분 검열*이 아닌 *시리즈 횡단의 사후 회수*가 될 수 있음.

### 4.3. *공간 카탈로그의 *한국 사회 의례 위계*의 도감화*

수색연합 §7 관찰 3의 발견(*시리즈가 한국 사회 의례 위계의 카탈로그*: 학교·열차·마트·성당)이 *처리반·호텔비다에서도 확인*:

- *처리반*: 한국총력고등학교(*1972년 입학*의 시간성) + *(대학)병원 추정 — 암흑색맹*(*마경 = 환자 영혼 식별 공간*)
- *호텔비다*: 호텔(*직장 위계 + 손님-점원 의례*) + *카지노*(귀하의 무대 추정)
- *수색연합*: 학교·열차·마트·성당

3시리즈 합산으로 *학교·열차·마트·성당·병원·호텔·카지노·시험장*의 *7종 의례 공간*. *한국형 장르가 *공간 = 의례 위계 = 생존 통화*의 등식*을 시리즈 차원에서 시연. 이는 *서양 SCP의 추상 공간(컨테인먼트 셀·차원 균열)*과 *결정적으로 다른 자리*. 표준 v1.0이 *공간 분류 절을 부재*시키나, *공간의 의례 위계 분류*가 *대응 지침 §3.3 1막 진입 이전의 핵심 변수*임이 시리즈 횡단으로 확립.

### 4.4. *주인공의 *시점 위치 3종**

3시리즈를 횡단하면 *주인공(=일차 청자)의 시점 위치*가 *3종*으로 분류됨:

- *제1종 — 외부 매체의 호명 청자*: 〈낙원〉·〈귀하〉·〈탈출작전 1·2·3〉 — *귀하 / 학생*으로 호명되는 *익명 행위자*. 호명체 비율 높음.
- *제2종 — 조직체 1인칭 복수의 일원*: 수색연합 대원(이태호·고지헌·양지혜) — *본 연합 / 저희*의 일원. 보고체 + 채팅체 진입.
- *제3종 — 1인칭 회상자*: 호텔비다 주해성 + 처리반 〈암흑색맹〉 한태준 — *나는 ~했다*의 *작품 내부 자기-회상*. 회상체 50% 이상.

표준 v1.0의 *§2.3 독자의 두 위치 동시 점유*(관찰자 + 잠재적 행위자)가 *3종 시점 위치의 분기*로 확장 가능. *Level IG 탐사자 = 제1종*이 디폴트이나, *제2·3종*의 *대응 지침 시점 모듈*이 *추가 자원*. 특히 *제3종 1인칭 회상자*가 *시점 모듈 후보*로 추가될 가능성.

### 4.5. *결번의 *기술 매체 오작동 흔적 변종**

수색연합·처리반은 *작가 차원 결번(번호 결번)*이 주력이나, 호텔비다는 *기술 매체 오작동 흔적(자모 깨짐 *정ㅈㅓㄴ* / 재전송·삭제 표시)*이라는 *결번의 변종*을 도입. 이는 *번호 체계 외부의 결번*. 시리즈 횡단으로 *결번 = 5종*으로 확장:

1. 번호 결번 (수색연합 〈해피 마트〉·〈소래 성당〉, 처리반 〈탈출작전 2·3〉)
2. 메타 균열 (수색연합 〈크루즈레인〉의 *영월 워터파크는 존재하지 않습니다*)
3. 인물 부재형 군림 (수색연합 〈낙원〉의 *그녀*)
4. 자모 깨짐·송신 실패 (호텔비다 *(재전송 / 삭제)*)
5. 수치 ??? 표기 (처리반 〈귀하〉)

5종이 *모두 *형식의 빈자리에 의한 환기*라는 동일 원리*로 작동. 표준 v1.0의 *§5.6 검열 처리*가 *부분 검열 한정*만 명시하나, *5종 음각 환기 도구함*을 본 메타 패턴이 제공.

### 4.6. *한국형 장르의 *옴니버스 진화 동력 = 매체 실험**

처리반 §3.4의 발견(*5작품 = 5종 매체체의 단일 매핑 / 옴니버스 = 매체 실험의 장*)이 *수색연합·호텔비다에서도 변종*:

- *수색연합*: *외피 단일성(지침서) + 내부 매체 다양성(2~5층)*. *외피 강제 + 내부 자유*의 조합.
- *호텔비다*: *5개 파일이 매체 다양성*(SMS / 체크리스트 / 매뉴얼 / 매뉴얼 / 채팅방). 한 작가의 단일 시리즈 내부에서도 매체 실험 진행.
- *처리반*: *5작품 = 5종 매체체*. 옴니버스 차원 매체 실험.

3시리즈 모두 *매체 실험을 옴니버스 진화 동력으로 사용*. 이는 *서양 SCP의 일관된 보고서 형식*과 *결정적으로 다른 자리*. 한국형 옴니버스는 *매체 다양화가 진화의 필수 동력*. 표준 v1.0이 *유동 분량*만 다루고 *매체 다양화*를 다루지 않으므로, *유동 매체* 원칙의 신설 가능성.

## §5. *한국형 장르의 *서양 SCP와의 차별점*

본 절은 *횡단 발견의 결정적 자리*. 3시리즈 합산에서 *한국형 장르가 서양 SCP 컨벤션과 차별되는 자리*를 종합.

### 5.1. 차별점 1 — *공간 = 한국 사회 의례 위계*의 도감화

서양 SCP는 *추상 공간*(컨테인먼트 셀·차원 균열·이상 부지)이 디폴트. 한국형 장르(3시리즈 합산)는 *학교·열차·마트·성당·병원·호텔·카지노·시험장*의 *현실 공간*이 디폴트이며, *각 공간이 그 공간 고유의 의례 위계*(교사-학생·승무원-손님·점원-손님·사제-신자·의사-환자·직원-고객·딜러-플레이어·감독관-수험생)를 *생존 통화*로 운영. *예의 위반 = 죽음*의 등식이 *행정 정형구*와 결합. 노스포비아 미학에 *직접 응용 가능* — APMB 사상체들의 *공간 분류 절*에 본 차별점 적용.

### 5.2. 차별점 2 — *조직 권위의 *인격화·복수화·와해**

서양 SCP는 *재단(Foundation)*이라는 *익명 단일 기관 권위*가 디폴트. 한국형 장르(3시리즈)는 *연합·처리반·호텔*이 *4명 이상의 인격화된 권위자*에 의해 운영되며, *권위자 간 사적 관계*(이도윤·제명의 가죽끈, 이태호 대장의 가족)가 본문에 진입. 시리즈가 진행될수록 *권위가 와해되는 곡선*이 함의. *친근한 기관 + 인간적 약점의 동거*. 노스포비아의 *APMB가 단일 만능 기관이 아닌 한국형 변종*으로 자리매김할 가능성.

### 5.3. 차별점 3 — *유머·자조의 *호러 톤 동거**

서양 SCP의 *임상적 단일 톤*과 결정적으로 다른 자리. 한국형 장르(3시리즈)는 *직장인 자조 + 대원 농담 + 학생 욕설 + 인터넷 어휘*가 *호러의 톤 균열이 아닌 동거*로 작동. *씨발이 권위 한계의 표지*(처리반), *유머가 부고의 사전 정서 투자*(수색연합), *자본주의 노예 자조가 호러의 입구*(호텔비다). 노스의 톤 결정에 *직접 응용 가능*.

### 5.4. 차별점 4 — *형식의 빈자리에 의한 환기 5종*

서양 SCP의 *[DATA EXPUNGED]·[REDACTED] 한 줄 가림*과 결정적으로 다른 자리. 한국형 장르(3시리즈)는 *번호 결번 / 메타 균열 / 인물 부재형 군림 / 자모 깨짐 / 수치 ??? 표기*의 *5종 음각 환기 도구함*을 발전. *형식의 빈자리 자체가 의미 생산*. 표준 v1.0의 *부분 검열 한정* 원칙이 *한국형의 5종 음각 환기*로 확장됨이 시리즈 횡단의 결정적 발견.

### 5.5. 차별점 5 — *살아 있는 문서* — 시간 누적된 매체

서양 SCP의 *정지된 보고서*(작성 시점 이후 갱신 거의 없음)와 결정적으로 다른 자리. 한국형 장르(3시리즈)는 *시간차 갱신 / 댓글 누적 / 갱신 메모 / 수색 차수 / 시각 스탬프*를 통해 *문서 자체가 시간을 살고 있는* 매체. *외부 시간의 흐름*이 *내부 권위의 와해를 기록*. 노스포비아의 *방송 = 시간을 살고 있는 사상체*와 *완벽 정합*.

### 5.6. 차별점 6 — *옴니버스 = 매체 실험의 장*

서양 SCP의 *일관된 보고서 형식*(SCP-XXX 표준)과 결정적으로 다른 자리. 한국형 장르(3시리즈)는 *작품마다 다른 매체체*(매뉴얼체 / 산문체 / 통신로그체 / 대본체 / 답안체 / 채팅체 / SMS / 회상체)를 *옴니버스 진화 동력*으로 사용. *매체 다양화 자체가 시리즈의 동력*. 노스포비아 사상체 시리즈가 설계될 경우 본 차별점이 *형식적 차별화 자리*로 기능 가능.

## §6. 대응 지침 설계 표준 갱신 제안 — *분류·우선순위*

본 절이 *3단 갱신 작업의 직접 입력*. 4개 카테고리로 분류 + 우선순위 라벨 부착.

*우선순위 정의 (§3.5 재게재)*:
- *우선 1*: 갱신 시 *결정적 개선* + *작업 비용이 작은* 자리
- *우선 2*: *큰 개선*이지만 *작업 비용이 큰* 자리
- *우선 3*: *부수 개선*. 후속 갱신으로 미룸 가능.

### 6.1. 카테고리 1 — *기존 자리의 보강*

표준 v1.0에 *이미 있는 자리*의 세부 강화.

- **제안 1.1** [우선 1]: 표준 *§1.4 격리픽션의 임상적 어조*에 *한국형 변종 — 일상 톤과의 동거*를 *추가 절(§1.4.1 한국형 임상 어조의 변종)*로 보강. *임상적 단일 톤*이 디폴트가 아니라 *임상 톤 + 직장인 자조 + 대원 농담의 동거*가 한국형 장르의 디폴트임을 명시. 근거: §2.11 메타 패턴 (3시리즈 모두 출현). 출처: 호텔비다 §2.6 자리 2, 수색연합 §7 관찰 1, 처리반 §7 관찰 3.

- **제안 1.2** [우선 1]: 표준 *§5.4 호명체 어미 일관성*에 *호명체 비율 차등 자리*를 *추가 소절(§5.4.1)*로 보강. *95% 극단 — 30% 이하*의 비율 차등이 *행위자 강제 고정의 강도*를 결정함을 명시. 95~70% 구간이 디폴트이나 *30% 이하 구간*에서는 *어미 일관성보다 매체 위계 직조가 우선*. 근거: §3.1 축 1. 출처: 수색연합 §4.3 시점 구조 변주표, 처리반 §4.3 시점 구조 변주표, 호텔비다 §5.

- **제안 1.3** [우선 1]: 표준 *§5.6 검열 처리*에 *제5종 — 번호 음각 사용*을 추가. *번호 결번·점프*가 *부분 검열과 동등한 효과*를 만드는 도구임을 명시. 결번 비율 *5~30% 구간이 권장*임을 추가. 근거: §2.6 메타 패턴 + §3.3 축 3. 출처: 수색연합 〈해피 마트〉·〈소래 성당〉, 처리반 〈탈출작전 2·3〉.

- **제안 1.4** [우선 1]: 표준 *§2.4 위반의 결과 미명시 원칙*에 *4종 우회 양태*를 추가. *반복 정형구 / 변주형 완곡어법 / 사례 누적형 / 결과 완전 부재형*의 4종이 시리즈마다 다르게 사용됨을 명시. 근거: §2.1 메타 패턴. 출처: 수색연합 §2.1, 처리반 §2.4, 호텔비다 §4.

### 6.4. 카테고리 4 — *배제 자리*

분석에서 발견되었으나 *노스포비아 미학과 대립*해 *표준에 도입하지 않을* 자리.

- **배제 1**: *권위자 간 사적 관계(가죽끈 반지·부부 관계 등)의 본문 상세 노출* (호텔비다 §4) — 이유: 노스포비아 미학의 *표면/본질 이중 구조*에서 *사적 관계의 본문 진입은 표면의 친근성을 강화*하나, *APMB의 임상적 공식 권위 외형*을 *사적 친밀로 침식*해 *임상 어조와 충돌*. *서명체 메모 형식*은 도입 가능하나 *사적 관계의 상세 묘사는 배제*.

- **배제 2**: *옥상 봉쇄 미완 + 통신 차단 항복의 시퀀스 결말 양태* (처리반 한국총력고등학교 시퀀스) — 이유: *대응 지침의 4막 비상 자리*가 *후속 절차 [기록 보류]*로 닫혀야 하나, 처리반의 *외부 단절 + 학교 측 발신 위장*은 *적측이 권위 매체를 전유*하는 자리. 이는 *대응 지침이 적측에 전유될 가능성을 시인*하는 자리이며 *대응 지침의 권위 자체를 무력화*. 노스포비아 미학의 *공식 권위 외형 보존*과 *부분 충돌*. *시점 모듈 또는 사이드의 *예외 자리*로 한정 도입 가능하나, *디폴트로는 배제*.

- **배제 3**: *유머의 *직설적 인터넷 어휘 노출** (호텔비다 *미라클 모닝 / 대박좋다 / 고용노동부 신고 감 / 자본주의의 더러운 노예*) — 이유: 노스포비아 미학의 *임상적 권위 외형*과 *직접 충돌*. 단 *§2.11 메타 패턴(유머·자조의 호러 톤 동거)*은 보존하되, *직설적 인터넷 어휘 대신 *완곡한 자조*(*본 인원이 본 환경에 대한 적응이 본인의 인지 안에 안정적으로 형성된 것으로 사료되는 시점부터*) 양태로 변환*해 도입. 즉 *동거 원리는 보존, 어휘 양태는 변환*.

- **배제 4**: *주관적 판별 의존의 극단 — 관리인의 기분 / 수려해 보인다면* (수색연합 〈소래 성당〉) — 이유: 표준 v1.0의 *§5.3 모호함 보존*은 *조건의 모호화*가 디폴트이나, *주관적 판별의 극단*은 *독자의 자기 분류 부담을 과도하게 증가*시켜 *읽기 흐름 자체를 차단*할 위험. *주관적 판별 의존형 분기 어휘*(제안 1.5)는 도입하되, *관리인의 기분* 수준의 *완전 주관 의존*은 배제.

## §7. 자유 관찰란 — 횡단 종합 시점의 발견

위 6개 절에 명시되지 않은, *횡단 종합 시점에 발견된* 주목할 자리.

- **관찰 1**: *3시리즈 모두 *완결되지 않은 살아 있는 시리즈**임이 횡단 시점에 발견. 수색연합은 *연합의 와해 연표*가 *후속 작품에서 결말 회수 가능성* + *외전 시리즈 미공개 작품 다수 추정*. 처리반은 *한국총력고등학교 시퀀스의 후속 회차*(탈출작전 4 + 모의고사 1·2 + 타임라인)가 *미확인*. 호텔비다는 *김재이 작가의 후속 시리즈 가능성*. 즉 *분석 시점에서 시리즈는 모두 *진행 중*인 상태이며 이 *미완 시리즈성*이 한국형 장르의 *결정적 매체적 자리*. 노스포비아도 *방송이 진행 중*이라는 점에서 *동일 자리에 위치*. 노스포비아 ARG 설계에서 *진행 중 = 시리즈의 매체적 본질*임을 자원화 가능.

- **관찰 2**: *3시리즈가 *각자 다른 작가/저자*에 속함에도 *메타 패턴의 정합도가 매우 높음*. 수색연합은 *익명 인터넷 규칙괴담 계보*, 처리반은 *한청민(〈암흑색맹〉) + 미상*, 호텔비다는 *김재이*. 작가군이 *완전 분리*이되 *메타 패턴 11개 중 9개*가 *3시리즈 모두에서 출현*. 이는 *한국형 행정 문체 호러 옴니버스가 이미 장르 컨벤션화*되었음을 시사. 노스포비아가 *이 컨벤션을 의식적으로 활용*하면 *독자가 장르 친숙성을 즉시 인지*할 가능성. 동시에 *컨벤션 차별화의 자리*도 명확히 식별 가능(노스포비아의 *방송 매체*가 본 컨벤션에 *부재한 매체*).

- **관찰 3**: *옴니버스 결합 4유형이 *시리즈마다 주력 조합이 다름*이 횡단 시점에 발견*. 수색연합 = 층위형 + 반향형 / 누적형(인물망) + 독립형(각 작품 완결). 처리반 = 층위형 + 반향형 / 누적형(시퀀스 한정). 호텔비다 = 층위형(5파일) + 반향형(파일 간 사후 회수). *3시리즈 모두 주력 = 층위형 + 반향형*이 *공통*이고, *보조 = 누적형/독립형*의 유무가 *차이*. 즉 *한국형 옴니버스 호러의 공식*이 *주력 (층위형 + 반향형) + 보조 (누적형/독립형)*임이 잠정 시사. 단 *3시리즈 표본은 과대 일반화 위험*. 노스포비아 사상체 시리즈 설계 시 *주력 (층위형 + 반향형)을 디폴트*로 가정 가능.

## §8. 메타 — 종합의 한계

본 종합본의 *한계 자기 공개*. 정직하게.

- **입력 자료의 *비균질성*이 어떤 자리에 어떻게 영향을 줬는가**: 본 종합은 *시리즈 통합본 2개 + 단독 작품 분석 1개*의 비균질 입력 자료를 다룸. 호텔비다는 *시리즈 단위*이나 *1단 통합본을 거치지 않은 작품 차원 분석*이므로 *시리즈 차원 추상*이 시리즈 통합본 2개보다 *얕음*. 본 종합의 §2 메타 패턴 11개 중 일부는 *호텔비다에서의 변종 확인이 *작품 차원의 한 사례*에 머물고 시리즈 차원의 패턴 확립까지는 가지 않음*. 특히 *§2.2 집단 단수 화자*, *§2.4 다층 매체 적층*, *§2.7 공식 권위의 복수화·인격화·균열*은 시리즈 통합본 2개에서 *시리즈 차원의 변주 분석*이 있는 반면, 호텔비다는 *단일 시리즈의 작품 차원 분석*이 인용되었음. 본 종합의 *3시리즈 횡단 안정성* 주장이 *2시리즈 + 1단독 작품* 수준의 안정성임에 유의.

- **시리즈 수의 부족(*3시리즈*)으로 *과대 일반화 위험*이 있는 자리**:
  - *§2.11 유머·자조의 호러 톤 동거*: 3시리즈 모두에서 출현하나 *작가가 다른 3시리즈*에 한정. *4번째 시리즈*에서 *유머가 부재한 시리즈*가 발견될 가능성. *시사적 패턴이 아닌 잠정 메타 패턴*으로 한정.
  - *§4.3 공간 = 한국 사회 의례 위계의 도감화*: 3시리즈 합산 7종 의례 공간이 *학교·열차·마트·성당·병원·호텔·카지노·시험장*에 한정. *비위계 공간*(공원·해변·산림·도시 거리 등)이 4번째 시리즈에 포함된다면 *공간 카탈로그의 의례 위계 분류 자체가 와해*될 가능성.
  - *§5.6 옴니버스 = 매체 실험의 장*: 3시리즈 표본의 공통이나, *4번째 시리즈*에서 *단일 매체체 고수형 옴니버스*가 발견될 가능성. *시사적 발견*.
  - *§7 관찰 3 *주력 (층위형 + 반향형) 공식**: 3시리즈 표본의 공통이나 *과대 일반화 위험 명시*.

- **3단 갱신 작업이 *반드시 검증해야 할 자리***:
  - *§6.1 제안 1.7 정서 인입형 사이드*: *시사적 단계*로 명명했으나, 3단 갱신 작업에서 *4번째 유형으로 격상할지 / 보강형의 변종으로 흡수할지* 결정 필요.
  - *§6.2 제안 2.5 공간 = 의례 위계 분류*: 7종 공간 카탈로그를 표준에 *명시 도입할지 / 시사적 도구함으로 한정할지* 결정 필요. *비위계 공간*의 사상체가 설계될 가능성을 고려.
  - *§6.4 배제 자리*: 배제 1~4의 *경계*가 명료하지 않음. *서명체 메모 형식은 도입 / 사적 관계 묘사는 배제*의 *경계선*이 *3단 갱신*에서 구체화 필요.
  - *§3 차이의 5축*: 5축이 *모두 독립적인 축*인지, *일부 축이 종속 관계*인지(예: *축 1 호명체 비율*과 *축 5 권위자 복수화*가 *역상관 관계*일 가능성) *3단 갱신*에서 검증 필요.
  - *§4.4 시점 위치 3종*: 제3종 *1인칭 회상자*가 *Level IG 탐사자 = 제1종이 디폴트인 노스포비아 미학*과 *어떻게 정합/대립*하는지 *3단 갱신*에서 결정 필요. *시점 모듈 형식*으로 도입 시 *§4.4 시점 모듈 권장 분량*과 조정 필요.

- **원작품 부재 + 시리즈 통합본의 *분석 자료에만 의존*한 종합**: 본 종합은 *원작품 13편(수색연합 4 + 처리반 5 + 호텔비다 5파일 = 14편이나 호텔비다 5파일은 단일 시리즈)*을 *직접 읽지 않고* 분석 자료의 인용에만 의존. 특히 *수색연합·처리반의 시리즈 통합본도 원작품을 직접 읽지 않은 1단 통합*이므로, 본 2단 종합은 *2단계 추상*에 해당. *원작품 직접 확인이 필요한 자리*는 *§6 제안의 구체 인용 검증*과 *§4 새 발견의 작품별 미세 확인*.
