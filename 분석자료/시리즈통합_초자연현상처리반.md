# 〈초자연현상처리반〉 시리즈 통합 분석

## §0. 시리즈 메타

- **시리즈명**: 초자연현상처리반
- **포함 작품 수**: 5
- **포함 작품 목록**:
  - 〈귀하는 순수한 인간입니다〉(독립 옴니버스, 단일 매뉴얼체)
  - 〈암흑색맹 소탕 작전〉(독립 옴니버스, 산문 회상록 + 행정 보고서)
  - 〈한국총력고등학교 탈출작전 1〉(시퀀스 1편, 통신 대화록 + 외부 무전)
  - 〈한국총력고등학교 탈출작전 2〉(시퀀스 2편, 분산 다시점 대본 + Remove 사이드)
  - 〈한국총력고등학교 탈출작전 3〉(시퀀스 3편, 답안지 발췌 매체)
- **시리즈 작가/출처**: 〈암흑색맹 소탕 작전〉 말미에 *작성자 한청민* 명시. 나머지 4편의 저자명 불명. 시퀀스 3편(탈출작전 1·2·3)이 동일 작가의 연속 회차인지, 옴니버스 공동작인지 여부는 확인 불가.
- **시리즈 총 분량**: 약 50,114자 (1,800 + 40,214 + 4,500 + 3,400 + 1,200). 단 〈탈출작전 1〉은 원작 20파트 시리얼 중 6파트만 추린 발췌본 기준이며, 원작 시리즈 전체는 *탈출작전 4부 + 모의고사 2부 + 타임라인*의 추가 파트가 존재함을 시퀀스 내부에서 사후 확인.
- **시리즈 통합 매체 분류**: **다층 우세**. 5작품 중 4작품(암흑색맹·탈출작전 1·2·3)이 *다층 매체*, 1작품(귀하는 순수한 인간입니다)만 *단일층*. 시리즈 차원 평균 매체 층 수는 *약 3층* (단일층 1 + 3층 3 + 4층 1).
- **시리즈 장르 비율 종합**:
  - 격리픽션 **30%** (작품별: 25 / 15 / 30 / 50 / 30 평균)
  - 나폴리탄 **32%** (작품별: 30 / 30 / 25 / 25 / 50 평균)
  - 규칙괴담 **28%** (작품별: 45 / 25 / 45 / 25 / 20 평균)
  - 잔여 **10%** (〈암흑색맹〉의 *서사 장편(액션·전투) 30%*가 단독 비중을 형성)
  - *나폴리탄 비중이 가장 큼*. 단 시리즈 횡단으로 보면 *규칙괴담의 출현이 항상 단독이 아니라 격리픽션·나폴리탄과 합금*되는 점이 결정적 — 즉 *순수 규칙괴담은 부재*하며 *모든 작품이 3장르 합금*.

## §1. 시리즈의 한 줄 정체

조직체(APMB-처리반)의 *공식 양식*(매뉴얼·브리핑·통신로그·보고서·답안지)이 *외부에 제시하는 정직한 얼굴*로 진입한 후, 그 양식이 *적측의 위장 매체로 전유 가능함을 매체 자체로 시연*하면서 *공식 권위가 작품 내부에서 분열·기만·우회·항복·단절되는 다양한 양태*를 시리즈 차원에서 펼쳐 보이는, *행정 형식과 그 형식의 침식 사이의 자리*에서 호러를 운영하는 옴니버스.

## §2. 시리즈 공통 패턴 (주 작업)

### 2.1. 행정 양식 자체가 서사 단위가 되는 *형식=서사 등식*

- **정의**: 작품의 *서사 단위*가 *행정·매체 단위*와 일치한다. 작전 브리핑 → 작전 수행 → 작전 결과 보고의 *행정 흐름*이 그대로 작품의 *막 구조*가 되며, 매뉴얼의 *조건 분기 라벨*이 *막 경계*가 되고, 통신 *회차 코드(part X-N)*가 *번호 진행*이 되며, 답안지의 *case 번호*가 *분기 식별자*가 된다.
- **출현 작품**:
  - 〈암흑색맹 소탕 작전〉 §6 자유 관찰 패턴 1: *작전 브리핑 → 작전 수행 → 작전 결과 보고의 행정 흐름이 그대로 작품의 막 구조와 일치한다*. 종결의 *행정 보고서 양식*이 *서사적 무게를 기타사항이라는 한 줄로 봉인*.
  - 〈귀하는 순수한 인간입니다〉 §2.1: *4단계 조건 분기 라벨*이 *막 경계*. *칩의 개수가 X개 이상 Y개 미만인 경우)*가 *조건절 라벨이 곧 막 진입 조건*.
  - 〈탈출작전 1·2〉 §2.1: *part 1-N / 2-N* 회차 코드가 *막 차수 노출 + 매체 단위*를 겸함. *part Remove 2*는 *번호 체계 외부에 별도 회차 표기*로 사이드 위계를 본문에 근접시킴.
  - 〈탈출작전 3〉 §2.2: *case 3-1·3-2·3-5·3-8·3-11(終)*의 *case 번호*가 *동일 시험지에 대한 5명 분기 응답의 식별자*. *case 번호 자체가 분기 마커*.
- **변주의 범위**:
  - *번호 노출 차등*: 〈암흑색맹〉=번호 부재 단일 산문 / 〈귀하〉=번호 부재 + 조건절 라벨 / 〈탈출작전 1〉=part 1-N 자릿수 패딩 없음 + (終) / 〈탈출작전 2〉=part 2-N + Remove + 9개 결번 / 〈탈출작전 3〉=case 3-N + 비균등 점프 + (終)
  - *행정 흐름의 명시성*: 〈암흑색맹〉이 *가장 명시적*(브리핑→수행→보고서), 〈탈출작전 3〉이 *가장 잔존 사료적*(시험지 부재 + 답안만 잔존)
- **기능**: *공식 권위의 외형*이 *작품 진입 단계에서 안정감을 부여*한 뒤, *그 외형 안에서 침식·기만·항복이 발생하는* 자리를 *외형의 변동*만으로 시연 가능. 형식 위장 원칙의 *시리즈 차원 핵심 도구*.

### 2.2. 외부 공식 발신체가 적측의 위장 매체로 전유되는 *권위 매체 양가성*

- **정의**: 시민·국민을 향한 *외부 공식 발신*(재난문자·재해대피문자·실종신고문자·행정안전부 장관 명의 등)이 *작품 내부에서 적측에 의해 모방·위장·전유*된다. *외부 표층은 정직하나 내부 의도는 적군에 의해 침식 가능*.
- **출현 작품**:
  - 〈탈출작전 1〉 외층: *재해대피문자(20.12.11. 18:23 발송)*가 *행정안전부 장관 강길태 명의*로 출현. 본 작품에서는 *정직한 공식 발신*으로 작동.
  - 〈탈출작전 2〉 외층 + Remove 2: *19:32 경계 해제 문자*(행정안전부 장관 강길태 명의)가 *학교 측이 발신한 가짜 최면 문자*임이 *part Remove 2의 통신 마비*에서 사후 폭로. 동일 발신인의 *정직한 문자(1편 18:23)*와 *위장 문자(2편 19:32)*가 *시퀀스 두 회차에서 대구*를 이룸.
  - 〈탈출작전 3〉 1막: *19:48 실종신고문자*가 *한국총력고등학교 교장 ■■■(이름 검열)* 명의로 발신. 시퀀스 2편의 *행정안전부 장관 위장*과 같은 자리 — *학교가 처리반의 공식 발신 형식을 모방한 자기 발신*.
  - 〈암흑색맹〉 0막: *유유영(관측기록사무 11팀) 브리핑*이 *공식 권위의 정직한 외형*으로 진입했으나, *예측예지예언 6팀이 11팀 전원 희생을 전제로 작전을 입안*했음이 *연결담당자 자신의 입에서 폭로* — 공식 권위가 *내부에서 분열*.
- **변주의 범위**:
  - *위장의 주체*: 〈탈출작전 2·3〉은 *학교(외부 적측)가 처리반/행정부의 발신 형식을 모방*. 〈암흑색맹〉은 *처리반 내부 부서(예측예지예언 6팀)가 형제 부서(대응제거적출 11팀)를 기만*. 즉 *외부 위장*과 *내부 분열*의 양 끝.
  - *폭로 시점*: 〈탈출작전 2〉는 *작품 종결의 Remove 2에서 폭로*, 〈암흑색맹〉은 *작전 한복판 3막에서 폭로*, 〈탈출작전 3〉은 *시퀀스 회차 사후 회수*로 폭로.
- **기능**: *공식 권위 = 신뢰 가능한 외부*라는 *작품 진입 시 안정감*을 *작품 후반·시퀀스 후속에서 폭파*하는 자리. 노스포비아 미학의 *표면/본질 이중 구조*와 깊이 정합.

### 2.3. 호명체 ↔ 보고체 ↔ 비격식체의 *3축 교차*

- **정의**: 직원/매뉴얼 작성자의 *공식 호명체*(*~하십시오/~바랍니다/귀하*)와 *조직 보고체*(*~로 보고됨/~확인됨*), 그리고 *현장 인물의 비격식 구어체·욕설·이모티콘·자필 메모*가 *한 작품 안에서 교차*. 단순한 2축(호명/보고)이 아닌 *3축 교차*가 시리즈의 결정적 자리.
- **출현 작품**:
  - 〈암흑색맹〉 §5: 호명체 약 8%(0막 브리핑) + 보고체·서술체 약 92%, *씨발 / 좆같은 / 모질아*가 *공포의 정점에서 비명을 대체*. *퇴사! 퇴사해, 씨발!*이 *외부 권능 호출의 트리거*.
  - 〈귀하〉 §5: 호명체 약 90%(*~을 추천합니다/~하지 않습니다*) + 보고체 극소수(*~로 보고된다*가 *결정적 정보 자리*에 박힘).
  - 〈탈출작전 1〉 §5: 직원=호명체(*~하십시오/귀하*), 학생=구어체(*~예요/~잖아요/씨발*). *귀하 ↔ 누나*의 *호명 비대칭*이 *직무적 거리 ↔ 의존적 친근*을 동시 표상.
  - 〈탈출작전 2〉 §5: 호명체 부재(대본 매체) + 대화체 75% + 통신 보고체 20% + 공식 발신체 5%. *씨발*이 *통신로그 매체에 진입하는 자리*가 *작전 공식성의 어휘 차원 항복*(part Remove 2의 *씨발! 통신 꺼!*).
  - 〈탈출작전 3〉 §5: 호명체 0% + 보고체 30%(발췌자 괄호 메모) + *답안체* 70%(시제·인칭 약화). *님들 ㄳ / ㄹㅇㅋㅋ / 555555 / ㅗ*가 *답안체 안의 비격식 잔존*. 그러나 *case 3-11의 정자체 감사*가 *비격식의 정반대 극*으로 등장.
- **변주의 범위**:
  - *비격식의 방향*: 〈암흑색맹〉=*직장인 짜증·체념의 욕설*, 〈탈출작전 2〉=*조직 통제 붕괴의 욕설*, 〈탈출작전 3〉=*수험생 은어·이모티콘*. 각 작품의 *비격식 자리가 인물의 사회적 위치를 환기*.
  - *호명체 비율의 양 극단*: 〈귀하〉의 90% ↔ 〈탈출작전 3〉의 0%. *호명체의 완전 부재*가 *처리반 통신 단절*과 *매체 차원에서 일치*하는 시리즈 정합성.
- **기능**: *공식 톤(임상)이 비격식 톤(짜증·체념·이모티콘)에 의해 침식*되는 자리에서 *조직 권위의 한계*가 *어휘 차원에서* 가시화. 노스포비아의 *친근한 호스트가 균열에서 무엇이 되는가*의 후보 자리.

### 2.4. 위반 결과의 *명시 부재 + 사이드/지문/사후 회수로 우회 시연*

- **정의**: 본 진행의 *규칙·금기·권고*에 대해 *위반 시 결과*가 직접 명시되지 않고, *사이드 단편*·*지문 매체*·*시퀀스 사후 회수*·*결번 봉인*으로 우회되어 환기.
- **출현 작품**:
  - 〈탈출작전 1〉 §2.3: *part 1-2의 단절 사망 사이드*가 *본 진행에서 결과 명시를 우회*하고 *생존 압박을 부여*. *사망 확인. 이쪽은 실패했습니다.*
  - 〈탈출작전 2〉 §2.6 자리 2: *part 2-8의 사후 결말 폭로*만 노출되고 *2-6·2-7의 결말 과정은 결번 안에 봉인*. *결말의 정서적 폭력만 노출, 과정은 결번에 봉인*.
  - 〈귀하〉 §4: *위반 결과는 거의 전면 부재 + 부분 암시*. *왜 그 수치인지, 체류 시간 소진 시 무엇이 일어나는지*는 *완전 부재*. *모호함의 디폴트로 정보 표적을 분포*.
  - 〈암흑색맹〉 §4: *최초의 암흑색맹과 네 마디 이상 대화하지 말랬는데*의 *위반 결과가 명시 직전에 회피*. *유예 시간 3분 20초*에 가까운 *위반의 시간 한계*만 명시.
  - 〈탈출작전 3〉 §4: *명시적 규칙·금기 0개* + *case 번호 점프(3-3·3-4·3-6·3-7·3-9·3-10 부재)*가 *위반·미응답 학생의 운명을 결번으로 봉인*. *부재가 곧 결과인 형식*.
- **변주의 범위**:
  - *우회 매체의 종류*: 사이드 단편(탈출작전 1) / 지문 음향 매체(탈출작전 2) / 시간 데이터 미세 갱신(귀하) / 활자 축소 하강(암흑색맹) / 결번 비기재(탈출작전 3)
  - *우회의 양*: 〈탈출작전 3〉이 *가장 완전한 우회*(규칙 0개·결번 다수·발췌자만), 〈탈출작전 1〉이 *가장 명시적 우회*(사이드 1회에 결과 압축)
- **기능**: *모호함의 디폴트* 미학을 *작품마다 다른 매체*로 실현. *대응 지침 표준*의 *부분 검열 한정* 원칙이 *시리즈 차원의 다양한 도구함*으로 구체화.

### 2.8. *작품 시간 ↔ 읽기 시간의 비대칭 설계*

- **정의**: 작품 내부의 시간(작전 시간·체류 시간·시각 스탬프)과 독자의 읽기 시간 사이에 *의도적 비대칭*이 설계되어, 비대칭 자체가 *호흡·정점·잔존감*의 도구가 됨.
- **출현 작품**:

  - 〈암흑색맹〉 §3: *마경 내부의 30분 + α*가 *수십 분 읽기*로 확장. *생략점 활자 축소 하강*이 *독자 읽기 속도를 강제로 늦추는 자리*.
  - 〈탈출작전 1〉 §3: *작품 내 41분(18:23→19:04)이 약 4,500자로 압축*. *발췌본의 결번이 시간 압축을 더 강화*.

- **변주의 범위**:
  - *압축 vs 확장*: 〈귀하〉·〈암흑색맹〉은 *작품 시간 < 읽기 시간*(확장), 〈탈출작전 1·2〉는 *작품 시간 > 읽기 시간*(압축), 〈탈출작전 3〉은 *읽기 후 잔존 검토 시간*(잔여).

## §3. 시리즈 차원의 새 발견

### 3.1. *처리반의 4대 부서명*이 시리즈 작품들에서 *위계적으로 노출·은닉*되는 자리

5작품을 합쳐 보면 *초자연현상처리반의 부서 명단*이 *각 작품마다 부분적으로 노출*되며 *전체 명단은 어느 한 작품에도 없음*이 발견된다. 〈암흑색맹〉의 0막 브리핑에서 *대응제거적출 1·2·5·10·11·12팀 / 관측기록사무 6·11팀 / 구출처리복원 8·12팀 / 예측예지예언 6팀 / 고난부활승천 3팀*이 *팀 번호 명시*로 노출되고, 〈탈출작전 1〉에서 *대응제거적출 2팀(김경수)·관측기록사무 2팀(성혜령)·구출처리복원 1팀(고대석·성시문)*이 등장하며, 〈탈출작전 2〉에서 *관측기록사무 1팀(양미옥)*이 추가되고, 〈탈출작전 3〉에서는 *부서 명칭 자체가 본문에서 사라진다*. 즉 시리즈 차원에서 *부서 명단은 작품마다 부분 노출되며, 그 부분 노출의 합산이 시리즈의 조직체 윤곽을 형성*한다 — 동시에 *고난부활승천 3팀*만은 〈암흑색맹〉의 *종교적 외부 권능*으로 단독 등장하고 다른 작품에는 부재 — *부서의 위계가 작품 출현 빈도와 일치*하는 자리(대응제거적출·관측기록사무는 빈출, 구출처리복원은 중간, 예측예지예언·고난부활승천은 단일 출현)가 *부서의 *세속/종교 위계*를 시리즈 차원에서 함의*.

### 3.2. *각 작품의 매체 단위가 시리즈 작품 5편을 하나의 *처리반 작전 기록 아카이브*로 묶는 자리*

각 작품의 매체를 시리즈 차원에서 재배열하면 *처리반의 가상 아카이브*가 드러난다: 〈귀하〉=*시민 배포용 매뉴얼 (사상체별 대응 지침서)* / 〈암흑색맹〉=*작전 보고 + 1인칭 회상록 (현장 기록 + 인사 기록)* / 〈탈출작전 1〉=*통신 대화록 (현장 통신 보관)* / 〈탈출작전 2〉=*분산 다시점 대본 (사고 재구성 자료)* / 〈탈출작전 3〉=*답안지 발췌 + Retrieve 표기 (잔존 사료)*. 5편이 합쳐지면 *조직의 5종 문서 매체*가 한 옴니버스로 완결된다 — *지침서 → 작전 기록 → 통신 → 사고 재구성 → 잔존 사료*의 *문서 위계의 점진 하향*(공식성 ↓, 잔여성 ↑)이 시리즈 진화의 한 축을 형성. 이 발견은 *한 작품만 볼 때는 보이지 않고 5편의 매체를 한 줄로 세울 때만 보임*.

### 3.3. *시각 시스템*의 시리즈 횡단 일관성과 *2020년 12월 11일*의 단일 일자 집중

한국총력고등학교 시퀀스 3편의 *모든 시각 스탬프*가 *2020.12.11.* 단일 일자에 집중되어 있고, 시간만 *18:23 → 18:58 → 19:32 → 19:34 → 19:48 → 19:50 → 20:06*로 흐른다 (탈출작전 1=18:23 재해대피문자, 탈출작전 2=18:58 작전 시작·19:32 경계 해제·19:34 Remove 2, 탈출작전 3=19:48 실종신고·20:06 통신 없음). 즉 *시퀀스 3편이 1시간 43분의 동일 작전일을 분할 점유*. 단일 일자의 *시각 정밀성*이 *시퀀스의 회차 = 같은 날의 다른 시간 슬롯*임을 환기. 한편 〈암흑색맹〉은 *2023. 05. 22.*로 별도 일자(*최초의 암흑색맹 소탕*)이며, 〈귀하〉는 *일자 무명시*. *시퀀스 = 단일 일자 분할 점유*가 *옴니버스 결합 유형의 결정적 표지*임이 시리즈 횡단으로만 보임.

### 3.4. *답안체·매뉴얼체·대본체·통신로그체·산문체*의 *5종 매체체*가 *처리반이 가진 표현 어휘의 시리즈 차원 도구함*임이 드러나는 자리

각 작품이 *서로 다른 매체체*를 *주력 채택*한다: 〈귀하〉=매뉴얼체 / 〈암흑색맹〉=산문체(회상록) / 〈탈출작전 1〉=통신로그·대화록 / 〈탈출작전 2〉=대본체(분산 다시점) / 〈탈출작전 3〉=답안체. *5작품 = 5종 매체체의 단일 매핑*. 이는 *작가가 한 매체체에 정착하지 않고 시리즈를 매체 실험의 장으로 사용*하는 자리이며, *처리반이라는 조직체가 표현할 수 있는 매체의 범위*를 *시리즈가 옴니버스로 시연*. 새 작품이 추가될 때마다 *기존 작품과 다른 매체체*가 채택될 가능성이 높음을 시리즈 차원에서 시사 — *옴니버스의 진화 동력이 *매체 다양화*에 위치*.

### 3.5. *공식 권위의 *외부 위장 → 내부 분열 → 외부 단절*의 3단 진화*

시리즈 5편을 *공식 권위의 신뢰성 양태*로 재배열하면 점진 곡선이 보인다:
- 〈귀하〉=공식 권위의 *외부 표층은 정직, 내부 작동은 모호*(*당사*가 카지노 관계자에게도 같은 매뉴얼 제공)
- 〈암흑색맹〉=공식 권위의 *내부 분열*(예측예지예언 6팀이 대응제거적출 11팀을 기만)
- 〈탈출작전 1〉=공식 권위의 *정직하나 한계*(처리반이 학교에 우위 없음)
- 〈탈출작전 2〉=공식 권위의 *외부 적측에 의한 위장 전유*(학교가 행정부 명의 모방) + *내부 명령 체계 항복*(통신 꺼! 생목 명령!)
- 〈탈출작전 3〉=공식 권위의 *외부 단절*(통신 없음) + *발신 주체가 외부 적측으로 전환*(학교 교장 명의 실종신고)

이 *5단 곡선*은 한 작품에서는 보이지 않고 *시리즈 횡단*에서만 드러난다. *처리반이라는 조직체의 권위가 시리즈 옴니버스 안에서 점진적으로 무너지는 자리*가 *작품 진화의 한 축*. 이는 *시퀀스 4편의 사후 후속 회수*와 결합할 때 *처리반 자체가 아카이브 잔존물로 변하는 결말*의 가능성까지 시사.

변주의 또 다른 자리: *장르 비율의 작품별 지배 장르*가 모두 다름 — 규칙괴담(귀하·탈출작전 1) / 격리픽션(탈출작전 2) / 나폴리탄(탈출작전 3) / 서사 장편(암흑색맹). *시리즈가 한 장르에 정착하지 않고 *5작품 = 5종 지배 장르의 단일 매핑*에 가까운 구성*을 가짐. 이는 *옴니버스 결합 유형의 *층위형 + 반향형*에 가까운 자리*임을 변주가 사후 환기.

## §5. 시리즈 진화·인물 누적·세계관 두께 (보조)

### 5.1. 시리즈 진화

발표 순서는 *식별 부분 가능*. 한국총력고등학교 시퀀스의 *part 번호*가 명시되어 있어 시퀀스 내부 순서는 *탈출작전 1 → 2 → 3*이 명확 (시각 스탬프 18:23 → 18:58 → 19:48의 작품 내 시간 순). 단 〈귀하〉와 〈암흑색맹〉의 시퀀스 외 발표 시점은 *식별 불가*. 〈암흑색맹〉이 *2023.05.22.* 작전일이고 한국총력고등학교 시퀀스가 *2020.12.11.* 작전일임에서, *작중 시간 순*은 *한국총력고등학교 → 암흑색맹*이나 *발표 순*은 *불명*. 〈귀하〉는 작중 시간 자체가 무명시.

시퀀스 3편의 매체 진화는 *명료*: *통신 대화록(1편) → 분산 다시점 대본 + Remove 사이드(2편) → 답안지 발췌 + Retrieve(3편)*. *통신 → 대본 → 잔존 사료*의 *공식성 점진 하향*. 후속 회차(탈출작전 4·모의고사 1~2·타임라인)가 시퀀스 내부에서 사후 회수되는 구조이나 본 분석 자료에서는 접근 불가 — *후속 회차에서 매체가 어떻게 더 진화하는지*는 추가 분석 필요.

### 5.2. 인물 누적

시리즈 내 *공유 인물·부서*가 한국총력고등학교 시퀀스에 집중. *대응제거적출 2팀 김경수*는 〈탈출작전 1·2〉의 *Remove 사이드*에 공통 등장(*인간/이물 사살 기준*과 *통신 꺼! 생목 명령!*의 두 자리). *관측기록사무 2팀 성혜령*도 〈탈출작전 1·2〉에 공통 등장. *대응제거적출 3팀*은 〈탈출작전 2〉의 *별관 작전 본팀*이며 *사망자 구혜민*이 명시. *고대석·성시문(구출처리복원 1팀)*은 〈탈출작전 1〉의 1편·1-2편에 각각 직원으로 등장.

누적 효과: *김경수의 두 차례 출현*에서 *첫 출현(탈출작전 1)은 비정한 실무 진술*(*둘 다 쏘면 됨*), *두 번째 출현(탈출작전 2)은 통제 항복*(*씨발! 통신 꺼!*) — *조직 권위자의 점진적 한계 노출*이 *동일 인물의 두 자리에서 누적*. *최일훈*(탈출작전 1, *1972년 입학·실종된 전교 1등*)이 시퀀스 내부의 *학교 동화 인물 사례*로 명시되며, 〈탈출작전 3〉의 *case 3-11 정자체 학생*과 *시리즈 차원의 동화 패턴*을 형성. 독립 옴니버스 2편(〈귀하〉·〈암흑색맹〉)과의 *인물 공유는 부재* — 시퀀스와 독립 옴니버스 간 인물 경계가 분리.

### 5.3. 세계관 두께

작품들 사이의 *빈자리에서 함의되는* 세계관:
- *처리반의 부서 위계*가 §3.1에서 정리한 *세속/종교 위계*(대응제거적출·관측기록사무·구출처리복원=세속 빈출 / 예측예지예언·고난부활승천=종교적 외부 권능)로 시리즈 횡단에서 함의.
- *작전일 단일 일자 집중*(시퀀스 3편 모두 2020.12.11.)이 *한국총력고등학교 사건이 단일 일자 안에서 옴니버스로 확장된 사건*임을 시사. *다른 사상체 사건*(암흑색맹 2023.05.22.)은 *별도 일자*로 분리.
- *최일훈의 1972년 입학*이 *학교가 한자 종결 마커 (終)이 어울리는 시간성*에 속함을 명시 — *학교의 시간이 현대보다 오래된 자리*가 *48년 누적 시간*으로 환기.
- *시민·국민을 향한 외부 공식 발신(재난문자·실종신고)*이 시리즈 차원에서 *행정안전부 ↔ 학교 측 ↔ 처리반*의 *3자 발신 경합*을 형성. *시민 측에서 보이는 외부 발신의 진실성*이 *시리즈 차원의 함의 자리*.

### 5.4. 옴니버스 결합 유형

**주력 = 층위형 + 반향형 / 보조 = 누적형**

- **층위형**(주력 1): 5작품이 *서로 다른 매체체·시점·등급*의 층위로 묶임. *지침서(귀하) / 작전 기록(암흑색맹) / 통신(탈출작전 1) / 사고 재구성(탈출작전 2) / 잔존 사료(탈출작전 3)*가 *조직체의 5종 문서 매체* 층위. *§3.4의 5종 매체체 매핑*과 정합.
- **반향형**(주력 2): 작품들이 *서로를 암묵 참조*하지 않으면서도 *함께 읽어야 *공식 권위의 진화 곡선·부서 명단·매체체 도구함*이 보임*. *한 작품만 보면 옴니버스의 깊이가 보이지 않음*. §3.1~§3.5의 5개 *시리즈 차원 새 발견*이 모두 *반향형의 산물*.
- **누적형**(보조): *한국총력고등학교 시퀀스 3편*에 한정해서는 *시간순·심도순 누적*이 성립(*동일 일자 1시간 43분 분할 + 매체의 공식성 점진 하향*). 단 *시리즈 전체*가 누적형은 아님.
- **독립형**(부재): 5작품 어느 것도 *완전 독립*은 아님. *처리반이라는 조직체*가 모든 작품에 *명시적·암시적으로* 침투.

## §6. 대응 지침 설계 표준 보강 시사 — 통합과 신설

### 6.1. 통합·중복 제거된 시사

- **시사 1 — *조건 분기 라벨·회차 코드·case 번호*에 의한 *제3의 막 전환 방식***: 작품별 §7 시사 1(귀하 — 조건 분기 라벨) + 작품별 §7 시사 4(탈출작전 1 — 시리얼 회차 종결자) + 작품별 §7 시사 2(탈출작전 2 — 결번 비율) + 작품별 §7 시사 2(탈출작전 3 — 비균등 번호 점프)를 통합. 표준의 *4막 구조*와 *번호 체계* 부분이 *번호 차수 노출 vs 상황 전제 변화*의 이분에 머물 때, 시리즈는 *조건 분기 라벨 + 시리얼 회차 코드 + case 번호 + (終) 한자 종결 마커 + 결번 점프*의 *5종 막 전환 도구함*을 시연 가능. 근거: §2.1, §2.6, §2.7의 시리즈 공통 패턴.

- **시사 2 — *부분 검열의 *결정적 위치 설계*와 *번호 음각 사용***: 작품별 §7 시사 2(귀하 — 검열 한 행의 위치) + 작품별 §7 시사 5(탈출작전 1 — 시점 절단을 통한 역방향 노출) + 작품별 §7 시사 7(탈출작전 3 — 자발적 비기재)를 통합. 표준의 *부분 검열 한정* 원칙이 *부분 검열만 허용*을 규정할 때, 시리즈는 *(a) 결정적 정보 두 자리 중 하나에 검열 박기 / (b) 시점 절단으로 본 진행 정보를 역방향 노출 / (c) 답하지 않은 자리가 검열과 동일 효과 / (d) 번호 결번·점프의 음각 사용*의 *4종 부분 검열 도구함*을 시연. 근거: §2.5, §2.6의 시리즈 공통 패턴.

- **시사 3 — *호명체·보고체·비격식체의 3축 교차와 *답안체·통신 약어체*의 제3·제4 어법***: 작품별 §7 시사 5(귀하 — 비대칭 교차) + 작품별 §7 시사 3(탈출작전 1 — 상호 호명) + 작품별 §7 시사 3(탈출작전 3 — 답안체·기록체·명부체) + 작품별 §7 시사 4(탈출작전 2 — 문장부호로 시점 표지)를 통합. 표준의 *호명체와 보고체의 교차 사용*이 *2축 교차*에 머물 때, 시리즈는 *(a) 3축 교차(호명+보고+비격식) / (b) 답안체·통신 약어체의 제3·제4 어법 / (c) 문장부호(대시 vs 따옴표)로 시점·정체성 표지 / (d) 호명의 비대칭(귀하 ↔ 누나)*의 *4종 시점 모듈 도구함*을 시연. 근거: §2.3의 시리즈 공통 패턴.

- **시사 4 — *모호함의 디폴트*가 *결과 명시 부재 + 사이드 우회 + 시간 미세 갱신 + 결번 봉인*으로 다양화**: 작품별 §7 시사 6(귀하 — 분기 간 모순 비해소) + 작품별 §7 시사 7(귀하 — 시간 데이터 미세 갱신) + 작품별 §7 시사 1(탈출작전 1 — 사이드의 책임 분담) + 작품별 §7 시사 6(탈출작전 2 — 음향 리듬) + 작품별 §7 시사 1(탈출작전 3 — 외부 참조 매체)를 통합. 표준의 *모호함의 디폴트*가 *명료/모호 사이 디폴트 선택*에 머물 때, 시리즈는 *결과 명시의 우회를 매체별로 다양화한 도구함*을 시연 — 사이드 단편 / 지문 음향 매체 / 시간 데이터 미세 갱신 / 활자 축소 하강 / 결번 비기재 / 외부 참조 매체(시험지 이미지 외부화). 근거: §2.4, §2.8의 시리즈 공통 패턴.

- **시사 5 — *행정 양식이 곧 서사 양식인 형식=서사 등식과 그 *적측 위장 전유* 가능성***: 작품별 §7 시사 5(암흑색맹 — 행정 보고서가 정점 봉인) + 작품별 §7 시사 6(암흑색맹 — 도상의 행정 위장) + 작품별 §7 시사 6(탈출작전 2 — 공식 발신체의 적측 위장) + 작품별 §7 시사 1(탈출작전 2 — 대본 매체)을 통합. 표준의 *형식 위장* 원칙이 *서사 구조의 노출 방지*에 한정될 때, 시리즈는 *(a) 행정 양식이 곧 서사 양식이 되는 형식=서사 등식 / (b) 그 양식의 정점 봉인 효과 / (c) 그 양식의 적측 위장 전유 가능성 / (d) 도상의 행정 위장*의 *4단 도구함*을 시연. 노스포비아 미학(표면/본질 이중 구조)과 깊은 정합. 근거: §2.1, §2.2의 시리즈 공통 패턴.

### 6.2. 시리즈 차원의 새 시사

- **시사 6 — *부서명의 위계적 노출·은닉*을 통한 *조직체 외형의 옴니버스 구성***: 시리즈 차원에서 처음 발견. 처리반의 4대 부서명이 *작품마다 부분 노출되며 전체 명단은 어느 한 작품에도 없음*이 시리즈 횡단으로만 보임(§3.1). 표준의 *APMB 4대 부서명*이 *고정 명단*으로 제시될 때, 시리즈는 *부서명의 위계가 작품 출현 빈도와 일치하며 *세속/종교 위계*를 함의*하는 자리를 시연. *부서 명단이 옴니버스 차원에서만 완성되는* 도구는 *사상체 문서·대응 지침*에서도 *복수 문서의 부분 명단 합산*으로 활용 가능. 근거: §3.1의 시리즈 차원 새 발견.

- **시사 7 — *옴니버스 5작품 = 5종 매체체의 단일 매핑*과 *공식성 점진 하향 곡선***: 시리즈 차원에서 처음 발견. 시리즈가 *한 매체체에 정착하지 않고 옴니버스 = 매체 실험의 장*으로 작동(§3.4). 시퀀스 내부에서는 *통신 → 대본 → 답안지*의 *공식성 점진 하향*까지 시연(§3.2). 표준의 *유동 분량* 원칙이 *분량의 자유*에 한정될 때, 시리즈는 *매체체의 자유 + 공식성 양태의 자유*까지 확장되어야 함을 시사. 사상체 문서 시리즈를 설계할 때 *작품마다 다른 매체체*를 의도적으로 채택하는 자리. 근거: §3.2, §3.4의 시리즈 차원 새 발견.

- **시사 8 — *공식 권위의 *외부 위장 → 내부 분열 → 외부 단절*의 5단 진화 곡선***: 시리즈 차원에서 처음 발견. 5작품의 *공식 권위 신뢰성*이 *외부 표층 정직(귀하) → 내부 분열(암흑색맹) → 정직하나 한계(탈출작전 1) → 외부 위장 전유 + 내부 항복(탈출작전 2) → 외부 단절(탈출작전 3)*의 곡선(§3.5). 표준의 *APMB 공식 권위*가 *전제로 제시*될 때, 시리즈는 *그 권위가 옴니버스 안에서 점진 무너지는 가능성*을 시연. 노스포비아 미학(*친근한 호스트가 균열에서 무엇이 되는가*)과 정합. 사상체 문서들의 *시리즈 횡단 권위 변동*을 의도적으로 설계하는 자리. 근거: §3.5의 시리즈 차원 새 발견.

- **시사 9 — *작전일 단일 일자 집중*을 통한 *시퀀스 결합의 시간 표지***: 시리즈 차원에서 처음 발견. 한국총력고등학교 시퀀스 3편이 *2020.12.11.* 단일 일자에 *18:23 → 20:06의 1시간 43분 분할*로 집중(§3.3). 표준의 *시간 처리*가 *시제·시간차 효과*에 머물 때, 시리즈는 *시퀀스의 옴니버스 결합 = 단일 일자의 시각 슬롯 분할*이라는 구조적 시간 표지를 시연. *시각 정밀성*이 *시퀀스 결합 유형의 표지*로 기능. 사상체 문서들의 *시간 관계*를 *시각 스탬프의 분할 점유*로 설계하는 자리. 근거: §3.3의 시리즈 차원 새 발견.

- **시사 10 — *외부 권능/외부 시점 사이드의 *Remove/Retrieve* 명명 자체가 외부의 행동 양태를 표지***: 시리즈 차원에서 처음 발견. 〈탈출작전 1·2〉의 *Remove*(제거·체계 분리)와 〈탈출작전 3〉의 *Retrieve*(회수)가 *명명만으로 외부의 행동 양태*를 표지(§2.9). 표준의 *사이드 끼임*이 *연동 유형(독립형/보강형/분기형)*에 머물 때, 시리즈는 *사이드의 *영문 명명 자체가 외부의 양태 분기*가 되는* 자리를 시연. 사상체 문서의 *외부 시점 사이드*에 *명명 차원의 양태 표지*를 추가하는 자리. 근거: §2.9의 시리즈 공통 패턴.

## §7. 자유 관찰란 — 통합 시점의 발견

- **관찰 1 — *짧은 단편 4편 + 장편 1편의 비대칭 옴니버스***: 〈암흑색맹〉(40,214자) 1편이 *시리즈 분량의 80%*를 단독 점유. 나머지 4편의 합계가 *10,900자*로 *전체의 20%*에 불과. 시리즈는 *장편 1 + 단편 4의 비대칭 옴니버스* 형태이며, *장편이 시리즈의 *서사적 척추*를 담당*하고 *단편이 *매체 실험의 다발*을 담당*하는 *역할 분담*이 통합 시점에 가시화. 분량 비대칭이 *옴니버스의 자유*를 *단편 차원에서 최대화*하는 자리.

- **관찰 2 — *한국총력고등학교 시퀀스가 *현재진행형 미완 사건*임이 시리즈 횡단으로만 보이는 자리***: 〈탈출작전 1〉의 *옥상 봉쇄 미완 종결*, 〈탈출작전 2〉의 *통신 차단 항복*, 〈탈출작전 3〉의 *통신 없음 + 학교 측 실종신고 발신*이 *시퀀스 3편 모두 미완 종결*. 시퀀스 외부에서 *후속 회차(탈출작전 4·모의고사 1~2·타임라인)*가 *사후 회수 자료*로 명시되나 본 분석 자료에서는 접근 불가 — 즉 *시퀀스 자체가 미완성 상태*이며, *시리즈 통합 시점에 *미완성 옴니버스*임이 드러남*. *후속 분석 단계(2단 시리즈 횡단 종합)에서 후속 회차 확인 필요*가 본 통합의 산물.

- **관찰 3 — *욕설(*씨발*)이 시리즈에서 *조직 권위의 한계 지점*에 일관 출현***: *씨발*이 시리즈 5편 중 4편에 등장(〈귀하〉만 부재). 〈암흑색맹〉의 *퇴사! 퇴사해, 씨발!*(외부 권능 호출 트리거), 〈탈출작전 1〉의 *씨발*(학생 구어체 진입), 〈탈출작전 2〉의 *씨발! 통신 꺼!*(통제 항복 명령), 〈탈출작전 3〉의 *씨발 난 이딴 거 안 배웠어 좆까*(case 3-2 불응 답안). *씨발의 출현 자리*가 모두 *조직 권위가 한계에 도달한 자리*이며, *시리즈 차원에서 *욕설이 권위 한계의 표지*로 기능*함이 통합 시점에 발견. 〈귀하〉만 부재한 이유는 *매뉴얼체 단층 + 화자가 익명 조직체*이므로 *비격식 화자가 등장하지 않기 때문*. *욕설의 유무 자체가 매체체의 자리*를 환기.

## §8. 메타 — 통합의 한계

- **분석 자료의 분석 깊이가 균질하지 않음**: 분석 자료 5개의 분량 자체가 균질하지 않다 (〈암흑색맹〉 분석 자료가 가장 깊은 §2.6 결정적 자리 3개·§7 시사 7개를 갖는 반면, 〈탈출작전 3〉 분석 자료는 *1,200자 원작*의 한계로 §2.6 자리·§7 시사가 상대적으로 짧음). 본 통합에서 *공통 패턴 추출 시 분량이 큰 작품의 자리가 *더 자주 인용*되는 편향*이 발생. 특히 §2.3(*호명체 ↔ 보고체 ↔ 비격식체의 3축 교차*) 및 §2.4(*위반 결과의 우회 시연*)에서 〈암흑색맹〉의 자리가 다른 작품보다 *대표 사례로 더 자주 호출*됨.

- **원작품 부재로 검증 불가능한 자리**:
  - 〈탈출작전 1〉의 *발췌본 결번 9개*(1-3·1-5~1-6·1-8~1-14·1-16~1-19)의 *원작 내용*은 본 통합에서 검증 불가. *결번이 발췌자 차원인지 작가 차원인지*가 §2.6의 *작가 vs 발췌자 결번* 변주에 영향.
  - 〈탈출작전 2〉의 *결번 9개*(2-1·2-2·2-3·2-6·2-7·2-9·2-11·2-12·2-13)의 *내용 추정*도 본 분석에서 불가. *3개 페어의 결말 과정*이 결번 안에 봉인되어 *§2.4(위반 결과 우회 시연)*의 사례 추가 검증 불가.
  - 〈탈출작전 3〉의 *모의고사 시험지 이미지 2장*이 본 분석에서 접근 불가. *질문 부재 + 답만 잔존*의 매체 비대칭이 *학생들의 응답 패턴 해석*에 영향. *질문이 무엇이었는지*가 §2.10(*육체의 매개화·도구화*)의 시사적 패턴 확장 가능성에 영향.
  - 시퀀스의 *후속 회차*(탈출작전 4·모의고사 1~2·타임라인)는 본 통합에서 접근 불가. §3.5의 *공식 권위 5단 곡선*의 *6단 이후 양태*가 후속 회차로 회수될 가능성이 시리즈 횡단 종합 단계에서 추가 검토 필요.

- **시리즈 작품 수의 부족으로 인한 과대 일반화 위험**:
  - **5작품 = 5종 매체체 매핑(§3.4)**: 5작품만으로 *작가가 한 매체체에 정착하지 않음*을 *시리즈 본질*로 단정하는 것은 *과대 일반화 위험*. 후속 회차 6편 이상(탈출작전 4 + 모의고사 1~2 + 타임라인) 추가 시 *중복 매체체 출현 가능성*도 존재. *시사적 패턴*으로 한정.
  - **공식 권위 5단 곡선(§3.5)**: 5작품의 *권위 양태*를 *진화 곡선*으로 해석하나, *발표 순서가 시간 순과 일치하는지 확정 불가* — *시간 순이 발표 순이 아니라면* 곡선의 *진화* 해석이 *작가의 시간 배치 의도*가 아닐 수 있음. *해석적 추론*임을 명시.
  - **검열 자리 설계(§2.5)**: 2/5 작품에만 출현하므로 *시리즈 본질*로 단정하지 않고 *시사적 패턴*으로 명명(§2.5 본문에 명시).
  - **육체의 매개화·도구화(§2.10)**: 2/5 작품에만 출현하므로 *시사적 패턴*으로 명명(§2.10 본문에 명시).

- **시퀀스와 독립 옴니버스의 *통합 가능성* 자체에 대한 자기 검토**: 본 통합은 *〈초자연현상처리반〉 시리즈 전체*(독립 옴니버스 2 + 시퀀스 3 = 5작품)를 *하나의 시리즈*로 통합. 그러나 *독립 옴니버스와 시퀀스가 *동일한 옴니버스 결합 양태에 속하는가*는 별도 검토 필요* — 본 통합에서 §5.4의 *주력 = 층위형 + 반향형 / 보조 = 누적형*은 시리즈 전체에 *층위형·반향형 적용 + 시퀀스 한정 누적형 적용*의 *복합 결합 유형*으로 정리. 단 *독립 옴니버스 2편과 시퀀스 3편을 *완전히 별도 옴니버스로 분리*하는 분석 단위 분해*도 후속 단계에서 가능성으로 남김.
