# 관리국 세부사항 레지스트리

본 문서는 웹사이트 콘텐츠 작성 과정에서 *등장한 모든 세부 디테일*을 일관성 유지를 위해 기록한다.

## 본 문서의 역할

- 동일한 인명·시설·사건이 *여러 페이지*에 등장할 때 같은 형태로 일관되게 나타나도록 보장
- 검열 패턴의 일관성 유지 (예: 같은 인명이 한 페이지에서 검열됐다면 다른 페이지에서도 같은 식으로 검열)
- 새 페이지 작성 시 *기존에 등장한 디테일*을 재활용함으로써 세계관의 살아있음 강화

## 갱신 원칙

- 새 페이지를 작성할 때 *새 디테일*(인명·시설·사건 등)이 등장하면 해당 세션 종료 전 본 문서에 등록
- *기존에 등록된 디테일*을 새 페이지에서 사용할 때 검열 형태와 명칭을 일관되게 유지
- 디테일 등록 시 *어느 페이지에서 어떻게 검열됐는지*도 함께 기록

## 검열 패턴 표기법

본 레지스트리에서 검열 패턴을 기록할 때 다음 표기를 사용:

- `박█████` — 4글자 검열 (성은 노출, 이름 4자 검열)
- `█████` — 5글자 전체 검열
- `[데이터 말소]` — 블록 단위 검열
- `2018-██-██` — 연도 노출, 월일 검열
