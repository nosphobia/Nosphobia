# 디자인 레퍼런스 카테고리 확정본

본 문서는 노스포비아 웹사이트의 디자인 작업에 사용할 외부 레퍼런스 자료를 카테고리별로 정리한다. 이 카테고리들은 *디자인 톤·구조·연출의 영감 원천*이며, mockup 제작 단계에서 LLM(예: Claude Code)에게 디자인 가이드로 제공된다.

- 디자인 *모순 공략 4원칙* (retro 시그널 + 현대 가독성)
- 다음 단계(사이트 구조 확정 → mockup)에서의 활용 계획

## 1. 카테고리 구조

### 1.1. 기능 분담

본 디자인 레퍼런스는 다음 3개 카테고리 + 1개 독립 자료로 구성된다.

| 번호 | 카테고리 | 기능 | 사이트의 어느 자리에 쓰는가 |
|---|---|---|---|
| **1번** | 실제 정부·공공 기관 사이트 | 디자인 톤의 토대 | 사이트 전체 (특히 구조 페이지) |
| **—** | SCP 재단 (독립 자료) | 구조·UX·시스템 벤치마크 | 사상체 문서 / 분류 체계 등 기능 단위 |
| **2번** | 아날로그/디지털 호러 ARG | 호러 연출 자리의 시각·연출 영감 | 인트로 / 404 / 접근 거부 / 마찰점 |
| **3번** | 2000년대 레트로 웹 미학 | 시대감의 보조 | 컬러·타이포·레이아웃의 부분 디테일 |

### 1.2. 카테고리 간 우선순위

- **1번 카테고리**가 디자인의 90%를 결정한다. 톤·구조·페이지 위계의 토대.
- **SCP 재단**은 별도 자료로 두고, 사이트 구조 확정 단계에서 1번과 비교 분석하여 시스템 구조(분류·검열·문서 양식 등)에 직접 활용.
- **3번 카테고리**는 1번 위에 *얹는 시대감*. 단독으로 쓰면 향수적이 되므로 1번과 섞어 사용.
- **2번 카테고리**는 후순위. 사이트 골격이 완성된 *후*에 호러 연출 자리에 적용.

### 1.3. 카테고리 가짓수 결정의 근거

처음 4개 카테고리(실제 정부 사이트 / SCP 재단 계열 / 아날로그 호러 ARG / 2000년대 레트로 웹)로 출발했으나, 논의 과정에서:

1. SCP 재단을 *카테고리*로 두면 1번과 디자인적 결이 겹쳐 카테고리의 기능적 차별점이 사라짐.
2. SCP 재단은 *디자인 레퍼런스*가 아니라 *구조·UX·시스템 벤치마크*로서의 역할이 명확함.

따라서 SCP 재단은 카테고리에서 분리하여 *독립 자료*로 두고, 카테고리는 3개로 재정렬했다 (이전 3번 → 새 2번, 이전 4번 → 새 3번).

## 2. 1번 카테고리 — 실제 정부·공공 기관 사이트

**기능**: 디자인 톤의 토대. 사이트 전체(특히 구조 페이지)가 *진짜 정부 같다*는 인상을 만드는 시각 표준의 모델.

### 2.1. 확정 후보 3선

#### ① 일본 외무성 (MOFA)
**URL**: https://www.mofa.go.jp/

표준 일본 정부 인트라넷의 정수. 좌측 카테고리 트리 + 정중앙 뉴스 슬라이드 + 우측 사이드 링크, 상단의 *글자 크기 조절(S/M/L)* 및 *FAQ·사이트맵·Links* 메뉴까지 — 노스포비아 사이트의 "표면" 디자인이 90% 여기에서 온다. 무게중심이 *제도적 디테일*에 실린 사이트라 노골적 호러 감각 없이도 충분히 음울하게 보이는 점이 핵심.

**봐야 할 페이지**: 메인 페이지 / 사이트맵 / About Us > 조직 구성

#### ② 일본 후생노동성 (MHLW)
**URL**: https://www.mhlw.go.jp/

감염병·검역·약물·정신건강 등 *위해 관리*를 본업으로 하는 기관이라, **사이트 톤 자체가 호러 친화적**. "이상 보고", "감염 확산 지도", "검역소 안내" 같은 페이지가 자연스럽게 존재함. 접근 거부 페이지나 사상체 대응 지침 페이지의 직접 영감.

**봐야 할 페이지**: 메인 / 감염병 정보 / 건강·의료

#### ③ 한국 국가법령정보센터
**URL**: https://www.law.go.kr/

한국어 정부 문서의 *시각 양식*. 좌측 트리 + 법령 본문 양식 + 조문 번호 + 부칙 + 시행일 표기 — 보안 서약서, 설립 근거 법령 페이지의 직접 양식 모델. 한국 정부 사이트 특유의 *낮은 채도 + 좁은 행간 + 명조체 본문* 톤. 한국 법령 시스템이 일본 시스템을 모태로 하므로 ①, ②와 톤 호환.

### 2.2. 사용자 선호의 시그널

1번 카테고리 후보 평가에서 사용자는 *원자력 규제 톤(NRA, NRC)*은 비선호, *표준 행정·법령 톤*은 선호. 이는 다음 결을 함의한다:

> 사용자는 *기관 자체가 호러스러운 사이트*보다 *건조하게 정상적인 행정 사이트*의 톤을 원함. 이는 *호러 연출 매트릭스*의 "구조 페이지는 거의 0%" 원칙과 정확히 일치.

따라서 후속 카테고리에서도 *건조한 행정 톤 > 권위적·위협적 톤*이 일관된 선호 기준.

## 3. SCP 재단 (독립 자료)

**기능**: 구조·UX·시스템의 직접 벤치마크. 디자인 레퍼런스가 아닌 *시스템 단위*에서 무엇을 빼올지의 모범 사례.

### 3.1. 주 레퍼런스

- **SCP 한국어**: https://scpko.wikidot.com/
- **SCP 영문**: https://scp-wiki.wikidot.com/

### 3.2. 빼올 시스템 단위

다음 시스템들이 노스포비아의 *기능 단위*에 직접 영감을 줄 영역:

- 사상체 문서의 *분류·메타 박스 표기*
- 검열 표기 양식 (의미를 알 수 없는 흑색 박스, `[데이터 말소]` 등)
- 식별 코드 양식
- 부서·기관·조직 페이지의 구조
- 자료실 / 사상체 일람의 목록·필터링 UI

### 3.3. 사이트 구조 확정 단계에서의 활용 계획

다음 작업 단계에서 *SCP 재단의 구조*와 *1번 카테고리(특히 일본 외무성)의 구조*를 비교 분석하여, 노스포비아 사이트의 최종 구조(좌측 트리 깊이 / 빵부스러기 / 페이지 위계 표시 등)를 확정한다.

## 4. 2번 카테고리 — 아날로그/디지털 호러 ARG (보관)

**기능**: 호러 연출 자리의 시각·연출 영감. 인트로 / 404 / 접근 거부 / 마찰점 등 *호러가 적극 노출되는 자리*에서 활용.

### 4.1. 작업 흐름상 위치

이 카테고리는 *사이트 골격이 완성된 후*에 활용한다. 호러 연출은 *마지막에 얹는 레이어*이므로 골격 단계에서 미리 결정하면 골격이 호러에 끌려갈 위험이 있음. 따라서 현재는 *후보 보관*만 한다.

### 4.2. 보관 후보 (9건)

| 후보 | 결 | 라이브 사이트 |
|---|---|---|
| **Local 58** (local58.tv) | 가상 방송국 ARG, 글리치·404 연출 | ✅ https://local58.tv/ |
| **Cicada 3301** | 음모론적 미스터리, 암호화·검열 시각 | 🔶 (아카이브) |
| **Hypnospace Outlaw** | 가상 1999년 인터넷 시뮬레이션 게임 | ❌ (게임) |
| **The Backrooms (Kane Pixels)** | 가상 연구소 Async의 문서·UI 자료 | ❌ (영상) |
| **The Mandela Catalogue** | 가상 정부 PSA, 경고 페이지 톤 | ❌ (영상) |
| **The Minerva Alliance** | 가상 정부 기관 + 이상 영상 수집 | ❌ (영상) |
| **The Monument Mythos** | 가상 미국 대통령 정부 음모론 | ❌ (영상) |
| **Mystery Flesh Pit National Park** | 가상 국립공원관리국 (컨셉 매치, 형식 비매치) | ✅ https://www.mysteryfleshpitnationalpark.com/ |
| **Hypnagogic Archive** | 가상 아카이브 기관 라이브 사이트 | ✅ https://hypnagogicarchive.neocities.org/ |

### 4.3. 자리별 활용 예시 (호러 연출 단계에서 결정)

- **인트로 / 접속 게이트**: Local 58의 부팅 시퀀스 / Cicada 3301의 암호화 톤
- **404 / 접근 거부**: Local 58의 깨진 페이지 / Cicada 3301의 검열 화면
- **사상체 문서 경고 영역**: The Mandela Catalogue의 정부 PSA 양식
- **유휴 효과**: Local 58의 글리치 / Backrooms의 노이즈

### 4.4. 주의 — Mystery Flesh Pit National Park의 한계

컨셉(가상 정부가 변칙성 관리)은 노스포비아와 거의 1:1 대응하나, **형식은 비매치**. 사이트가 본질적으로 *Tumblr 피드 / 모던 SNS 타임라인* 구조라 *2000년대 정부 인트라넷* 구조와 정면 충돌. 디자인 직접 차용은 불가하며, *컨셉의 자기 검증* 용도로만 참고.

## 5. 3번 카테고리 — 2000년대 레트로 웹 미학

**기능**: 시대감의 보조. *컬러·타이포·레이아웃 관습*의 부분 디테일을 빌려옴.

### 5.1. 카테고리의 정확한 위치

1번 카테고리가 *디자인 톤의 토대*라면, 3번은 그 위에 *얹는 시대감*. 단독으로 사용하면 향수적·노스탤지어 박물관처럼 되어 호러가 사라지므로 1번과 섞어 사용한다.

### 5.2. 확정 후보 5선

#### ① Wayback Machine — 일본 외무성 2005년경 캡처
**URL 형식**: https://web.archive.org/web/2005*/www.mofa.go.jp/

`web.archive.org` 접속 후 위 URL 입력 → 캘린더에서 2005년 캡처 클릭. 2003~2006년 사이가 시대감이 가장 짙음. 1번 카테고리의 *옛 모습*.

#### ② Wayback Machine — 한국 국세청 2005년경 캡처
**URL 형식**: https://web.archive.org/web/2005*/www.nts.go.kr/

한국어 정부 사이트의 시대감 — 명조 본문 + 굴림 메뉴 시기. 일부 캡처는 한글 폰트가 깨져있을 수 있는데, *그 자체*도 시대감의 일부 자료.

#### ③ 일본 기상청 (JMA) — 살아있는 retro
**URL**: https://www.jma.go.jp/ (영문판: https://www.jma.go.jp/jma/en/)

*재해·이상기상 정보*를 다루는 권위 기관. 1번 카테고리와 결이 호환되면서 *시대감이 더 짙음*. 좌측 트리, 표 안의 표, 그라데이션 배너, 16px 미만 본문 등 검증할 디테일이 *현재 라이브 사이트*에 그대로 남아있어 Wayback 없이도 검증 가능.

#### ④ 일본 국립공문서관 디지털 아카이브 — 컨셉 직매치
**URL**: https://www.digital.archives.go.jp/
**자매 사이트 JACAR**: https://www.jacar.go.jp/ (외무성+방위성+국립공문서관 자료 통합)

*공문서 디지털 아카이브* — 노스포비아의 *자료실 / 사상체 일람*과 기능적 컨셉이 직접 매치. 자료 검색·열람·메타데이터 표시·계층 분류 인터페이스가 *기록 관리 UI*의 직접 모델.

#### ⑤ 일본 대학 도서관 (도쿄대 도서관)
**URL**: https://www.lib.u-tokyo.ac.jp/

학술·연구 톤. 학과별 페이지 진입 시의 *서브 헤더 + 좌측 트리 + 본문* 3분할, *목록형 게시판*(공지·자료), 도서 검색 인터페이스 — 조직 구성도·부서 페이지·자료실 양식의 보조 영감.

### 5.3. 시대감 *과잉*의 위험 — 차용 가이드

빌려올 것:
- ✅ **레이아웃 관습** (좁은 단, 좌측 트리, 표 안의 표)
- ✅ **타이포** — 한국어는 명조 본문 + 굴림 메뉴 정도. 모노스페이스는 식별 코드·검열에만.
- ✅ **컬러 디테일** (그라데이션 배너의 미세함, 구분선)

빌려오지 말 것:
- ⚠️ **GIF 애니메이션** — 절대 금지. 향수로 빠지는 가장 빠른 길.
- ⚠️ **레인보우 컬러 / 형광색** — 금지. 노스포비아 톤은 *건조한 회색·남보라(`#322659`)* 기반.
- ⚠️ **이모티콘 / ASCII 아트** — 금지.

요약: *제도적 디테일*은 빌려오고, *놀이적 디테일*은 거른다.

### 5.4. 폐기된 후보와 그 이유

다음 후보들은 검토 후 폐기됨:
- **W3C** (https://www.w3.org/) — 기관의 *역사적 정체성*은 retro이나, 현재 디자인은 2015년 이후의 미니멀·반응형 톤으로 리뉴얼되어 retro 보존 실패.
- **IETF / RFC Editor** — 동일 이유로 폐기.

교훈: 카테고리 추천 시 *역사적 정체성*이 아닌 *현재 디자인 표면*을 확인할 것.

## 6. 모순 공략 4원칙 — 디자인의 핵심 전략

본 프로젝트의 디자인은 다음 모순을 공략한다:

> **표면**: *가독성 나쁜 옛날 공식 사이트* 같이 *보임* (컨셉)
> **실제**: *가독성은 현대 표준* (사용성)

이 모순을 풀지 못하면 시청자가 *진짜 정부 사이트같다*고 *느끼기 전에* 이탈한다. 시각 톤은 옛날, 본문 크기는 현대 — 이런 식의 분리가 필요.

### 6.1. 4원칙 매트릭스

| 원칙 | Retro로 가져갈 것 | 현대로 끌어올릴 것 |
|---|---|---|
| **1. 시각 시그널 vs 인터랙션** | 폰트 패밀리 (명조 본문 + 굴림 메뉴), 컬러 채도, 그라데이션 디테일 | 호버 응답, 클릭 피드백 (지연 없음), 페이지 로딩 |
| **2. 밀도 vs 간격** | 페이지에 정보가 *빽빽한 인상* | 정보 단위 사이의 *실제 간격*은 충분히 (`padding`, `line-height` 현대 표준) |
| **3. 디테일 vs 구조** | 표 안에 표, 구분선 GIF *대신 SVG로 모방*, 좌측 트리 메뉴 | 사이트맵 깊이는 적정 (3단계 이내), 빵부스러기 명확, 페이지 위계 표시 |
| **4. 어조 vs 명확성** | 관료적 건조함, 한자어, 수동태 | *어디로 가는 링크인지* / *지금 어느 페이지인지*는 시각적으로 분명하게 |

### 6.2. 핵심 룰 — 폰트 크기

진짜 2000년대 정부 사이트는 본문이 12~13px이었다. 노스포비아 사이트는 **본문 16px 이상 (한국어 본문 16~17px 권장)** 으로 한다. 시각 톤은 옛날, 본문 크기는 현대 — 모순 공략의 가장 단순한 첫 결정.

### 6.3. 호러 연출과의 관계

모순 공략은 *컨셉 보존을 위한 절충*이 아니라 *호러를 강화하는 적극적 전략*이다. 이유:

- 진짜 옛 정부 사이트는 *가독성 자체가 나빠서* 시청자가 *내용*에 도달하지 않는다. 그러면 호러 본문(사상체 문서)도 *읽히지 않은 채로 스킵*된다.
- 현대 가독성으로 옛 미학을 입히면 시청자가 *옛날 같은데 잘 읽힌다*는 미세한 이질감을 첫 단계에서 받는다. 그 이질감 자체가 *호러 연출가 일어나기 좋은 토양*.

즉 *너무 잘 읽히는 옛날 사이트*는 그 자체로 이미 *미세한 균열*의 시작이다.
