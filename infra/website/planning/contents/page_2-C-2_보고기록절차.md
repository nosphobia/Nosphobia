### 1. 보고의 적용 범위

#### 1.1. 보고 의무의 위임 근거

본 항목은 본국이 정한「초상현상관리국 직무 강령」 및 「공통 수칙」의 위임에 따라, 본국 인원 — 정규 직원 및 IG 등급 임시 인가 인원을 포함 — 의 보고 의무의 운영 절차를 정한다. 본 절차의 위반은 본국의 정해진 인사 처분 절차 또는 IG 등급 인원의 계약 재검토 절차의 사유가 될 수 있다.

#### 1.2. 보고 사항의 범위

본국 인원이 본국의 직무 수행 중에 인지한 다음의 사항은 본국에 보고하여야 합니다.

| 분류 | 보고 대상 |
|---|---|
| 변칙 현상 | 사상체로 추정되는 변칙 현상의 직접 인지·간접 인지 일체 |
| 사상체 관련 정황 | 본국이 식별한 사상체의 변칙성 발현, 격리 절차 운영 중의 예외 정황, 본국이 미식별한 사상체의 가능성을 시사하는 정황 |
| 본인의 자기 상태 변화 | 본국의 직무 수행 중·후에 본인이 인지한 인지·정신·신체 상태의 변화 |
| 본국 운영의 예외 | 본 사이트·본국 시설·본국 통신의 예상 외 양상, 본국 인원의 절차 위반 추정 정황 |
| 본인의 절차 위반 인지 | 본인이 본국의 절차를 위반한 사실을 사후 인지한 경우 |

본 보고 범위에서 *인지*라 함은, 본인의 감각·사고·기억·꿈·환각·기타 일체의 정신적 작용을 통한 인지를 포함합니다. 본 인지의 시점이 사상의 발생 시점보다 늦을 수 있음을 본 절차는 전제합니다.

#### 1.3. 보고의 자가 판단 자제

본인이 인지한 사항이 *본 보고 범위에 해당하는지에 대한 자가 판단*은 본인의 자가 판단의 영역이 아닙니다. 인지한 사항의 *보고 범위 해당 여부 판단*은 본국의 결정 영역이며, 본인은 *인지한 사항의 보고*만을 수행하십시오.

본 수칙의 결과로, *과다 보고*에 대한 본국의 인사 처분은 일반적으로 적용되지 아니합니다.

### 2. 보고의 양식

보고는 다음의 표준 양식에 따라 본국에 제출됩니다.

```
[ 보고자 ]      [본국 인원 ID / IG 등급 인원 ID]
[ 보고 일시 ]    YYYY-██-██ ██:██
[ 보고 분류 ]    [변칙 현상 / 사상체 관련 / 자기 상태 / 본국 운영 / 절차 위반]
[ 인지 시점 ]    YYYY-██-██ ██:██
[ 인지 경로 ]    [직접 인지 / 간접 인지 / 사후 인지]
[ 인지 위치 ]    [본 사이트의 페이지 / 본국 시설 / 외부]
[ 본문 ]        [인지한 사항의 객관적 기술]
[ 본인의 해석 ]  [본인이 추정하는 사상의 의미 — 강제 아님]
```

본 양식은 본국의 보고 처리 시스템의 표준 양식이며, 모든 보고는 본 양식의 *본문* 영역까지를 필수 입력으로 한다. *본인의 해석* 영역은 본인의 선택에 따라 작성하지 아니하여도 무방하다.

본 양식은 본국의 결정에 따라 갱신될 수 있다.

---

### 3. 보고의 채널

본국의 보고 채널은 다음의 두 경로로 운영된다.

#### 3.1. 본 사이트의 보고 영역

본 사이트 내에 IG 등급 인원의 보고용 단독 페이지가 운영된다. 본 페이지를 통한 보고는 본국의 보안 통제부에 *즉시 전달*되며, 본 부서의 정해진 분류 절차에 따라 처리된다.

#### 3.2. 본국의 인가한 외부 통신 경로

본 사이트의 보고 영역에 접근이 어려운 상황 — 본국의 절차 위반 정황의 인지 등 — 에 대해서는 본국이 별도로 인가한 외부 통신 경로의 사용이 허용된다. 본 경로의 상세 및 사용 조건은 본국의 결정에 따라 IG 등급 인원에게 별도 안내된다.

본국의 인가를 받지 아니한 외부 경로 — 본인의 사적 통신 수단, 외부 매체, 본국 외 일반인 — 를 통한 보고는 본국의 절차 위반에 해당하며, 본인이 본 페이지의 §1.1 보고 의무를 이행한 것으로 간주되지 아니한다.

---

### 4. 보고의 후속 처리

#### 4.1. 보고의 분류와 전달

본국의 보안 통제부는 접수된 보고를 다음의 절차로 처리한다.

```
   [본 사이트 보고]    →    [보안 통제부 접수·1차 분류]    →    [해당 부서 전달]
                                          ↓
                                  [본인 통지 결정]
```

| 단계 | 담당 | 산출물 |
|:---:|---|---|
| 1 | 보안 통제부 | 보고의 1차 분류 (긴급도·해당 부서·관련 사상체) |
| 2 | 보안 통제부 → 해당 부서 | 분류된 보고의 해당 부서 전달 |
| 3 | 해당 부서 | 본국의 절차에 따른 후속 조치 |
| 4 | 본국 | 본인에 대한 통지 여부의 결정 |

#### 4.2. 본인에 대한 통지

본 보고에 대한 본국의 처리 결과·후속 조치·관련 결정의 본인에 대한 통지에 관하여는 [기록 보류] 한다.

본 절차의 결과로, 본인이 제출한 보고에 대한 본국의 처리가 *완료되었는지 여부*를 본인이 인지할 수 있는 일반 경로는 본국이 별도로 결정하지 아니하는 한 운영되지 아니한다.

---

### 5. 본국의 기록 영역

#### 5.1. 본국의 기록 운영

본국 인원의 모든 보고는 본국의 보안 통제부의 기록 영역에 누적된다. 본 기록은 본국의 정해진 보관 절차에 따라 보관되며, 본 기록의 *내용*에 대한 본인의 열람·정정·삭제 요청에 관하여는 [기록 보류] 한다.

본 기록은 본국의 사상체 문서·사건 기록·인사 자료의 *기초 자료*가 된다. 본인이 제출한 보고의 일부는 본국의 결정에 따라 사상체 문서의 *사건 기록* 영역에 등재될 수 있으며, 본 등재 시 보고자의 신원 정보의 노출·검열에 관하여는 본국이 결정한다.

#### 5.2. 본 사이트 활동의 기록

본인이 본 사이트에서 수행하는 *열람·접근·체류·이탈*의 일체는 보고와 별개로 본국의 보안 통제부의 기록 영역에 자동 누적된다. 본 기록의 운영 원칙은 「보안 통제부」 §3 및 IG 등급 인원의 보안 서약서 제9조를 따른다.

본 활동 기록은 본인의 보고 누락·과다 보고·자가 판단 위반의 사후 검증의 자료가 될 수 있다.

---

### 6. 본 항목과 다른 영역의 관계

본 항목은 본국의 보고·기록 절차의 일반 양식을 정한다. 사상체별 별도의 보고 양식은 각 사상체의 사상체 문서 *대응 지침* 항목에서, 본국 인원·임시 인가 인원의 공통 행동 규범은 「공통 수칙」 항목에서, 격리 절차의 일반 원칙은 「격리 절차 원칙」 항목에서 다룬다.

- §5.1 *기록 내용 열람·정정·삭제 요청 [기록 보류]* — page 2-B-3 §5와 동일 패턴

본 페이지에서 *검열되지 않은 것*: 보고 의무·범위·양식 8필드·채널 2종·후속 처리 흐름. 즉 *시청자가 무엇을 어떻게 보고해야 하는가*는 완전 공개, *시청자가 본 보고의 결과를 알 수 있는가*는 차단.

### D. 균열의 자리 (이중 구조의 미세 노출)

1. **§1.2 보고 범위 5분류의 *광범위함*** — *변칙 현상 / 사상체 관련 / 본인의 자기 상태 / 본국 운영의 예외 / 본인의 절차 위반* 의 5분류는 *시청자의 일상 거의 전 영역*을 포괄. 시청자가 본 사이트와 노스포비아 방송에 노출되는 동안 *경험하는 사실상 모든 것*이 보고 대상이 될 수 있음. *과다 보고에 대한 인사 처분 미적용*(§1.3)과 결합하여 *최대 보고의 행정 유도*가 정립.

2. **§1.2 *인지 = 본인의 감각·사고·기억·꿈·환각 포함*** — 보안 서약서 제4조 ②의 어휘가 본 페이지에서 *보고 양식의 운영 어휘*로 재발현. 시청자의 *꿈조차도 본 사이트의 보고 영역에 입력되어야 하는 자리*. 본인의 *사적 영역*과 *본국 직무 영역*의 경계가 무너지는 자리.

3. **§1.3 *보고 범위 해당 여부 판단은 본인의 자가 판단의 영역이 아닙니다*** — 시청자의 *판단력*마저 본국에 종속. 시청자는 *보고할지 말지*를 결정할 수 없으며 *오직 보고만 수행*. 본인의 *행위*가 *판단 없이 본국에 자동 입력*되는 위치에 묶임.

4. **§4.2 *본인 통지 [기록 보류]*** — 시청자가 *본인이 보고한 것에 대한 본국의 처리*를 알 수 없음. *단방향 입력*만 가능. 시청자의 *피드백 루프*가 본 페이지에서 행정 어휘로 차단.

5. **§5.1 *보고가 사상체 문서의 사건 기록 영역에 등재될 수 있으며, 보고자 신원의 노출·검열에 관하여는 본국이 결정한다*** — 시청자의 보고가 *공식 사상체 문서의 일부*가 될 수 있음의 인정. 동시에 *시청자 본인이 누구로 등장하는가* — 신원이 노출되는지 검열되는지 — 는 본국의 단독 결정. 시청자가 *본국의 기록물의 등장인물*이 될 가능성과 *그 정체성의 단독 결정권*이 본국에 귀속됨.

6. **§5.2 *본 사이트 활동 기록이 본인의 보고 누락·과다 보고·자가 판단 위반의 사후 검증 자료*** — 시청자의 *모든 활동*이 *본인의 보고와 교차 검증*됨. 즉 *본인이 인지한 것*과 *본인이 보고한 것*의 차이를 본국이 *기록을 통해 사후 추론*. 시청자의 *무엇을 보고하지 않았는가*도 본국의 평가 대상.
