# 대응 지침 연출 가이드

> **본 문서를 받은 LLM에게**: 본 문서는 *문체·연출의 원리집*이다. 창작 파이프라인이나
> 번호 규약을 강제하지 않는다. 너의 역할은 (1) 창작자의 의도를 본 문서로 파악하고,
> (2) 아이디어·문체·연출 패턴을 *제안*하는 것이다. 결정은 창작자가 한다.

---

## §0. 세 작품과 세 장르

한 사상체 문서 안의 세 작품은 각자 다른 장르로 흐른다 (프로젝트_의도 §2.4):

| 작품 | 장르 | 전제 | 공포의 원천 |
|---|---|---|---|
| **대응 지침** | 규칙괴담 | *조우*를 상정 — 생존+조사 후 귀환 | *형식의 모순* (규칙 간 충돌, 위반 결과 미명시) |
| **사건 기록** | 나폴리탄 | 특정 인물의 특정 시공간 사건 | *형식의 부재* (의미의 미결정) |
| **격리 절차** | 격리픽션(SCP계) | *격리된 상태*를 상정 | *형식의 권위* (임상 어조와 분류 체계) |

대응 지침은 세 장르의 *합금*이다 — 규칙괴담의 골격에 임상 어조와 모호함이 얹힌다:

- 격리픽션의 *임상 어조* → 공식 문서 외형
- 나폴리탄의 *모호함* → 위반 결과 미명시, 조건 분기 어휘의 모호함
- 규칙괴담의 *번호 매겨진 규칙* → 번호 순서의 서사 진행

LLM은 작성·제안 시 세 장르의 어휘·어조·구조를 *각자의 자리에서* 활용한다.

## §1. 다섯 가지 문체 원리

### 1.1. 임상 어조 — 공식 문서 외형

끔찍한 내용을 차분한 어조로. SCP계의 핵심.

- 수동태 우선 — *"본 사상체는 격리되었다"* (×"우리가 격리했다")
- 명사화 — *"본 개체의 인명 살해 빈도가 높음"*
- 부조리한 정밀도 — *"평균 0.7초 간격으로"*
- 부드러운 부정 — *"권장되지 않는 상호작용 패턴"*
- 추가 연구 필요 식 봉합 — *"본 결과의 통계적 유의성은 후속 검증 요구"*

어조가 깨지면 몰입 손상. *경어 명령형*(`~하십시오`)과 *임상 보고체*를 교차하되, 어조 일관성은 *문단 단위*로 유지.

#### 한국형 변종 — 임상 어조와 일상 톤의 동거

서양 SCP의 임상 단일 톤과 달리, 한국형 행정 문체 호러는 *임상 톤 + 직장인 자조 + 대원 농담의 동거*가 디폴트다(수색연합·처리반·호텔비다 공통 관찰).

**노스포비아 응용**: *친근한 호스트가 균열에서 무엇이 되는가*. 노스의 톤에 직접 응용. 단 직설적 인터넷 어휘는 *완곡한 자조*로 변환한다 — 동거 원리는 보존, 어휘 양태는 변환.

- *고용노동부 신고 감* (배제) → *본인의 노무 환경 적정성에 대한 별도 검토가 필요하다고 사료되는 자리* (변환)

호러 어조의 정점에 *짧은 자조 1구*를 끼우거나, *비격식 댓글*을 임상 어조 사이에 1~2회 배치. 단 비격식 비율이 *본문 30% 초과*하면 임상 위장이 무너진다. 임상 단일 톤도 유효한 선택지.

### 1.2. 모호함 보존 — 나폴리탄의 본질

명료하게 쓸 수 있는 자리도 *의도적으로 모호하게* 변환하는 것이 이 장르의 기본 태도.

- *위반 결과를 명시하지 않음* — *"~하지 마십시오"*까지만, *왜 안 되는지*는 함의로만
- *조건절을 모호하게* — *"§3을 따랐다면"*(명료) → *"무사히 수행했다면"*(모호)
- *결말의 부재* — 마지막이 완결되지 않고 *"후속 절차는 [데이터 말소]"*

#### 위반 결과 우회의 4종 양태

| 양태 | 특성 |
|---|---|
| **(1) 반복 정형구** | 같은 우회 표현이 작품 내/시리즈 내 후렴으로 반복. *환유 카운터* 누적. |
| **(2) 변주형 완곡어법** | 핵심 어휘를 분포형 완곡 표현으로 변주 (*그다지 유쾌하지 않은 / 좋지 않은 / 지극히 어려운*) |
| **(3) 사례 누적형** | *동료/선행 인원의 사후 처리 사례*가 현재 위협의 환유 (*해당 직원은 팔의 부상으로 퇴사하였음*) |
| **(4) 결과 완전 부재형** | *결번 비기재 + 결말 미명시*가 완전 우회. 항목이 *있어야 할 자리에 없음*으로 환기 |

(1) 반복 정형구는 *나폴리탄 모호함의 한국형 변종* — 결과를 명시하지 않되 정형구의 누적이 환유적으로 위협을 환기. *명시*가 아닌 *환유 누적*이므로 모호함 원칙과 충돌하지 않는다.

위반 결과를 직접 쓰고 싶은 충동을 *상시* 억제. *사례가 보고됨 / 양상으로 분류됨 / 가능성이 검토 중* 같은 간접 표현으로 우회.

### 1.3. 모호한 조건절 — 자기 분류의 강제

대응 지침의 분기는 게임북과 다르다. 게임북은 *플레이어의 선택*이지만, 이 장르는 *독자가 자기 상황의 해당 여부를 스스로 판단*해야 한다. 이 *자기 판단의 부담*이 공포의 자리.

```
나쁜 (명료): "시선 접촉이 성립한 경우 §150으로 이동하십시오."
좋은 (모호): "시선 접촉이 본인의 인지 안에서 *확실히 성립하지 않았다*고
            단정할 수 없는 경우라면 §150번 지침으로 이동하십시오."
```

#### 주관적 판별 의존형 (한국형 변종)

측정 가능한 객관 변수 대신 *독자의 주관적 판별*에 분기를 위임:

- 인지 안정성 의존 — *본 환경이 본인의 인지 안에 안정적으로 형성된 시점부터*
- 상식 의존 — *상식적으로 ~과 다를 수 있습니다*
- 사유 의존 — *어떠한 사유로든*
- 외형 의존 — *수려해 보인다면*

단 *완전 주관 의존*(*관리인의 기분에 따라*)은 *읽기 흐름 자체를 차단*하므로 배제. 부분 주관 의존은 도입 / 완전 주관 의존은 배제. 디폴트는 인지 안정성 의존이 가장 안전.

### 1.4. 호명체 — 행위자 위치의 강제

호출·지시는 *경어 명령형*(`~하십시오`)을 사용. 권고형(`~을 권장합니다`)은 자기 통제 영역에 한정되므로 강제성 있는 행동 지시에는 부적합.

호명체와 보고체(`~로 보고된다`)의 *교차*가 독자의 두 위치를 동시에 환기한다:

- *관찰자 위치* — 내가 이 사상체를 마주칠 일은 현재로선 없다. 정보로 읽는다.
- *잠재적 행위자 위치* — 만약 마주친다면 이 지침을 따라야 한다.

어느 한쪽으로만 기울면 효과 손실.

#### 호명체 비율 — 매체 다양성의 눈금

| 비율 | 효과 | 적용 자리 |
|---|---|---|
| **95%** | 행위자 강제 고정의 극단. 매뉴얼체 단층. | 짧은·단순 사상체 |
| **95~70%** | 권장 디폴트. 강한 점유 + 보고체·각주 진입 허용. | 대다수 사상체 |
| **70~30%** | 권위 분산. 보고체·채팅체·1인칭 회상 진입. 매체 다층화 강함. | 다층 매체 사상체 |
| **30% 이하** | 매체 위계 직조가 어미 일관성을 대체. | 시점 모듈 한정 |

비율이 낮을수록 보조 매체(보고체·채팅체·메모)의 비중이 증가한다. 호명체가 사용되는 모든 자리에서는 경어 명령형 유지.

### 1.5. 유동 매체 — 매체체의 자유

사상체마다 *매체체*(매뉴얼체 / 산문체 / 통신로그체 / 대본체 / 답안체 / 채팅체 / SMS / 회상체)를 자유 선택. 매체 다양화 자체가 한국형 옴니버스의 진화 동력. *작품마다 다른 매체체*가 시리즈 진화의 자원이 된다.

## §2. 검열 — 형식의 빈자리에 의한 환기

서양 SCP의 *[DATA EXPUNGED] 한 줄 가림*과 달리, 한국형 장르는 *5종 음각 환기 도구함*을 쓴다. 모두 *형식의 빈자리에 의한 환기*라는 동일 원리.

| 종 | 형식 | 비고 |
|---|---|---|
| **(1) 부분 검열** | `█` / `[데이터 말소]` / `[기록 보류]` | 모든 사상체의 기본. 본문의 5~15% |
| **(2) 번호 결번** | §10을 비우거나 *본판에 게재되지 않음* 명시 | 5~30% 권장. 4막 후반 집중 경향 |
| **(3) 메타 균열** | *영월 워터파크는 존재하지 않습니다* | 항목은 있으나 내용이 자기/외부 부정 |
| **(4) 인물 부재형 군림** | *그녀*가 단 1회만 호명, 나머지 전 항목 부재 | 부재 자체가 본문을 지배 |
| **(5) 자모 깨짐·송신 실패** | *정ㅈㅓㄴ ████ (재전송) (삭제되었습니다)* | 통신로그체·SMS·채팅체에서 자연. 매뉴얼체엔 부자연 |
| **(6) 수치 ??? 표기** | *칩 개수가 ??? 개 이상 ??? 개 미만* | 부조리한 정밀도와 결합 가능 |

**전체 검열 금지**: 한 항목 전체가 *[기밀 분류]* 한 줄로만 구성되는 자리는 *없다*. 탐사자(Level IG)는 계약직이며 대응 지침 숙지가 필요하므로, 통째로 가림은 세계관 내적 부자연.

**조합 사용**: 5종은 상호 배타적이지 않으나 *2~3종*이 권장(전 종 동시 사용은 시각적 산만). 한국형 디폴트 조합 = *부분 검열 + 번호 결번*.

## §3. 시간축 — 살아 있는 문서

대응 지침이 다루는 시간은 *두 축*으로 동시 노출된다. 이것이 *살아 있는 문서*의 효과를 만든다.

| 시간축 | 매체 표지 | 어조 |
|---|---|---|
| **작품 내부 시간** | 탐사자의 현재 행위 시점. 호명체 현재형. | 즉각·강제 |
| **문서 외부 시간** | 보고체 과거형 + 갱신 일자 + 시각 스탬프 + 권위자 서명 + 후일담 각주 | 누적·증언 |

현재형 호명체로만 작성하면 시간축이 단일 평탄해져 *살아 있는 문서* 효과가 부재한다. 본문 안에 *과거형 보고·갱신 메모·시각 스탬프 중 1~2종*을 의식적으로 배치.

#### 4종 시간차 양태

| 양태 | 특성 | 외부 시간 매체 |
|---|---|---|
| **다일자 누적** | 외부 시간이 수년 누적. 갱신 일자·후일담 분산. | 갱신 메모 다수 |
| **단일 일자 분할** | 외부 시간이 1일. 시각 스탬프 분 단위 정밀도. | 시각 스탬프 |
| **응축 + 비선형** | 짧은 응축 + 읽기 순서 ≠ 시간 순서. | 파일/매체 분리 |
| **시간 정지** | 작품 시간 정지, 읽기 시간만 흐름. | 최소 매체 |

*시간 정지*가 가장 가벼운 디폴트. 외부 시간 매체는 *2~3종 이내*가 권장(4종 이상은 산만).

**노스포비아 응용**: *방송 = 시간을 살고 있는 사상체*. 방송의 정지된 시간(공간) + 외부 시청자의 흐르는 시간(매체)이 본 절의 직계 응용.

## §4. 추론 표적의 3층 분포

사상체 윤곽은 단일 명제가 아니라 *3층 구조*로 분포시킨다.

| 층 | 비중 | 특성 |
|---|---|---|
| **1층 — 표면** | 약 60% | 다수 항목이 직접 묘사. 첫 읽기에 즉시 추론. |
| **2층 — 대조** | 약 30% | 항목 X와 Y를 함께 읽어야 보임. 재독 가치. |
| **3층 — 미지** | 약 10% | 부분 검열·미공개 어휘로만 흔적. *절대 비공개*. |

비중은 권장 골격이며 조정 가능. 단 *3층이 0%*가 되면 나폴리탄 미학 손실 — 최소 5%는 유지.

3층은 분포되는 *차원*이 셋이다: (a) 한 작품 안 항목 위치, (b) 작품 시간 후반 집중(합금형 반전), (c) 시리즈/옴니버스 분산(시리즈 사상체에 한함).

## §5. 서사 위치별 적용 비율

세 장르의 비율은 *서사의 위치*에 따라 변동한다. 대응 지침의 자연 곡선은 *진입→조우→사후→비상*이며, 이는 안전 안내문이 *평범한 것에서 비상으로* 흐르는 일반 행정 문서의 곡선과 같다. 공포의 자리는 *이 자연 곡선이 비정상으로 변질되는 지점*에 위치한다.

| 위치 | 격리픽션 | 나폴리탄 | 규칙괴담 | 분량 | 검열 밀도 |
|---|---|---|---|---|---|
| 진입 이전 | 강 | 약 | 강 | 1~2 문장 | 5% 이하 |
| 조우 | 중 | 중 | 강 | 1 문단 | 5~10% |
| 사후 | 강 | 중 | 중 | 1~2 문단 | 10% |
| 비상 | 중 | 강 | 중 | 1 문단(밀도 높게) | 10~15% |

진입은 *공식 문서 외형*이 우선, 비상은 *모호함*이 우선. *진입이 비상보다 밀도가 높은* 역전은 자연스럽지 않다.

#### 공간 = 의례 위계 (한국형 자원)

한국형 장르는 *학교·열차·마트·성당·병원·호텔·카지노/시험장*의 현실 공간이 디폴트이며, 각 공간의 *의례 위계*(교사-학생·승무원-손님·의사-환자 등)가 *생존 통화*가 된다 — *예의 위반 = 죽음*의 등식이 행정 정형구와 결합. *비위계 공간*(공원·해변·자택)도 가능하나 그땐 *공간 = 다른 변수*(시간성·격리도·접근 빈도)로 설계.

**노스포비아 응용**: *방송 공간*은 이 카탈로그에 부재한 매체다. 다른 사상체를 7종 공간에 분포시키면 장르 친숙성을 주면서, 방송 매체는 *컨벤션 부재의 새 자리*로 차별화된다.

## §6. 한국형 장르의 서양 SCP 차별점 6종

노스포비아 미학의 *디폴트 자원*. (수색연합·처리반·호텔비다 횡단 종합)

1. **공간 = 한국 사회 의례 위계의 도감화** — 추상 공간(컨테인먼트 셀) 대신 현실 공간 + 고유 의례 위계. → §5
2. **조직 권위의 인격화·복수화·와해** — 익명 단일 재단 대신 인격화된 권위자들 + 와해 곡선. 단 권위자의 사적 관계 상세 노출은 배제, *서명체 메모*에 한정.
3. **유머·자조의 호러 톤 동거** — 임상 단일 톤과의 결정적 차이. 단 직설 인터넷 어휘는 완곡 자조로 변환. → §1.1
4. **형식의 빈자리에 의한 환기 5종** — *[REDACTED] 한 줄*과의 차이. 5종 음각 환기. → §2
5. **살아 있는 문서 — 시간 누적된 매체** — 정지된 보고서와의 차이. 갱신/댓글/시각 스탬프. *방송 = 시간을 살고 있는 사상체*와 완벽 정합. → §3
6. **옴니버스 = 매체 실험의 장** — 일관된 표준 형식과의 차이. 작품마다 다른 매체체. → §1.5

## §7. 배제 자리 — 노스포비아 미학과 대립

다음 4항목은 한국형 장르에 있으나 노스포비아 미학과 대립해 배제한다.

1. **권위자 사적 관계의 본문 상세 노출** — 임상 권위를 사적 친밀로 침식. *서명 한 줄*(*— 이도윤*)은 가능, 그 이상은 배제.
2. **적측의 권위 매체 전유** — 대응 지침이 적측에 전유돼 본인을 속이는 자리가 메인에 등장. 외부 단절·통신 부재는 비상의 자연 자리이나, *적측이 본 매체를 전유*하는 자리는 별도 매체로 위장 필요.
3. **직설적 인터넷 어휘** — *미라클 모닝 / 대박좋다 / 고용노동부 신고 감*. 완곡 자조로 변환.
4. **완전 주관 의존 분기 어휘** — *관리인의 기분에 따라*. 읽기 흐름을 차단. 부분 주관 의존(§1.3)은 허용.

## §8. 자기 점검 (제안·작성 시)

```
1. 어조가 임상 어조를 유지하는가? (수동태·명사화·불확정 어미)
   동거 자리라면 완곡 자조로 변환되었는가?
2. 위반 결과가 직접 명시되지 않고 간접 표현으로 우회되었는가?
3. 조건절이 모호한가? 완전 주관 의존은 아닌가?
4. 추론 표적 1·2·3층이 분포되어 있는가? (3층 ≥ 5%)
5. 검열이 5종 도구함의 2~3종 조합인가? 전체 가림은 없는가?
6. 외부 시간 매체가 1종 이상 노출되어 살아 있는 문서 효과가 있는가?
7. §7의 배제 자리 4항목이 회피되었는가?
8. (노스포비아) 표면/본질 이중 구조가 유지되는가?
```

## 부록. 짧은 문체 표본

원본(archive)의 §10에 더 많은 예시가 있다. 여기엔 핵심 4종만.

**위반 결과 — 나쁜 vs 좋은**
```
나쁜 (직접): "시선을 접촉할 경우 진입자는 학생 개체로 변형된다. 따라서 금합니다."
좋은 (간접): "*학생*에 해당하는 형상에 시선 접촉을 ██초 이상 유지하지 마십시오.
            시선 접촉의 지속이 본 사상체의 *진입 유도*에 대한 무의식적 응답으로
            처리되는 사례가 보고된 바 있습니다."
```

**모호한 조건절**
```
나쁜 (직접 변수): "현재 시각이 13:30 이후라면 §200으로 이동"
좋은 (간접 양상): "본 사상체 내부의 *야간 환경*이 본인의 인지 안에서 안정적으로
                형성된 시점부터 ██시간이 경과한 양상이 자각될 경우, §200번 지침으로
                이동하십시오."
```

**살아 있는 문서 — 갱신 메모 끼임**
```
§47. 본 사상체와의 조우 시 [현재형 호명체] ...

(2026.03.04. 갱신: 본 항목의 *진입 유도* 어휘는 본 사상체의 ██차 활성 양상
이후 ████ 절차에 따른 재분류 검토 중. — ████ 본국 차단부)

§48. ...
```

**번호 결번 — 안내 부재형**
```
§8. ... §9. ...
§11. *복도*의 자연 진행을 따른 인원은 §15번 지침으로 이동하십시오.
```
§10이 단순 누락. 독자는 *의도된 누락인지 오기인지* 자기 분류한다.
