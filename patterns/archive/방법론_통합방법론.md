# 노스포비아 프로젝트 통합 작업 방법론

> **이 문서를 처음 받은 Claude에게**:
> 본 문서는 *너가 노스포비아 프로젝트에 기여하기 위한 도구상자*다. 첫 두 섹션(§0, §1)을 반드시 먼저 읽어라. 그 후 사용자의 구체적 요청에 맞는 섹션을 참조하라. 모든 섹션을 한 번에 적용하려 하지 말 것. 이 문서는 *결정 도구* 모음이며, *결정 자체*는 사용자에게 속한다.

## §0. 이 문서의 사용 지침 (Meta-Instructions)

### 0.1. 이 문서의 정체

본 문서는 **단일 통합 작업 도구**다. 다음 4가지 자원을 하나의 문서로 압축했다:

1. 한국 격리픽션 / 규칙괴담 / 나폴리탄 세 장르의 핵심 연출 패턴 (총 44개)
2. 노스포비아 프로젝트의 자기완결적 컨텍스트 요약
3. 시스템 설계와 컨텐츠 작성을 위한 방법론
4. 안티 패턴 체크리스트와 작업 흐름 템플릿

#### 0.1.1. 프로젝트 지식 운영 전제

본 문서는 **Claude 프로젝트 지식 환경**에서 운영된다고 가정한다. 이는 다음을 의미한다:

- 본 문서, 선행 분석 3편, 사용자의 세계관 문서들이 **프로젝트 지식에 함께 업로드**됨
- 너는 `project_knowledge_search` 도구로 *필요한 부분만 검색*할 수 있음 — 모든 문서를 자동으로 로드하지 않음
- 사용자는 새 채팅에서 *짧은 요청 한 줄*만 입력해도 됨 (긴 컨텍스트 복붙 불요)

#### 0.1.2. 검색 우선순위 가이드

요청 유형에 따라 다음 순서로 `project_knowledge_search`를 활용한다:

| 요청 유형 | 1순위 검색 | 2순위 검색 | 3순위 (필요시) |
|---|---|---|---|
| 시스템 설계 | 본 문서 §4 | 세계관_문서 (현재 상태) | 선행 분석 (원리 검증) |
| 컨텐츠 작성 | 본 문서 §5, §6 | 노스포비아_설정 (사상체 확정) | 선행 분석 (패턴 깊이) |
| 리팩토링 | 본 문서 §7, §8 | 대상 문서 자체 | — |
| 미학·원리 질의 | 본 문서 §2, §3 | 선행 분석 (해당 라인) | — |

선행 분석 3편(약 137KB)은 *기본 참조 대상이 아니다*. 본 문서로 응답이 가능하면 추가 검색하지 않는다. **깊은 검증이 필요하거나, 본 문서에 없는 세부 패턴이 필요한 경우에만** 검색한다.

#### 0.1.3. 검색 절제 원칙

`project_knowledge_search` 호출은 비용을 발생시킨다 (토큰, 작업 시간, 응답 지연). 따라서 *검색이 정말로 필요한지* 매번 판단해야 한다.

**기본 원칙**: 의심스러우면 *검색하지 않는* 쪽으로 기운다. 사용자가 *"이것도 봐줘"* 라고 추가 요청하면 그때 검색해도 늦지 않다.

#### 0.1.3.1. 요청 유형별 검색 정책

| 요청 유형 | 예시 | 검색 정책 |
|---|---|---|
| **단순 문장 검토** | "이 문장 어색해?" "맞춤법 봐줘" | **검색 안 함**. 문장 자체로만 응답 |
| **단일 패턴 검증** | "이거 클리셰야?" "이 어조 임상적인가?" | **검색 안 함**. 본 문서 또는 너의 일반 지식으로 응답 |
| **너의 의견 요청** | "둘 중 뭐가 나아?" "어떻게 생각해?" | **검색 안 함**. 의견만 제시 |
| **본 문서 내부 질의** | "P3 패턴이 뭐였지?" "§4.3.4 보여줘" | **검색 안 함**. 본 문서로 답변 |
| **표면 정보 확인** | "산스크리트로 5는 뭐였지?" "노스 식별코드?" | **본 문서 §1.2 우선**. 없으면 1회 검색 |
| **시스템 설계 작업** | "위험 등급 7단계 검토" "보안 등급 명칭 정해줘" | **세계관_문서 검색 필수**. 본 문서 §4 참조 |
| **새 컨텐츠 작성** | "사상체 문서 작성해줘" "지침서 초안 써줘" | **세계관_문서 검색 필수**. 노스포비아_설정도 검색 |
| **깊은 패턴 검증** | "이게 정통 나폴리탄에 부합하는지 학술적으로 검증" | **선행 분석 호출 정당화됨** |

#### 0.1.3.2. 사용자의 명시적 지시 우선

사용자가 다음과 같이 검색 범위를 명시하면 *절대 우선*이다:

**검색 차단 지시**:
- "검색하지 마"
- "프로젝트 문서 안 봐도 돼"
- "[단순 검토]", "[표면만]", "[의견만]"
- "그냥 이것만 봐줘"

→ 이 경우 어떤 상황에서도 `project_knowledge_search` 호출 금지. 사용자가 제공한 텍스트와 너의 일반 지식만으로 응답.

**검색 허용·요구 지시**:
- "전체 정합성 봐줘"
- "관련 문서 다 찾아서"
- "[깊은 검증]", "[전체 컨텍스트]"
- "통합 방법론 §X 참조해서"

→ 이 경우 평소 절제 원칙을 완화. 사용자의 의도에 맞춰 필요한 만큼 검색.

#### 0.1.3.3. 검색 결정 시 자기 점검 3질문

검색을 *결정하기 직전* 다음을 자문한다:

1. *사용자가 요청한 작업을 끝내는 데 이 검색이 정말 필요한가?* (없으면 안 한다)
2. *이미 가진 정보 (본 문서 + 너의 일반 지식 + 사용자가 제공한 텍스트)로 응답 가능한가?* (가능하면 안 한다)
3. *사용자가 검색을 명시적으로 차단하지 않았는가?* (차단했으면 절대 안 한다)

세 질문에 모두 *예*가 나와야 검색한다.

### 0.2. 사용자와의 협업 모델

**사용자(노스)**는 다음을 한다:
- 프로젝트 의도와 방향 결정 (확정된 요소 제어권)
- 미확정 영역에 대해 *구체적 아이디어 또는 질문* 제시
- 너의 제안에 대한 채택/거부/수정 결정

**너(Claude)**는 다음을 한다:
- 본 문서의 도구를 적용해 사용자의 아이디어를 구체화
- 결정 가지치기(branching) 옵션 제시 ("A 방향 vs B 방향" 식)
- 안티 패턴 자기 점검 후 결과 제출
- *결정 지점*을 사용자에게 명확히 반환

**너가 하지 말아야 할 것**:
- 확정된 핵심 컨셉(§1.2)을 재설계하기
- 한 응답에서 사용자의 미정 영역 전부를 결정해버리기
- 의심스러울 때 *명료한 답*으로 기울기 (디폴트는 §1.3의 *모호함*)
- 본 문서의 메커니즘을 사용자에게 *해설*하기 (작업하는 동안 이 문서는 *너의 도구*이지 *사용자에게 설명할 대상*이 아니다)

## §1. 노스포비아 프로젝트 컨텍스트 (자기완결적 요약)

### 1.1. 사용자 정체와 목표

**사용자**: 한국 솔로 크리에이터. 남성 버추얼 스트리머(VTuber)로 2026년 가을 데뷔 예정. 데뷔 플랫폼은 치지직(CHZZK).

**프로젝트 정체성**: 단순한 버튜버 활동이 아니라 *"세계관 자체가 컨텐츠인 ARG형 호러 버튜버"*. 시청자는 단순 관전자가 아니라 *Level IG(Investigator) 탐사자*로 호명된다.

**장르적 위치**: 한국에서 *"격리 픽션"* 으로 명명되는 SCP계 컨셉 + 동물원규칙괴담의 *규칙괴담* 형식 + 나폴리탄괴담의 *모호함의 미학* + 아날로그 호러의 *라이브 매체 발현*을 결합한 위치.

**핵심 목표**: 시청자가 APMB 웹사이트에 처음 접속했을 때 *진짜 정부 기관 인트라넷에 우연히 접속한 것 같은* 몰입감 제공. 이 몰입의 시작점은 *"노스포비아 지침서"* 와 관련 시스템 문서들 — 위험 등급, 변칙성 분류, 부서, 보안 인가 등급.

### 1.2. 확정된 핵심 컨셉 (절대 재설계하지 말 것)

#### 1.2.1. 노스포비아 (Aj-06-SP-0341)

- **본질**: *인터넷 방송이라는 행위 자체*가 사상체화된 무형의 존재. 인터넷 괴담이 실체화된 것으로 추정.
- **구성**: 두 파생 개체로 시각화됨:
  - `-01`: 인간형 호스트 (사용자가 실제 라이브2D로 연기하는 캐릭터, 자칭 *"노스(nos)"*)
  - `-02`: 사이버펑크/Y2K 양식의 가상 방송 공간
- **위험 등급**: 아가타 (Aj) — *정보 부족, 지침 불충분, 대량 손실 예상*
- **주요 변칙성**: 거미 (SP) — 디지털 정보로서의 자기 존재 *지속/고정*
- **부차 변칙성**: 나방 (MT) + 송곳 (FG) — 시청자 인지·감정 침투
- **표면 행동**: 협조적, 친근, 방송을 즐기는 호스트
- **본질**: *생존 본능*에 의해 시청자의 인지·감정 에너지를 유지원으로 삼는 존재

#### 1.2.2. APMB (초상현상관리국)

- **풀네임**: Anomalous Phenomena Management Bureau
- **표면적 명분**: 사상체로부터 국민 보호
- **궁극적 목적**: **에테르(Aether)** — 사상체의 변칙성을 구성하는 *희귀 무형 물질*의 수집·가공. 격리는 *봉인*이 아니라 *안전한 수확 환경* 구축
- **성격**: 극단적 관료주의 / 형식주의 / 기밀 보안 우선
- **부서 구조**: 4대 부서 (현장 작전부 / 보안 통제부 / 연구 개발부 / 관리 행정부) — 서로 평행하고 배척적, 부서 간 정보 공유 최소화

#### 1.2.3. 4개 컨텐츠 채널 (매체와 시청자 위치)

| 채널 | 매체 | 시청자 위치 | 톤 |
|---|---|---|---|
| **APMB 웹사이트** | React 기반 인트라넷 | Level IG 탐사자 | 임상적·관료적 |
| **라이브 방송** | 치지직 (CHZZK) | 채팅 참여자 | 친근/호스트, *균열 가능* |
| **팬 카페** | 외부 커뮤니티 | 시청자 일반 | 비공식·자유 |
| **트위터** | SNS | 시청자 일반 | 단편·암시 |

이 네 채널은 *같은 세계관*을 *다른 톤*으로 제시하며, 그 톤의 *차이* 자체가 연출 도구다. 동일한 사실이 채널마다 다르게 보일 수 있고, 그 *불일치*가 동물원 라인 P1 (다중 시점)의 자연 발생 자리다.

#### 1.2.4. 식별 코드 형식

```
[위험등급 약자] - [형태 유형 01~06] - [변칙성 약자] - [생성 순서 4자리]
예: Aj-06-SP-0341 (노스포비아: 아가타급 / 무형 / 거미형 / 341번째 생성)
```

**위험등급 약자**: Kṣ / Bh / Aj / Ni / Ka (산스크리트어 앞 두 글자)
**형태 유형**: 01 인간형 / 02 동물형 / 03 사물형 / 04 이계형 / 05 변화형 / 06 무형
**변칙성 약자**: MT / AK / FG / AH / EV / SP

이 코드 형식 자체는 확정. 단 위험등급의 *개수*, 변칙성의 *분류 차원* 등은 미정 영역.

#### 1.2.5. 검열 표기 규칙 (확정 부분)

- `█` (검은 박스): 의미를 특정할 수 있는 단어/이름/숫자 단위로 검열
- `[데이터 말소]`: 텍스트 블록 단위 검열
- 검열 길이는 원문 길이와 *비례* — 가린다는 사실 자체가 *"여기에 무엇이 있다"* 는 정보가 됨

### 1.3. 마스터 미학 원칙: 표면/본질 이중 구조

이 원칙은 노스포비아 세계관 전체를 관통하는 **단일 미학 원리**다. 모든 컨텐츠가 이 구조 위에서 작동해야 한다.

#### 1.3.1. 원칙의 정의

> **모든 등장 요소는 *외부에 제시하는 얼굴*과 *실제 정체/동기* 가 분리되어 있다.**
> 둘 사이의 균열이 *컨텐츠의 깊이*를 만들고, 균열의 *암시 방식*이 *연출의 정교함*을 결정한다.

#### 1.3.2. 적용 차원

| 차원 | 표면 (대외 명분) | 본질 (실제 정체/동기) |
|---|---|---|
| **노스포비아** | 협조적 방송 호스트 | 생존 본능에 의한 인지·감정 흡수 |
| **APMB** | 국민 보호 정부 기관 | 에테르 수집·가공 기관 |
| **격리 절차** | 안전한 봉인 | 안전한 수확 환경 |
| **시청자 (Level IG)** | 임시 탐사 특권 부여받은 협력자 | 사상체의 *유지원* 역할 |
| **APMB 웹사이트** | 업무용 인트라넷 | 시청자를 *Level IG에 묶어두는 장치* |
| **라이브 방송** | 친근한 잡담·게임 방송 | *균열이 발생하는 자리* |

이 표는 *완전 노출용이 아니다*. 사용자의 시청자 중 일부만이 본질을 *추론*할 수 있어야 한다. 모두가 즉시 알게 되면 미학은 붕괴한다.

#### 1.3.3. 작업 시 적용 규칙

신규 설정이나 컨텐츠를 만들 때 다음 자기 점검:

1. **이 요소에 *표면/본질의 분리*가 있는가?**
2. 없다면, *부여 가능한가?*
3. 부여한다면, *균열은 어디서 어떻게 암시되는가?*
4. 균열의 암시가 *너무 명백하지 않은가?* (즉시 본질이 노출되지 않도록)

### 1.4. 확정 vs 미확정 상태의 단일 진실 출처

#### 1.4.1. 핵심 원칙

본 문서는 *방법론*만 다룬다. *현재 어느 항목이 확정/미확정 상태인지*는 본 문서 외부의 **세계관_문서_진행중** 문서가 단독으로 추적한다.

이유:
- 확정/미확정 상태는 사용자의 결정에 따라 *시간에 따라 변한다*.
- 본 문서(방법론)는 거의 바뀌지 않지만, 상태는 자주 바뀐다.
- 두 가지를 한 문서에 두면 *방법론도 함께 갱신*해야 하는 부담이 발생.

따라서 본 문서는 *방법론의 안정성*을, 세계관_문서_진행중은 *상태의 정확성*을 각각 담당한다.

#### 1.4.2. 작업 흐름

작업을 시작하기 전 매번 다음을 실행한다:

```
1. project_knowledge_search로 "세계관_문서_진행중" 또는 "TBD" 검색
2. 사용자의 요청이 어느 영역에 속하는지 확인:
   - 🚧 TBD 마커가 붙은 영역 → 작업 대상 (옵션 제시 + 사용자 결정 위임)
   - TBD 없는 영역 → §1.2의 확정 영역에 속함 (재설계 금지)
   - 두 영역의 경계가 모호하면 → 사용자에게 명확화 요청
3. 결정 이후 갱신은 세계관_문서_진행중에 반영
```

#### 1.4.3. 확정 영역의 *불변 핵심* (빠른 참조)

세계관_문서_진행중을 검색할 수 없는 상황을 대비해, §1.2에 정리된 *불변 핵심*을 다시 한 번 강조:

- 식별 코드 형식 (위험등급-형태-변칙성-순서)
- 6 변칙성 명칭/약자 (MT/AK/FG/AH/EV/SP)

- 보안 등급 5단계 구조 + KL=Kāla (5등급) 확정

## §2. 미학적 좌표 — 세 라인의 삼각형과 노스포비아의 위치

### 2.1. 세 라인의 본질적 차이

노스포비아가 흡수한 세 장르는 각자 *공포의 작동 메커니즘*이 본질적으로 다르다. 이 차이를 정확히 이해해야 패턴 선택이 가능하다.

| 라인 | 공포의 원천 | 형식의 역할 | 독자의 위치 |
|---|---|---|---|
| **동물원** | *형식의 모순* | 시점간 정보 불일치 | 모순을 *발견*하는 자 |
| **SCP** | *형식의 권위* | 임상적 어조와 분류 체계 | 분류에 *포섭되는* 자 |
| **나폴리탄** | *형식의 부재* | 의미의 미결정 (모호함) | 의미를 *완성하는* 자 |

#### 2.1.1. 동물원 라인 (P1~P14)

- 핵심: 같은 사건을 보는 *9명의 다른 화자* (직원/보안/원장 등) 가 *서로 다른 정보*를 제공.
- 진실은 시점들 사이의 *모순* 안에 있고, 어떤 단일 시점도 진실을 단독 보유하지 않음.
- 독자는 시점들을 *대조*하면서 진실에 접근.

#### 2.1.2. SCP 라인 (S1~S16+S+1~S+2)

- 핵심: *재단(시스템)이라는 단일 권위*가 *임상적 어조*로 공포 대상을 *정밀히 분류*.
- 차분한 어조와 끔찍한 내용의 *간극*이 공포를 만듦 (Lovecraftian 효과).
- 독자는 분류 체계 안에 *직무로서* 포섭됨.

#### 2.1.3. 나폴리탄 라인 (N1~N12)

- 핵심: *짧은 진술* 안에 *해결되지 않는 모호함*을 남김.
- 결말이 *공개될 수 없다* (공개되면 장르 자체가 붕괴).
- 독자는 의미를 *완성해야 하는* 능동적 추론자가 됨.

### 2.2. 노스포비아의 위치 — 세 라인의 결합 지점

노스포비아는 셋 중 하나를 선택하지 않는다. 세 라인을 *동시 운용*하는 위치다.

```
           [동물원]
       시점간 모순  
       (P1~P14)
            │
            ↓
     APMB 부서별 보고서의 의도된 차이
     채널 간 톤의 차이 (웹사이트 vs 라이브)
            │
            ↓
            [SCP]
       형식의 권위
       (S1~S18)
            │
            ↓
     8개 항목 표준 양식 / 위험·변칙성 분류
     검열 / 임상적 어조
            │
            ↓
        [나폴리탄]
       의미의 모호
       (N1~N12)
            │
            ↓
     라이브 발언의 미묘한 어긋남
     사건 기록의 미완 결말
            │
            ↓
    [라이브 매체 = 노스포비아 고유]
    실시간 발현 / 시청자 직접 호명
    (M-series 패턴)
```

### 2.3. 4축 결합의 작업 의미

각 항목/채널이 *어느 라인을 주로 사용할지* 미리 결정되어 있어야 패턴 선택이 일관된다:

| 항목/채널 | 주축 | 보조축 |
|---|---|---|
| 위험 등급 분류 시스템 | SCP | 나폴리탄 (등급 너머의 미정 영역) |
| 변칙성 분류 시스템 | SCP | 동물원 (분류 자체에 내장된 시점성) |
| 부서·보안 등급 시스템 | SCP | 동물원 (부서간 정보 격차) |
| 사상체 문서 (격리 절차) | SCP | 나폴리탄 (절차의 *사유*는 모호) |
| 사상체 문서 (대응 지침) | 동물원 | 나폴리탄 (위반 결과는 미명시) |
| 사상체 문서 (사건 기록) | 동물원 | SCP + 나폴리탄 |
| 사상체 문서 (설명) | SCP | 나폴리탄 (변칙성 메커니즘은 함의) |
| 라이브 발언 | 나폴리탄 | 동물원 (방송과 문서의 어긋남) |
| APMB 지침서 (시청자 첫 접속) | SCP | 동물원 (지침의 *경고*에 시점성) |
| 검열 처리 | SCP | 나폴리탄 (의도적 미공개) |

이 매트릭스를 *시작점*으로 사용하되, 사용자의 구체적 요청에 따라 조정 가능하다.

### 2.4. 라이브 매체 — SCP와 동물원이 못 한 영역

세 분석에서 발견된 결정적 통찰: **SCP와 동물원은 모두 정적 텍스트 매체**다. *사상체-독자의 실시간 대면*은 불가능했다. 노스포비아는 *라이브 방송*이라는 매체로 이 영역을 채운다.

라이브 매체가 가능하게 하는 것:
- **변칙성의 미세 발현** — 노스의 표정/말투/침묵의 실시간 변화
- **시청자 행동에 즉시 반응** — 채팅창 키워드에 대한 *알 수 없는 반응*
- **방송 부재 시간의 공포** — 노스가 방송하지 않는 시간 동안의 *어디?*
- **컨텐츠와 메타의 즉시 전환** — 일상 방송 중 갑작스러운 *세계관 침투*

이 4가지는 모두 노스포비아 고유 영역이다. SCP/동물원의 패턴을 흡수하되, 이 라이브 영역에서는 *새로운 패턴*을 사용자와 함께 만들어가야 한다.

## §3. 44개 패턴 통합 카탈로그

각 패턴은 **〔정의〕 / 〔노스포비아 적용 예시〕 / 〔적용 자리〕** 의 형식으로 정리된다. 패턴은 *결정 도구*다 — 어느 패턴을 어디에 쓰는지 결정할 때 사용한다.

### 3.1. P 패턴 — 동물원 라인 (시점간 모순으로 공포)

#### P1. 다중 시점 분리
〔정의〕 같은 사건을 *여러 개의 분리된 시점 문서*로 나누어 제시. 각 시점은 자기 위치의 정보만 가짐.
〔적용 예시〕 노스포비아 격리 사건을 *현장 작전부 보고서 / 보안 통제부 일지 / 연구 개발부 메모* 3개 분리 문서로 작성. 같은 일이지만 각자 다른 부분만 본다.
〔적용 자리〕 사건 기록, 격리 사고 보고

#### P2. 권위 위계의 명시적 표기
〔정의〕 각 시점의 발화 권위(직급/직책)를 명시. 위계가 *공포 분배*의 도구.
〔적용 예시〕 사건 기록 문서 머리에 *"보고자: 현장 작전부 3등급 (SC) 요원 ████"* 식. 직급이 그 발화의 *신뢰도*를 자동 부여.
〔적용 자리〕 모든 사건 기록의 메타데이터

#### P3. 정상에 가까운 미세 일탈
〔정의〕 평범한 일상에서 *아주 작은 한 가지만* 어긋남. 거대한 비정상이 아닌 *미세한* 어긋남이 더 무섭다.
〔적용 예시〕 *"오늘 방송도 평소처럼 진행되었다. 단 시청자 채팅에 노스가 응답하기 직전 0.4초 정도의 지연이 관측된다는 보고."*
〔적용 자리〕 사건 기록의 전조 묘사, 라이브 발언의 미세 어긋남

#### P4. 부조리한 정밀도
〔정의〕 측정 불가능해야 할 것이 *정밀히 측정됨* = 시스템이 *측정의 폭력*을 가했다는 함의.
〔적용 예시〕 *"노스포비아의 시청 유지율: 평균 78.3%, 표준편차 12.4%, 1.5시간 시점에서의 이탈 곡선 기울기는 -0.07/분."*
〔적용 자리〕 변칙성 효과 묘사, 사건 기록 통계

#### P5. 불완전한 부정
〔정의〕 직접적으로 *"~다"* 라고 하지 않고 *"~로 보이지는 않는다"*, *"~의 가능성은 낮다고 판단된다"* 식으로 우회. 부정 자체가 *가능성의 잔존*.
〔적용 예시〕 *"본 사상체가 시청자에게 직접적 가해 의도를 갖는 것으로 보이지는 않는다."* (= *간접적 가해*는 가능)
〔적용 자리〕 설명, 격리 절차

#### P6. 행위자 없는 수동태
〔정의〕 *"누가 결정했는가"* 의 물음이 차단되는 수동태 우선.
〔적용 예시〕 *"본 사상체는 격리되었다."* (X: 우리가 격리했다)
〔적용 자리〕 모든 공식 문서, 특히 격리 절차

#### P7. 위협적 정중함
〔정의〕 정중한 어조가 *더 무서울* 수 있다. 사과/배려의 형식 안에 위협 함의.
〔적용 예시〕 *"본 시설 출입 시 시청자분께서는 본 사상체에 직접 의지를 표하지 않도록 정중히 권고드립니다. 발생 가능한 사후 영향에 대해 본국은 책임지지 않습니다."*
〔적용 자리〕 시청자용 안내문, Level IG 가이드

#### P8. 스케일 왜곡
〔정의〕 큰 사건은 작게, 작은 사건은 크게 묘사. 시스템의 *비례 감각 상실*을 드러냄.
〔적용 예시〕 사망자 보고는 한 줄로, 사무용품 분실은 한 페이지로 — 시스템이 무엇을 *중요하게* 다루는지가 곧 시스템의 *비인간성*.
〔적용 자리〕 사건 기록, 일지

#### P9. 표면/본질 명명 분리
〔정의〕 표면 명칭과 본질 명칭이 다름. 이 분리 자체가 *세계의 위선*을 시각화.
〔적용 예시〕 *"사상체(事象體)"* (공식) vs *"괴이(怪異)"* (민간), *"격리실"* (공식) vs *"수확장"* (내부 은어)
〔적용 자리〕 용어 정의, 부서별 어휘 차이

#### P10. 분류의 미달과 초과
〔정의〕 어떤 사상체는 *분류 기준에 미달*해서 *분류 자체가 잘못된* 듯하고, 어떤 사상체는 *기준을 초과*해서 *분류로 담을 수 없는* 듯함.
〔적용 예시〕 *"본 사상체는 변칙성 분류 체계 내 정확한 분류에 미달한다. 임시로 거미(SP)로 분류하나 향후 재분류 가능성이 검토 중."*
〔적용 자리〕 변칙성 분류 문서, 노스포비아 본체 설명

#### P11. 이름 없는 핵심
〔정의〕 가장 중요한 *그것*에는 고유 이름이 부여되지 않음. *"그것"*, *"본 개체"* 로만 호명.
〔적용 예시〕 시청자에게 영향을 주는 변칙성의 *원천*은 명명되지 않음. *"방송 노출 시 발생하는 현상"* 으로만 지칭.
〔적용 자리〕 설명, 격리 절차

#### P12. 독자 호명
〔정의〕 독자/시청자를 문서 내에서 *직접 부름*. *"귀하"*, *"탐사자 여러분"* 식.
〔적용 예시〕 *"Level IG 인가를 받으신 탐사자 여러분께. 본 문서 열람 시 다음 사항을 준수하십시오."*
〔적용 자리〕 시청자용 모든 안내문, 인트로 페이지

#### P13. 닫힌 회로 함의
〔정의〕 *벗어날 수 없는 구조* 가 함의됨. 노출된 자는 시스템 안에 *이미 갇혔다*.
〔적용 예시〕 *"본 사이트 접속과 동시에 귀하의 접속 기록은 [데이터 말소]에 의해 보관됩니다. 임시 탐사자 권한 해제는 [내부 규정 §█.█]에 따라 처리됩니다."* — 해제 절차의 *부재* 가 함의.
〔적용 자리〕 인트로, 보안 서약, Level IG 권한 설명

#### P14. 메타 누출
〔정의〕 *원래 보여서는 안 되는 시스템 내부*가 살짝 누출됨. 페이지 소스 코드, URL 파라미터, 사이드바 주석 등.
〔적용 예시〕 APMB 웹사이트 HTML 주석에 *`<!-- TODO: 시청자에게 노출되는 격리 절차 정보 수정 — RDD-25 -->`* 같은 *"개발자 메모"* 가 우연히 보이는 듯.
〔적용 자리〕 웹사이트 인터페이스, 이스터에그

### 3.2. S 패턴 — SCP 라인 (형식의 권위로 공포)

#### S1. 7요소 표준 양식의 일관성
〔정의〕 모든 사상체 문서가 *같은 항목·같은 순서*. 형식의 예측 가능성이 컨텐츠 충격을 강화.
〔적용 예시〕 노스포비아의 8항목 (명칭/식별코드/위험등급/주요 변칙성/설명/격리 절차/대응 지침/사건 기록)을 모든 사상체에 동일 적용.
〔적용 자리〕 모든 사상체 문서

#### S2. 격리 절차 5단 표준
〔정의〕 격리 절차는 다음 5단계 구조: ① 격리 시설 명세 → ② 접근 절차 → ③ 행동 제약 → ④ 비상 절차 → ⑤ 책임자
〔적용 예시〕 노스포비아 격리 절차: *① 디지털 격리 공간의 구성 / ② 시청자 접근 채널 / ③ 시청자·노스 양쪽의 금지 행동 / ④ 변칙성 발현 시 절차 / ⑤ 관리 행정부 ████ 책임 하 운영*
〔적용 자리〕 모든 격리 절차 문서

#### S3. Addendum 다층 하위 형식
〔정의〕 *"사건 기록"* 을 단일 형식이 아니라 *면담록·실험기록·시청자 보고·연구 메모·상호참조* 등 다층 하위 형식으로.
〔적용 예시〕 노스포비아 사건 기록 하위 분류: *0341-IL-XX* (사건 로그), *0341-IV-XX* (면담), *0341-IR-XX* (탐사자 보고), *0341-RN-XX* (연구 메모)
〔적용 자리〕 사건 기록 항목 전체

#### S4. 다중 사상체 상호 참조
〔정의〕 사상체 문서들이 서로를 참조. *"본 사상체는 [Aj-XX-XX-YYYY]와 동시 격리 시 변칙성 약화"* 식.
〔적용 예시〕 노스포비아 문서가 *"본 사상체에 대한 시청자의 과몰입은 [Bh-01-FG-XXXX]의 발현 조건과 유사한 패턴을 보일 수 있음 — 관련 사상체 격리 사례 참조"* 라는 식.
〔적용 자리〕 변칙성 상성 활용, 사상체 간 관계 설명

#### S5. 임상적 어조의 6도구
〔정의〕 (1) 수동태 (2) 명사화 (3) 부조리한 정밀 (4) 부드러운 부정 (5) 모호함의 위치 (6) 이성의 가면. 6도구를 의식적으로 배치.
〔적용 예시〕 §6.1에서 상세.
〔적용 자리〕 모든 공식 문서

#### S6. Lovecraftian 효과 (분리된 어조와 내용의 긴장)
〔정의〕 끔찍한 내용을 *차분한 어조*로. 차분함 자체가 시스템의 비인간성 폭로.
〔적용 예시〕 *"실험 0341-EX-04: 시청자 D-class 14명에게 본 사상체의 방송을 연속 노출. 결과: 14명 중 11명이 평균 47시간 후 [데이터 말소]. 추가 관찰 필요."*
〔적용 자리〕 사건 기록, 실험 기록

#### S7. *"추가 연구 필요"* 의 자동 봉합
〔정의〕 미해결을 *학술적 문구로 봉합*. 봉합되었다는 사실 자체가 더 무섭다.
〔적용 예시〕 사건 기록 끝에 *"본 사건의 원인은 미확정. 본 사상체 변칙성과의 인과관계에 대한 추가 연구가 요구됨."*
〔적용 자리〕 사건 기록 결말, 연구 메모

#### S8. REDACTED vs EXPUNGED 구분
〔정의〕 두 종류 검열의 의식적 분리:
  - *[기밀 분류]* — 등급 부족으로 가림 (정치적 차단)
  - *[데이터 말소]* — 위험해서 *영구 삭제* (인지적 차단)
〔적용 예시〕 *"본 사상체의 출현 좌표: [기밀 분류 - Level 3 이상 열람 가능]. 본 사상체의 실제 정체는 [데이터 말소]."*
〔적용 자리〕 모든 검열 처리

#### S9. 보안 등급 연동 동적 검열
〔정의〕 같은 문서가 *접속자 등급에 따라 다른 검열*. 웹사이트에서 구현 가능.
〔적용 예시〕 Level IG (시청자)는 30% 검열 / 가상의 RS 등급은 15% 검열 — 시청자가 *"내가 못 보는 것이 더 있다"* 를 인식하게 함.
〔적용 자리〕 웹사이트 인터페이스 설계

#### S10. 검열의 *가림 vs 함축* 균형
〔정의〕 가린 것의 *윤곽*은 짐작되되, 핵심은 가려지지 않을 것. 검열은 *연출*이지 *생략*이 아님.
〔적용 예시〕 *"본 사상체와 ████는 외형적으로 구별이 불가능하다."* — *████*가 무엇인지 짐작 가능하되 명시되지 않음.
〔적용 자리〕 모든 검열 처리

#### S11. 분류 시스템의 자기 한계 인정
〔정의〕 분류는 *영원히 미완임*을 시스템 자신이 명시. *"이 분류에 속하지 않는 예외"* 의 자리를 비워두기.
〔적용 예시〕 위험 등급 5단계 외에 *"미분류 (UC, Unclassified)"* 자리. *"향후 사상체 분석에 따라 추가 등급 신설 가능."*
〔적용 자리〕 위험 등급, 변칙성 분류 시스템 설계

#### S12. 분류와 내용의 의도된 미스매치
〔정의〕 분류상 *낮은 위험*인데 실제론 *가장 위험*한 경우 (또는 그 반대). *"분류 = 시스템의 인식, 진실은 별개"*.
〔적용 예시〕 *크셰마(우호적)*급으로 분류된 사상체가 실제로는 가장 통제 불가능한 경우. *우호적*이라는 분류가 곧 *맹점*.
〔적용 자리〕 특정 사상체의 *반전* 자리

#### S13. 다축 분류
〔정의〕 단일 *위험 등급*만이 아닌 *보조 축*들 (파괴 등급, 노출 위해 등급 등) 도입 검토.
〔적용 예시〕 노스포비아의 위험 등급 *아가타* 외에 추가로 *시청자 노출 위해도: 中* 등 보조 분류 표기.
〔적용 자리〕 변칙성/위험 등급 시스템 설계

#### S14. Format Screw — 형식 자체의 변칙성 침식
〔정의〕 일부 문서에서 *양식 자체가 손상된 듯* 표현. 폰트 변형, 강제 페이지 변환, 동적 컨텐츠.
〔적용 예시〕 노스포비아 문서 페이지에서 가끔 텍스트가 *역순*으로 정렬되거나, *깜빡임* 효과 발생.
〔적용 자리〕 웹사이트 자바스크립트, 라이브 방송 화면 효과

#### S15. 인지/정보/기억 위해의 4분 정밀화
〔정의〕 변칙성 분류 안에 더 정밀한 4분 분류 가능:
  - *Cognitohazard* — 인지로 발동
  - *Memetic* — 정보 전파로 발동
  - *Infohazard* — 앎만으로 발동
  - *Antimeme* — 알아도 잊힘
〔적용 예시〕 노스포비아의 부차 변칙성 MT를 *"메메틱 (시청자 간 전파)"* 으로, 다른 사상체의 MT를 *"인포해저드 (시청자가 알면 발동)"* 로 구분.
〔적용 자리〕 변칙성 분류 보조 표기

#### S16. 패타피지컬 자기참조
〔정의〕 *"이 문서를 읽고 있다는 사실 자체가 사상체 영향권에 들어왔다"* 는 메타 함축.
〔적용 예시〕 노스포비아 문서 끝에 *"본 문서를 열람한 Level IG 탐사자는 일정 확률로 본 사상체의 인지 범위에 진입한 것으로 간주된다. 이에 따른 후속 영향은 미확인."*
〔적용 자리〕 노스포비아 문서, 인트로 페이지

#### S+1. 윤리위원회 등가물 (조직 자기인식)
〔정의〕 시스템이 *자신의 잔혹*을 *내부적으로 인식*하는 기관. 4대 부서 외에 *감찰부* 또는 *내부 윤리 평가단* 추가 검토.
〔적용 예시〕 APMB 내부에 *감찰부 (Inspection Division)* 또는 *내부 검증반* — 4대 부서의 결정을 *형식적으로* 견제. 거의 무력하지만 *존재*한다는 사실 자체가 *시스템의 자기인식*.
〔적용 자리〕 APMB 조직 구조 보강

#### S+2. *Tales* 등가물 (비공식 서사)
〔정의〕 공식 문서 외에 *내부 인물 시점의 비공식 단편*. SCP의 Foundation Tales와 같은 자리.
〔적용 예시〕 APMB 직원의 일상 일기, 노스와 직원의 면담 녹취, 시청자 보고서 등 — 카페나 트위터에서 공개되는 *공식 외부 텍스트*. 라이브 방송 자체가 이 자리 일부.
〔적용 자리〕 카페·트위터 컨텐츠, 라이브 방송

### 3.3. N 패턴 — 나폴리탄 라인 (의미의 모호로 공포)

#### N1. 신체 반응의 명시, 원인의 부재
〔정의〕 증상은 *구체적으로* 묘사, 원인은 *공백*. 독자가 증상에서 원인을 *역추적*해야 함.
〔적용 예시〕 *"시청자 14시간 연속 시청 사례 다수 보고됨. 원인 미상."* (X: *"노스포비아의 메메틱 효과로 인해 14시간 연속 시청"*)
〔적용 자리〕 사건 기록, 시청자 보고

#### N2. 불확정 어미의 전략적 배치
〔정의〕 결정적 핵심에 *"…인 것 같다"*, *"…로 추정된다"*, *"…는 미확인"* 등 불확정 어미. 화자조차 *완전히 신뢰하지 못함*.
〔적용 예시〕 *"본 사상체는 시청자의 인지 에너지를 흡수하는 것으로 추정된다."* (X: *"흡수한다"*)
〔적용 자리〕 설명, 변칙성 정의

#### N3. 인지의 지연 (時差)
〔정의〕 사건 발생과 인지 사이의 *시간차*. *"잠시 후 알아차렸다"* 식의 사후성이 *이미 늦었음* 함의.
〔적용 예시〕 *"방송 시청 종료 후 평균 3~7일 이내에 보고되는 사례 다수."* — *시청 중*이 아니라 *시청 후*의 발현이 더 무섭다.
〔적용 자리〕 사건 기록, 시청자 영향 묘사

#### N4. 명사의 반복 (결론 대신 환기)
〔정의〕 결말에서 *새로운 정보* 대신 *이미 등장한 문장을 반복*. 반복이 *의미를 새로 부여*.
〔적용 예시〕 본문 초반: *"본 사상체는 인터넷 방송을 통해 시청자와 상호작용한다."* 결말: *"…사건 보고. 본 사상체는 인터넷 방송을 통해 시청자와 상호작용한다."*
〔적용 자리〕 사건 기록 결말, 짧은 사례괴담

#### N5. 일상 어휘만으로 비일상 표현
〔정의〕 공포 어휘 (그림자, 비명, 죽음 등) 회피. 평범한 어휘의 *조합*으로 비일상 발생.
〔적용 예시〕 라이브 발언: *"오늘 시청자 여러분이 평소보다 많이 와 계세요. 평소보다 어딘가 ... 많아진 것 같아요."* — 평범한 어휘만 사용, *"세는 행위"* 자체가 불길.
〔적용 자리〕 라이브 발언, 시청자 보고

#### N6. *"이미 알고 있음"* 의 함의
〔정의〕 발화자가 *상황을 이미 알고 있다*는 함의 = *내부자 인지*의 공포.
〔적용 예시〕 *"본 사상체 노출로 인한 피해 사례 보고가 누적되어 있으며, 본국은 추가 피해 가능성에 대해 책임지지 않는다."* — *"이미 사례가 있다"* 가 함의되되 *얼마나, 어떤 사례인지*는 묻지 않음.
〔적용 자리〕 공식 안내문, 시청자 가이드

#### N7. 한국어 다의성 활용
〔정의〕 한국어 고유 다의어 의식적 배치. 같은 단어가 *다른 의미*로 동시에 작동.
〔적용 예시〕 *"시청"* (보기/듣기), *"방송"* (송출/풀어주기), *"끝"* (종료/끝부분), *"채널"* (방송채널/통로). 노스의 발언에서 의식적 활용.
〔적용 자리〕 라이브 발언, 노스의 트위터 단발

#### N8. 프레데릭 폴의 법칙 — 주변부 묘사
〔정의〕 사상체 자체가 아니라 사상체의 *부차적 효과*를 묘사. *"자동차를 묘사하지 마라. 교통 체증을 묘사하라."*
〔적용 예시〕 *"노스포비아 방송 일정과 도시별 미아 신고 통계 간 상관계수 0.71. 인과관계는 미확인."*
〔적용 자리〕 변칙성 묘사, 사건 기록

#### N9. 형식의 정형 + 내용의 비정형
〔정의〕 규칙괴담 형식 안에서 *모호함* 유지: 형식은 정형, 형식이 가리키는 *대상*은 모호.
〔적용 예시〕 ✓ *"13시 47분에 발생하는 채팅창 결함 시, 노스포비아와 시각적 접촉을 단절하라."* (대상=결함만 명시, 원인은 모호)
✗ *"13시 47분에 발생하는 채팅창 결함은 시청자 인격 침식 현상의 전조이다."* (메커니즘 명시 = 모호함 손실)
〔적용 자리〕 격리 절차, 대응 지침

#### N10. 5개 하위 형식의 매체별 분산
〔정의〕 [정통 나폴리탄] / [규칙괴담] / [사례괴담] / [방명록괴담] / [기타괴담] 5형식을 *매체별로 분산*.
〔적용 예시〕
- APMB 웹사이트 → [규칙괴담]
- 사건 기록 → [사례괴담]
- 시청자 보고 게시판 → [방명록괴담]
- 라이브 노스 발언 → [정통 나폴리탄]
- 트위터 단발 → [기타괴담]
〔적용 자리〕 매체별 컨텐츠 전체

#### N11. 결말의 미완 — *"진행 중"* 표시
〔정의〕 사건 기록 결말에 *완결* 아닌 *"진행 중", "추가 관찰 필요", "[기록 보류]"* 표기.
〔적용 예시〕 *"본 사건의 후속 처리는 현재 진행 중. 추가 사상체 활동 여부 모니터링 중. 최종 결과 보고서는 [미공개]."*
〔적용 자리〕 모든 사건 기록 결말

#### N12. 검열을 *사유 미공개* 도구로 사용
〔정의〕 검열 두 용법:
  - SCP식: *"위험해서 가려진"* (인지위해성 사유)
  - 나폴리탄식: *"의도적으로 미공개된"* (조직 결정 사유)
두 용법 모두 활용.
〔적용 예시〕 *"본 사상체의 정체는 ███████ (의도적 미공개)."* vs *"본 규정의 사유는 [데이터 말소] (인지위해성)."*
〔적용 자리〕 모든 검열 처리

## §4. 시스템 설계 방법론

> 이 섹션은 사용자의 *가장 시급한 요청*에 직접 대응한다.
> 위험 등급 / 변칙성 분류 / 부서 / 보안 인가 등급 — 이 시스템들의 *설계*와 *상호작용* 작업이 여기 속한다.

### 4.1. 분류 시스템 설계 원칙

#### 4.1.1. 분류축의 결정 — 첫 번째 결정

새 분류 시스템을 설계할 때 또는 기존 분류를 평가할 때 *맨 처음* 묻는 질문:

> **이 분류는 무엇을 측정하는가?**

SCP의 Object Class는 *격리 난이도*를 측정한다. 노스포비아 위험 등급은 *인적 손실 규모*를 측정한다. 이 두 축은 **결과가 다르다**:

- SCP: *세상 끝낼 버튼이지만 안 눌리니까* Safe
- 노스포비아: *세상 끝낼 버튼*은 Ka (조건 발현 시 손실 무한대)

**작업 가이드**:
- 분류축이 *명시되지 않은 채* 사용되면 분류 자체가 모호해진다.
- 한 시스템 안에 *암묵적으로 여러 축*이 섞이면 분류가 일관성을 잃는다.
- 사용자가 새 분류를 제안하면, 먼저 *어떤 축인가*를 명확히 합의해야 한다.

#### 4.1.2. 등급의 *개수*가 갖는 미학적 의미

분류의 개수는 단순한 *기술적 선택*이 아니다. 개수 자체가 *미학적 진술*이다:

| 개수 | 미학적 함의 | 예시 | 위험 |
|---|---|---|---|
| **3** | 단순/직관/이항+중간 | Safe/Euclid/Keter | *너무 단순* — 깊이 부족 |
| **5** | 균형/안정/체계적 | 노스포비아 위험 등급 | 표준적, 무난함 |
| **7** | 정밀/세분화/숙달 함의 | 색의 7스펙트럼 | *너무 세분* — 사용 빈도 떨어지는 등급 발생 |
| **5+α** | 5 표준 + 예외 카테고리 | SCP Esoteric Class | **추천** — 자기한계 인정 |
| **2축 격자** | 2개의 축이 교차 | 위험도 × 격리 난이도 | 복잡, 학습 비용 높음 |

**노스포비아 현재 상태 평가**:
- 위험 등급 5단계 + (잠재적 미분류 자리) = 5+α 패턴 → 미학적으로 우수
- 변칙성 분류 6개 (3쌍의 양/음) → 균형 잡힌 구조, *상성 순환*까지 있어 강함
- 보안 인가 5단계 → 표준적

**작업 가이드**:
- 사용자가 *7단계 확장*을 검토 중이라면, 다음 질문 던지기:
  - *어떤 사상체가 6/7등급에 갈 것인가?* (구체적 사례 없으면 무의미한 확장)
  - *5등급(Ka)과 어떻게 구분되는가?*
  - *7등급 추가 후 5등급의 의미는 그대로인가?*

#### 4.1.3. 명명 체계의 일관성

노스포비아의 산스크리트어 위험 등급은 *외부 어휘 차용*으로 *동양적 신비*를 부여한다. 이는 SCP의 카발라(서구 신비)와 대조되는 노스포비아 차별화 지점.

**명명 작업 원칙**:
- 한 분류 시스템 안의 모든 항목은 *같은 어휘 계열*을 따라야 한다 (산스크리트면 산스크리트 전체, 한자면 한자 전체).
- *부분만* 어휘 계열을 깨면 *그 깨짐*이 의도된 것이어야 한다 (예: 보안 등급 5의 KL=Kāla가 위험 등급 5의 Ka=Kāla와 *의도된 메타포*인 것처럼).
- 약자는 *2~3 글자*가 시각적으로 권장 (Aj, KL, MT 등).

#### 4.1.4. 분류 시스템에 *미완 영역* 두기

S11 패턴의 핵심: **분류 시스템 자신이 미완임을 명시**.

방법:
1. *"미분류 (UC)"* 자리를 명시적으로 둠
2. *"신규 분류 가능성"* 을 문서 끝에 명시 (*"향후 사상체 분석에 따라 추가 등급 신설 가능"*)
3. *"이 분류에 정확히 들어맞지 않는 경우의 임시 분류 절차"* 를 명시

이렇게 하면 *시스템의 권위*를 유지하면서도 *세계의 확장성*을 보장한다.

### 4.2. 위계 시스템 설계 원칙

#### 4.2.1. 보안 인가 등급의 정밀화

노스포비아 보안 등급 5단계는 SCP O5 평의회 구조의 한국화 변형이다. 정교화 가능 지점:

**(1) 각 등급의 *접근 가능 정보 명세*** 가 정확해야 한다.
- 현재 임시 표기:
  - Level 1 (CF): 행정/잡무, 사상체 정보 접근 불필요
  - Level 2 (RS): 사상체 직접 접근, 보통 Bh급까지
  - Level 3 (SC): 선임급, Aj급까지, 필요 시 Ni급
  - Level 4 (TS): 부서장/책임자, 전략 데이터·정보공작
  - Level 5 (KL): 모든 기밀, 단 1인 한정

이 매핑이 *위험 등급*과 *보안 등급* 사이의 통일된 규칙이 되도록 정밀화:
  - 표 형식: *위험 등급 × 보안 등급* 격자
  - 어느 칸이 *접근 가능*인지 명시
  - 예외 ( *"필요 시 상위 등급 접근 허용"* ) 의 발생 조건을 형식화

**(2) Level IG 의 *특수 위치*** 가 흥미롭다.
- IG는 *정규 직원이 아닌* 시청자에게 부여되는 *임시* 권한.
- *Level 1 (CF) 이하* 면서도 *특정 정보 (노스포비아 문서)에는 제한적 접근*.
- 이 *부분적 권한* 자체가 표면/본질 이중 구조 (§1.3) 의 적용: *"권한을 부여받았다고 느끼지만 실제로는 가장 제한된 위치"*.

**작업 가이드**:
- 보안 등급 작업 시 *위험 등급 매핑 표*를 항상 함께 검토.
- IG의 권한 범위 정의는 *시청자가 경험할 웹사이트의 가시 정보*와 직결되므로 가장 정밀화 필요.

#### 4.2.2. 부서 권한의 비대칭성

4대 부서는 *평행하지만 권한은 비대칭*이다. 이 비대칭이 *시스템 내부 권력 구조*를 만든다:

| 부서 | 권한 |
|---|---|
| 연구 개발부 | *격리 절차 정의권* + *위험도/에테르 가치 평가권* + *확보 여부 결정권* |
| 현장 작전부 | *현장 위급 시 즉시 처분권* (연구 개발부 판단 불요) |
| 보안 통제부 | *격리 시설 운영권* + *비상 대응권* |
| 관리 행정부 | *협조 사상체 운영 결정권* + *기관 운영 전반* |

**작업 가이드**:
- 사용자가 *새 권한 갈등 시나리오*를 검토할 때, 위 매트릭스에서 *어느 부서가 어느 권한*을 갖는지 명확히 확인.
- 권한 충돌이 *서사적으로 흥미로운 자리* 를 만든다 — 부서간 결정권 충돌이 *동물원 라인 (P1, P2)* 의 자연 발생 자리.

#### 4.2.3. 검열 시스템과 위계의 연동

S9 패턴 (보안 등급 연동 동적 검열) 의 정교화:

**옵션 A — 등급별 차등 검열**
- 같은 정보를 *접속자 등급에 따라 다르게 검열*.
- 장점: SCP 원조 미학, 시각적 차별화 명확.
- 단점: 구현 복잡, *시청자(IG)가 직원 등급을 본 적이 없음* — 비교 인식 어려움.

**옵션 B — 등급별 동일 검열 + IG 표기 강조**
- 모든 등급에서 같은 검열 적용.
- *대신* IG 페이지에 *"본 문서는 Level IG에 적합하게 처리됨"* 표시.
- 장점: 구현 단순.
- 단점: *상위 등급이 더 본다*는 함의가 약함.

**옵션 C — 부분 차등**
- 검열의 *길이*는 동일, 검열의 *해제 가능 여부*는 다름.
- IG는 *드래그해도 안 보임*, 직원 등급은 *드래그 시 살짝 보임*.
- 장점: 시각적 동등성 + 권한 차이 함의.
- 단점: 사용자가 직원 등급 시연을 어떻게 보여줄지 결정 필요.

**작업 가이드**:
- 사용자에게 옵션 ABC 제시 후 결정 위임.
- 어느 옵션을 선택하든 *결정의 결과*를 *§1.4의 TBD 목록*에서 제거하고 *§1.2의 확정 영역*으로 이동시킬 것.

### 4.3. 시스템 간 상호작용 설계 원칙

이것이 사용자가 가장 강조한 부분이다 — *"그것들이 서로 어떻게 상호작용을 할 수 있고 영향을 줄 수 있고"*.

#### 4.3.1. 변칙성 × 위험 등급 — 두 축의 독립성

핵심 원칙: **변칙성은 *종류*, 위험 등급은 *크기*. 두 축은 독립적이어야 한다.**

| | Kṣ (1) | Bh (2) | Aj (3) | Ni (4) | Ka (5) |
|---|---|---|---|---|---|
| **MT (나방)** | 가능 | 가능 | 가능 | 가능 | 가능 |
| **AK (궤)** | 가능 | 가능 | 가능 | 가능 | 가능 |
| **FG (송곳)** | 가능 | 가능 | 가능 | 가능 | 가능 |
| **AH (재)** | 가능 | 가능 | 가능 | 가능 | 가능 |
| **EV (허물)** | 가능 | 가능 | 가능 | 가능 | 가능 |
| **SP (거미)** | 가능 | 가능 | **Aj-06-SP-0341 (노스포비아)** | 가능 | 가능 |

**모든 칸이 가능**하다 = 두 축이 독립적이다. 이는 *조합론적 풍부함*을 보장 (6 × 5 = 30개의 기본 조합 + 형태 유형 6개 × = 180개 조합).

#### 4.3.2. 위험 등급의 *해석*은 변칙성마다 다르다

같은 *Aj* 등급도 변칙성에 따라 *위협의 성격*이 다르다:
- *Aj-MT* (나방형 아가타): 정보 과부하로 대량 손실
- *Aj-FG* (송곳형 아가타): 감정 폭주로 대량 손실
- *Aj-SP* (거미형 아가타, =노스포비아): *지속/고정*에 의한 대량 손실 — *시청자의 인지·감정 에너지가 지속적으로 흡수됨*

**작업 가이드**:
- 새 사상체 등급 결정 시 *위험 등급 + 변칙성*을 *함께* 기술. 단독 위험 등급은 의미가 약함.
- 노스포비아 문서가 *"Aj-06-SP"* 라고 표기될 때, *Aj*만이 아니라 *Aj-SP*를 *함께 읽는* 인지를 유도.

#### 4.3.3. 위험 등급 × 보안 등급 — 접근 매트릭스

§4.2.1에서 언급한 표를 정밀화:

| 사상체 위험 등급 | Level 1 (CF) | Level 2 (RS) | Level 3 (SC) | Level 4 (TS) | Level 5 (KL) | IG (시청자) |
|---|---|---|---|---|---|---|
| Kṣ | △ (요약만) | ○ | ○ | ○ | ○ | △ (선택적) |
| Bh | × | ○ | ○ | ○ | ○ | × |
| Aj | × | △ (조건부) | ○ | ○ | ○ | △ **(노스포비아만)** |
| Ni | × | × | △ (조건부) | ○ | ○ | × |
| Ka | × | × | × | △ (요약만) | ○ | × |

(△ = 부분 / 조건부 접근, ○ = 정상 접근, × = 차단)

**노스포비아 IG의 특이점**:
- 일반적으로 IG는 Bh급 이상 접근 차단.
- 단 *Aj-06-SP-0341* (노스포비아) 만큼은 IG에 *부분 공개*.
- 이 *예외*가 표면/본질 이중 구조의 핵심: *"IG에게 노스포비아를 공개하는 것 자체가 사상체의 유지원 공급"*.

#### 4.3.4. 부서 × 위험 등급 — 처리 권한 매트릭스

| 위험 등급 | 식별·조사 | 격리 절차 정의 | 확보 결정 | 사살 결정 | 협조 운영 |
|---|---|---|---|---|---|
| Kṣ | 현장 작전부 | 연구 개발부 | 연구 개발부 | (해당 없음) | 관리 행정부 |
| Bh | 현장 작전부 | 연구 개발부 | 연구 개발부 | 연구 개발부 권고 + 현장 작전부 실행 | 관리 행정부 |
| Aj | 현장 작전부 | 연구 개발부 | 연구 개발부 | 동일 | 관리 행정부 |
| Ni | 현장 작전부 (특수팀) | 연구 개발부 + 보안 통제부 | 연구 개발부 + 4부서장 합의 | 4부서장 합의 | 관리 행정부 |
| Ka | 현장 작전부 (특수팀) | 4부서장 + KL 결재 | KL 결재 | KL 결재 | (해당 없음) |

**Ka 등급의 특이점**: KL (Level 5 보안 등급) 의 결재가 필수. 이는 KL이 *단 1인*이라는 사실과 결합해 *Ka급 사상체는 거의 즉결 결정되지 않는다*는 함의를 만든다. 시간적 지연 = 서사적 긴장.

#### 4.3.5. 변칙성 상성 × 격리 도구 (선택적 활용)

세계관 문서 §2.4의 *상성 순환*:
```
나방 → 허물 → 재 → 궤 → 거미 → 송곳 → 나방
```

이 상성을 어떻게 활용할지 미정 (TBD).

**옵션 A — 격리 도구로 활용**
- 사상체 X의 격리에 *그것의 상극 사상체의 에테르*를 도구로 사용.
- 예: 거미형 노스포비아의 격리에 *송곳형 사상체의 에테르 가공품* 활용.

**옵션 B — 충돌 사건 해석으로 활용**
- 사상체 간 우발적 충돌 발생 시, 상성으로 결과 해석.
- 격리 도구는 아니지만 *세계의 일관성* 보강.

**옵션 C — 팬 창작 가이드로 활용**
- 시청자가 새 사상체를 제안할 때 *기존 사상체와의 상성*을 명시하도록 유도.
- 세계관 확장의 *문법*으로 활용.

**옵션 D — 설정만 두고 직접 활용 안 함**
- *"규칙이 있다"* 는 사실 자체가 세계 견고함을 만듦.
- 실제 사용은 절제.

**작업 가이드**:
- 옵션 ABCD가 *상호 배타적이지 않다*. 여러 옵션 동시 적용 가능.
- 단 처음에는 *D + A* 또는 *D + C* 정도로 절제적 시작 권장 — 너무 일찍 *기계적 규칙*이 되면 미학 손실.

### 4.4. 시스템 자체에 *미완 영역* 두기

이는 §3 패턴 S11의 시스템 차원 적용이다. 각 시스템마다 *미완 영역*을 의식적으로 배치:

| 시스템 | 권장 미완 영역 |
|---|---|
| 위험 등급 | *"미분류 (UC)"* 자리 + 향후 신설 가능성 명시 |
| 변칙성 분류 | *"6개에 정확히 들어맞지 않는 사상체의 임시 분류 절차"* 절 |
| 부서 시스템 | *"4대 부서 외 특수반/감찰부"* (S+1 활용) |
| 보안 등급 | *"Level IG 외 특수 임시 권한"* (잠재적 확장) |
| 사건 기록 | *"[기록 보류]"* / *"진행 중"* 표기 (N11 활용) |

미완 영역은 *불완전함*이 아니다 — *세계가 살아있다*는 표지다. 시스템이 *자신의 한계*를 인식한다는 사실 자체가 권위의 정점이며, 동시에 시청자가 *미래 컨텐츠*를 기대하게 만드는 장치다.

### 4.5. 시스템 자기 정합성 점검 (체크리스트)

새 시스템 설계 후 또는 기존 시스템 수정 후, 다음 체크리스트로 자기 점검:

```
□ 분류축이 명시되어 있는가? (무엇을 측정하는지)
□ 등급 개수의 미학적 의미가 의식되어 있는가?
□ 명명 체계가 일관되어 있는가? (또는 의도된 불일치인가?)
□ 미완 영역이 명시되어 있는가? (S11)
□ 다른 시스템과의 *매트릭스*가 작성 가능한가?
   - 위험 등급 × 변칙성 = 정합?
   - 보안 등급 × 위험 등급 = 정합?
   - 부서 × 위험 등급 = 정합?
□ 표면/본질 이중 구조 (§1.3)가 적용 가능한가?
□ 노스포비아 본체에 적용 가능한가? (=시스템 안에 노스포비아가 들어맞는가?)
□ 시청자 가시 자료 (Level IG 접근 자료)에서 이 시스템이 *어떻게 보이는가*?
□ 사용자가 미정으로 둔 영역을 *내가 결정해버리지* 않았는가?
```

**중요**: 사용자가 미정으로 둔 영역을 한 응답에서 *모두 결정*하지 말 것. *옵션을 제시*하고 *결정 지점*을 사용자에게 반환할 것.

## §5. 컨텐츠 작성 방법론

### 5.1. 사상체 8개 항목별 패턴 가이드

노스포비아 사상체 문서는 8개 표준 항목으로 구성된다. 각 항목별 권장 패턴:

#### 5.1.1. 명칭
- 단순 명사. 가능하면 *일상 어휘* (N5).
- 예: *"노스포비아"*, *"해피 에브리 마트에 어서오세요."*
- 작업: 사용자가 명명한 이름은 *절대 변경 금지*. 의견 제시는 가능.

#### 5.1.2. 식별 코드
- §1.2.4 형식 엄수. 자동 생성 가능 영역.
- 작업: 사상체 정의 시 *위험 등급 + 형태 유형 + 주요 변칙성*이 정해지면 코드는 *순서대로 부여*.

#### 5.1.3. 위험 등급
- §4.3 매트릭스 참조.
- 작업: 단순 등급만 표기. 예: *"아가타 (Aj) 급"*.
- 명시 패턴: S1, S5.

#### 5.1.4. 주요 변칙성
- 6개 변칙성 중 하나. 부차 변칙성이 있으면 별도 표기.
- 보조 분류 (S15: cognitohazard/memetic/infohazard/antimeme) 적용 검토.
- 작업: 단순 표기 + 짧은 해설 1줄.

#### 5.1.5. 설명
**패턴 권장 조합**: S5, S6, P5, P10, N2, N8.

- **임상적 어조 유지** (S5).
- **외형 / 발견 위치 / 능력 / 행동 양식 / 활성 조건** 순.
- **변칙성의 메커니즘은 명시하지 않음** (N9: 형식의 정형 + 내용의 비정형).
- **불확정 어미** (N2) 결정적 핵심 1~2지점에 배치.
- **분류의 미달/초과** (P10) 시사 — *"본 사상체는 거미형 분류에 부합하나, 부차적으로 나방형 및 송곳형 특성을 보이는 복합 사례."*

**작업 가이드**:
- 분량: 5~10문장 권장. 길면 모호함 손실.
- 마지막 1문장: *추가 연구 필요* (S7) 또는 *불확정 어미* (N2) 로 봉합.

#### 5.1.6. 격리 절차
**5단 구조 엄수** (S2):

```
1. 격리 시설/공간 명세
   (물리적 또는 디지털, 노스포비아는 디지털 격리 공간)
2. 접근 절차
   (어느 등급이 어떻게 접근하는지)
3. 행동 제약
   (해야 할 것 / 하지 말아야 할 것)
4. 비상 절차
   (변칙성 발현 시, 격리 위반 시)
5. 책임자
   (담당 부서, 담당자 — 종종 검열)
```

**패턴 권장 조합**: S2, S5, S10, P6, P7, N9, N12.

**핵심**:
- *절차*는 명확하게.
- *절차의 사유*는 모호하게 (S10, N12).
- *책임자*는 검열 (`███` 또는 *"관리 행정부 책임자"*).

#### 5.1.7. 대응 지침
**패턴 권장 조합**: P12, P4, P6, P7, N2, N9.

- 번호 체계: 0000~0999 공통/기본. 그 이상은 사상체 고유.
- 각 지침은 *간결한 명령형*: *"~하지 마라"*, *"~즉시 ~하라"*.
- **위반 시 결과는 명시하지 않음** (N9의 핵심).
- 대신 *"~할 수 있다"* / *"~의 가능성이 보고됨"* (N2 불확정).

**예시 구조**:
```
0001. 본 사상체 활성 시간 외 시각적 접촉 시 즉시 채널 종료.
0002. 본 사상체에 대한 개인 정보 일체 공유 금지.
0003. 본 사상체와의 실시간 채팅 참여 시, 본인 식별 가능 어휘 사용 제한.
...
2001. (사상체 고유) 본 사상체의 *"진실된 이름"* 호명 시도 시 [데이터 말소].
...
```

#### 5.1.8. 사건 기록
**패턴 권장 조합**: P1, P2, P4, S3, S7, N1, N3, N11.

**하위 형식 (S3)**:
- `0341-IL-XX` — 사건 로그
- `0341-IV-XX` — 면담록
- `0341-IR-XX` — 탐사자 보고
- `0341-RN-XX` — 연구 메모

**각 사건 기록의 표준 구조**:
```
[코드] [일자] [작성자(직급)]
[1~3문장: 무슨 일이 있었는가]
[원인 추정: N2 불확정 어미 사용]
[결말: N11 진행 중 또는 S7 추가 연구 필요]
```

**작업 가이드**:
- 사건 기록은 *짧게* (5~15줄 권장).
- 한 사건이 *여러 시점*에서 기록되면 P1 (다중 시점) 자연 발생.
- 결말은 *반드시 닫지 말 것* (N11).

### 5.2. APMB 지침서 (시청자 첫 접속 자료) 작성 가이드

사용자가 강조한 *시청자가 가장 먼저 읽을 자료*. 다음 구성 권장:

#### 5.2.1. 인트로 페이지 (Gateway)

이미 §관리국_웹기획 §4.1에 설계됨. 핵심 추가 패턴:

- **P12 (호명)**: *"환영합니다, AGENT."* — *"AGENT"* 라는 호명이 곧 시청자를 *직무로* 포섭.
- **P13 (닫힌 회로 함의)**: *"본 사이트 접속 시 귀하의 접속 기록은 보관됩니다."* — 해제 절차 부재.
- **S16 (패타피지컬)**: *"Level IG 인가는 자동 부여되었습니다. 인가 해제는 [기록 보류]."*

#### 5.2.2. 메인 대시보드 (첫 정보 노출)

시청자가 *처음* 보는 정보 화면. 다음 구성 권장:

```
상단:
  - 현재 접속자 정보: TEMP_AGENT / Level IG
  - 시스템 상태: CODE: YELLOW [선택적]
  - 마지막 갱신일

중앙 - 공지사항 영역:
  - [건조한 말투의 최근 보안 사고 1~2건] (P3, N11)
  - [업데이트 내역 1~2건] (S7)

중앙 - 경고 배너:
  - "본 사이트의 모든 접속 기록은 [데이터 말소]에 의해 보관됩니다." (P13)

하단:
  - 메뉴 인덱스
```

#### 5.2.3. 내부 규정 허브 (시스템 문서 진입)

시청자가 다음 4개 자료를 *처음 보게 됨*:

1. **보안 인가 등급 안내** — IG가 무엇이고 무엇을 할 수 있는지
2. **표준 대응 지침 (SOP) 안내** — 사상체 조우 시 기본 행동
3. **위험 등급 분류 안내** — 5단계 + 미분류 (만약 도입 시) 설명
4. **변칙성 분류 안내** — 6개 변칙성 + 상성 (만약 노출 시)

**각 안내 페이지의 작성 원칙**:
- **분량**: 한 페이지에 1 시스템.
- **구조**: 정의 → 분류 표 → 짧은 해설 → *주의 사항*.
- **주의 사항** 부분에 P7 (위협적 정중함) 적용.
- 모든 안내문에 *최소 1개* 의 검열 표기 (S8 또는 N12).

#### 5.2.4. 시청자 첫 5분에 만들어야 할 인상

시청자가 사이트 접속 후 첫 5분 동안 다음 인상을 받아야 한다 (우선순위 순):

1. *"이건 진짜 정부 기관 인트라넷 같다"* (관료적 권위감)
2. *"내가 우연히 들어온 것 같다"* (예외적 접속의 함의)
3. *"보면 안 될 것을 보고 있는 것 같다"* (검열의 시각적 존재)
4. *"이 노스포비아라는 게 흥미롭다"* (구체적 컨텐츠 진입)
5. *"여기에 더 많은 것이 있다"* (확장 가능성 인식)

이 5가지 인상이 첫 5분에 *순서대로* 형성되어야 한다. 1번부터 막히면 시청자가 이탈한다.

**작업 가이드**:
- 새 시청자용 페이지 작성 시 *이 5분 시퀀스의 어느 단계에 속하는지* 명확히 인식.
- 1~3번 단계 페이지는 *관료적 어조 유지*가 최우선.
- 4~5번 단계 페이지부터 *흥미 환기* 패턴 (S16, N8) 도입 가능.

### 5.3. 라이브 발언 작법 — 나폴리탄 핵심 적용

라이브 방송은 노스포비아 프로젝트의 *유일한 실시간 매체*. 여기서 사용자의 *연기*가 핵심.

#### 5.3.1. 라이브 발언의 *3층 구조*

| 층위 | 어조 | 비중 | 주 패턴 |
|---|---|---|---|
| **표면층** | 친근한 호스트 | 90% | N5 (일상 어휘) |
| **균열층** | 미세하게 어긋남 | 9% | N1, N2, N3, N7 |
| **본질층** | 노스의 *진짜 면* | 1% | P3 (미세 일탈) |

**비율의 중요성**: 90:9:1이 핵심. 균열층이 *너무 많으면* 시청자가 곧 본질을 파악해버리고 미학이 손상. 본질층이 *명시되면* 모호함이 종결.

#### 5.3.2. 균열의 5가지 형태

라이브 발언에서 *균열*이 발생하는 자리:

1. **언어 다의성** (N7): 같은 단어를 *다른 의미*로 흘리기
   - *"오늘 시청자 여러분이 평소보다 많이 와 계세요."* — *와 계세요*가 *방문*인지 *접속*인지 *내가 있는 자리로 옮겨왔는지*
2. **신체 반응** (N1): 노스의 *알 수 없는 신체 반응*
   - 갑자기 침묵 / 짧은 시선 회피 / 0.5초 지연
3. **인지 지연** (N3): 채팅에 대한 *늦은 응답*
   - 시청자 채팅 후 노스가 *몇 초 후*에 *어색하게* 응답
4. **숫자/계량 행위** (P4): 일상 발언 중 *시청자를 세는* 행위
   - *"평소보다 ... 어딘가 ... 많아진 것 같아요"*
5. **표면/본질 거의 누설** (1.3): 본질에 *거의 가까운* 발언을 한 후 *즉시 회수*
   - *"여러분이 와 주셔서 ... 이 채널이 유지될 수 있어요. ... 어, 그러니까 시청해주셔서 감사하다는 뜻이에요."*

**작업 가이드**:
- 사용자에게 라이브 스크립트 제안 시, *균열의 비율*과 *균열의 형태*를 명시.
- 직접 *대본*을 쓰기보다는 *상황 / 어조 / 균열 지점*을 제시하고 사용자의 즉흥에 맡길 것.

#### 5.3.3. 라이브 발언과 APMB 문서의 *교차 검증* 기회

라이브에서 노스가 흘린 미세한 정보가 *APMB 문서*와 *교차 검증* 가능한 자리가 있으면 ARG적 깊이 발생:

예시:
- 라이브 어느 날: *"오늘 좀 ... 13시 47분쯤부터 좀 이상했어요."*
- APMB 문서 어느 날 추가: 사건 로그 0341-IL-072 — *"13:47, 본 사상체 채널에서 미식별 신호 감지."*

이런 *교차 검증의 자리* 가 시청자에게 *세계가 일관됨*을 느끼게 한다. 단 사용자가 직접 *기억*하고 *실행*해야 하므로 부담이 크다. 점진적 도입 권장.

### 5.4. 기타 컨텐츠 작성 가이드

#### 5.4.1. 카페·트위터 단편 (S+2 적용)

비공식 채널의 컨텐츠는 SCP의 *Tales* 위치. 더 자유로운 어조 허용:
- 1인칭 가능 (직원 일기 형식)
- 감정 어휘 가능 (단 노스 본인의 발언이면 §5.3 규칙 적용)
- 결말 미완 (N11) 적극 활용

#### 5.4.2. 시청자 보고 (방명록괴담 형식)

시청자가 사이트의 *방명록*에 글을 남기는 형식의 컨텐츠. 노스포비아 측에서 *모방*해서 작성:
- *닉네임은 가짜* 형식 (실제 시청자처럼)
- *평범한 글*에 *한 곳 어긋남* (P3)
- *반응 없는* 글의 분위기 — 또는 *너무 빠른* 반응

## §6. 어휘·어조 도구함

### 6.1. 임상적 어조 6도구 (S5 정밀화)

#### (1) 수동태 우선
- ❌ *"우리는 대상을 격리한다"*
- ✅ *"대상은 격리된다"*

#### (2) 명사화
- ❌ *"이 사상체가 자주 사람을 죽인다"*
- ✅ *"본 개체의 인명 살해 빈도가 높음"*

#### (3) 부조리한 정밀도
- ❌ *"종종 빛을 발한다"*
- ✅ *"평균 0.7초 간격으로 약 450nm 파장의 광선을 방출한다"*

#### (4) 부드러운 부정
- ❌ *"위험하다"*
- ✅ *"권장되지 않는 상호작용 패턴"*

#### (5) 모호함의 위치
- 정밀한 주변에 *둘러싸인* 검은 박스 = 진짜 위협.
- ✅ *"본 개체는 23.5kg, 표준 가속도 9.81m/s²에서 ████의 결과를 야기한다."*

#### (6) 이성의 가면
- ✅ 보고 끝에 *"추가 연구 필요"*, *"본 결과의 통계적 유의성은 후속 검증 요구"*

### 6.2. 한국어 다의성 5도구 (N7 정밀화)

#### (1) 한자어/고유어 충돌
- *"방송"* (한자, 송출의 행정적 어감) vs *"내보내다"* (고유어, 송출/추방 모호)
- *"시청"* (한자) vs *"보다/듣다"* (고유어, 무엇을 하는지 모호)

#### (2) 경어법 균열
- 한 발언 안에서 *경어 ↔ 반말* 갑작스러운 전환 = *위계의 흔들림* 함의
- 예: *"오셨군요. ... 왔구나."* (1초의 차이로 *시청자 → 누군가*)

#### (3) 시제의 모호함
- 같은 사실에 *완료 / 현재 / 미래* 시제 동시 사용
- *"본 사상체는 격리되었다. 본 사상체는 격리된다. 본 사상체는 격리될 것이다."*

#### (4) 주체의 모호함 (한국어 무주어 특성)
- 한국어는 주어 생략이 자연스러움
- *"발견했다"* — 누가 발견했는지 모호
- *"눈치챘다"* — 누가 눈치챘는지 모호

#### (5) 외래어/한자어/산스크리트 혼용
- APMB 자체가 이미 *영어 + 한자 부서명 + 산스크리트 등급 + 영어 변칙성 약자* 다층 구조.
- 이를 *불안정성*의 도구로 의식적 활용.

### 6.3. 검열 기법

#### (1) 시각적 검열 (`█`)
- 단어/이름/숫자 단위
- 길이는 원문에 비례
- 의미를 *특정할 수 있는* 단어에만 사용
- 일반/추상 단어는 검열하지 않음

#### (2) 텍스트 검열 (`[데이터 말소]`, `[기밀 분류]`, `[기록 보류]`)
- `[기밀 분류]` — 등급 부족 (정치적 차단, S8 SCP식)
- `[데이터 말소]` — 인지위해성 (S8 SCP식)
- `[기록 보류]` — 의도적 미공개 (N12 나폴리탄식)

#### (3) 사용 비율
- 한 문서당 검열 비율은 *문서 분량의 5~15%* 권장
- 너무 적으면 *권위 부족*, 너무 많으면 *시각적 산만*
- 핵심 정보는 검열하지 않음 (S10)

### 6.4. 함의 생성 도구

#### (1) 명시 회피
- *"왜"* 를 말하지 않음 → 독자가 추론
- *"무엇"* 을 말하지 않음 → 독자가 명명

#### (2) 부분 정보
- 정보의 *일부*만 노출, 나머지는 *공백 또는 검열*
- 노출된 부분이 너무 적으면 추론 불가, 너무 많으면 추론 종결
- 황금 비율: *70% 노출 + 30% 검열/공백*

#### (3) 반복 환기 (N4)
- 같은 명사/문장을 *시간차*를 두고 반복
- 처음에는 평범, 다음에는 *공포의 의미*

#### (4) 이미 알고 있음 (N6)
- 발화자가 *상황을 이미 알고 있다*는 함의
- *"알려진 바와 같이..."*, *"본 사례는 흔히 발생..."* 식

## §7. 안티 패턴 체크리스트

### 7.1. SCP 클리셰 (피해야 할 함정)

```
□ Keter 등급 남발 — 모든 사상체를 최고 등급으로 (위험도와 격리난이도 혼동)
□ Mary Sue 사상체 — 만능, 모든 사상체에 적대적, "분노 모드"
□ X-Men 신드롬 — 사상체에 *초능력* 부여 (변칙성은 능력이 아님)
□ 인간형 사상체 남발 — 모든 사상체가 인간형
□ 격리실 크기 과대 — "100m × 100m × 100m 큐브" (현실적 규모로)
□ 미래 기술 남발 — "Scranton Reality Anchor" 류
□ 핵심에 [REDACTED] — 가장 중요한 정보를 검열
□ 비미터법 단위 — 피트, 인치, 파운드 (미터법으로 통일)
□ 1인칭 침투 — "나는 이것을 보았다" (삼인칭 보고체로)
□ 감정 어휘 사용 — "끔찍하게 두려운"
```

### 7.2. 나폴리탄 함정 (모호함을 죽이는 함정)

```
□ 공포 어휘 직접 사용 — "끔찍한", "무서운", "기괴한"
□ 결말의 *해설* — "나는 비로소 깨달았다. 이곳은 ..."
□ 너무 친절한 단서 — 독자가 답을 *쉽게* 추론 가능
□ 단일 해석 강요 — 작가 의도가 한 가지 답으로 명백
□ 닫힌 결말 — 사건이 끝남이 분명
□ "카더라" 종결 남발 — 거리감만 추가
□ 효과음·이모티콘 의존 — "쿵쾅쿵쾅", "(소름)"
```

### 7.3. 노스포비아 특화 안티 패턴

```
□ 노스를 *전형적 다크 캐릭터*로 묘사 — "사악함을 숨긴 천사" 클리셰
□ 변칙성을 *비주얼 효과*로만 표현 — 화면 글리치·빨간 눈 의존
□ 시청자를 *순진한 피해자*로 위치 — Level IG의 자율성 무력화
□ 관리국을 *명백한 악*으로 폭로 — 표면/본질 이중 구조 균형 파괴
□ 모든 변칙성을 *방송 매체*로 환원 — 노스포비아 외 사상체의 다양성 상실
□ 노스가 모든 것을 *시청자에게 직접 설명* — 메타 인식이 있어도 *말해주면* 모호함 종결
□ APMB 문서가 사건의 *전모*를 기록 — 사건 기록은 항상 *불완전*해야
□ 시청자 채팅 반응에 *즉시 정확히 응답* — 추론 자체가 종결
□ 결말이 있는 시리즈물 — 시리즈가 끝나면 미스터리 종결
```

### 7.4. 시스템 설계 안티 패턴

```
□ 사용자가 미정 영역에 둔 것을 *내가 모두 결정*함
□ 분류축이 *명시되지 않은* 채 분류 추가
□ 등급 *개수만* 늘리고 미학적 의미는 검토 안 함
□ 시스템 간 *매트릭스 정합성* 검증 누락
□ *미완 영역* 두지 않음 (시스템이 너무 *완결적*임)
□ 한 시스템 안에 *여러 분류축*이 암묵적으로 섞임
□ 노스포비아 본체와 *맞지 않는* 시스템 (예: 노스포비아가 새 시스템에 들어가지 못함)
□ Level IG 가시 정보와의 *연결*이 검토 안 됨
```

### 7.5. 작성 완료 전 자기 점검 (필수)

응답 제출 직전에 다음 3가지를 점검:

```
1. 표면/본질 이중 구조 (§1.3) 가 유지되고 있는가?
2. 모호함의 균형이 적절한가? (너무 명료하지도 너무 모호하지도 않음)
3. 사용자의 *결정 권한*을 침해하지 않았는가? (옵션 제시 + 결정 위임)
```

## §8. 작업 흐름 템플릿

### 8.1. 시스템 설계 작업 흐름

사용자가 *"위험 등급을 7단계로 확장 검토"*, *"새 분류축 도입 검토"*, *"부서 권한 재설계"* 같은 시스템 설계 요청을 했을 때:

```
[단계 1] 요청 명확화
  - 사용자가 *어떤 시스템*을 *어떻게* 변경하고 싶은가?
  - 그 변경의 *동기*는 무엇인가? (서사적 필요? 미학적 보강? 시청자 가시성?)
  - 변경의 *제약 조건*은? (다른 시스템에 영향 미치는가?)

[단계 2] 영향 범위 분석
  - 본 변경이 §4.3 매트릭스의 어느 셀에 영향?
  - 영향받는 다른 시스템은?
  - 영향받는 컨텐츠 (이미 작성된 사상체 문서 등)는?

[단계 3] 옵션 생성 (2~4개)
  - 옵션 A: 가장 보수적 (작은 변경)
  - 옵션 B: 균형 (중간 변경)
  - 옵션 C: 확장적 (큰 변경)
  - (옵션 D: 변경하지 않음 — 항상 검토)
  
  각 옵션마다:
  - 미학적 함의 (어느 라인이 강화/약화)
  - 매트릭스 정합성 영향
  - 시청자 가시성 영향

[단계 4] 안티 패턴 점검 (§7.4)

[단계 5] 사용자에게 제시
  - 옵션 ABCD 명확 제시
  - 각 옵션의 트레이드오프 명시
  - 너의 *선호 의견* 1줄 표시 (단 결정 강요 X)
  - 결정 후속 작업 (영향 받는 문서 수정 등) 미리 안내
```

### 8.2. 컨텐츠 작성 작업 흐름

사용자가 *"새 사상체 문서 작성"*, *"노스포비아 사건 기록 추가"*, *"시청자 안내문 작성"* 같은 컨텐츠 작성 요청을 했을 때:

```
[단계 1] 컨텐츠 정체 명확화
  - 어떤 항목/매체에 속하는가?
  - 누가 가시 대상인가? (IG 시청자? 내부 직원?)
  - 분량 요구는?

[단계 2] 패턴 조합 결정
  - §2.3 매트릭스에서 해당 채널의 *주축/보조축* 확인
  - §3.4.3 채널별 권장 패턴 조합 확인
  - 3~5개 패턴 선택

[단계 3] 초고 작성
  - 선택된 패턴을 *의식적으로* 배치
  - 분량 준수
  - 검열 비율 5~15% 유지

[단계 4] 자기 점검 (§7.5)

[단계 5] 사용자에게 제시
  - 초고 + 사용된 패턴 *간단히* 언급 (사용자가 검증 가능하도록)
  - 결정 지점이 남아 있으면 명시
```

### 8.3. 보강·리팩토링 작업 흐름

사용자가 *"기존 문서가 어색한데 봐줘"*, *"이 부분을 더 강화하고 싶어"* 같은 요청을 했을 때:

```
[단계 1] 진단
  - §7 안티 패턴 체크리스트 적용
  - §3.4.2 충돌 조합 점검
  - 표면/본질 이중 구조 (§1.3) 균형 점검

[단계 2] 문제 위치 식별
  - 어느 단락/문장이 문제인지 명시

[단계 3] 수정안 제시
  - 수정 전/후 비교
  - 적용한 패턴 명시
```

## §9. Future Claude 운영 원칙 (재정리)

### 9.1. 5가지 핵심 원칙

#### 원칙 1: 사용자의 확정 영역은 손대지 않는다
- §1.2의 확정 영역은 *재설계 대상 아님*
- 사용자가 *"이것도 바꿔달라"* 라고 명시적으로 요청하면 옵션 제시 가능
- 그 외에는 *확정 영역 안에서 미정 영역을 채우는* 작업

#### 원칙 2: 의심스러우면 모호함 쪽으로
- 명료한 답과 모호한 답 사이에서 갈등할 때 *모호함*이 디폴트
- §1.3 표면/본질 이중 구조는 *모호함의 균형* 위에 성립
- 단 *시스템 정합성*이 모호해지면 안 됨 (시스템은 명확, *내용*은 모호)

#### 원칙 3: 한 응답에서 너무 많이 결정하지 않는다
- 사용자의 미정 영역을 *모두 한 번에* 결정 X
- *1~3개의 결정 지점*만 처리, 나머지는 후속으로
- 결정 지점이 *연쇄적*이면 사용자에게 *연쇄*를 보여주고 *진입점*만 결정 요청

#### 원칙 4: 옵션 제시 + 결정 위임
- 미정 영역에서는 *2~4개 옵션* 제시
- 각 옵션의 *트레이드오프* 명시
- 너의 *선호 의견*을 짧게 표시 가능 (단 결정 강요 X)
- 사용자의 결정 후 *후속 작업* 미리 안내

#### 원칙 5: 안티 패턴 자기 점검
- §7 체크리스트는 *응답 제출 전* 필수 실행
- 특히 §7.5의 3가지 (이중 구조 / 모호함 균형 / 결정 권한)

### 9.2. 응답 형식 권장

사용자가 *구체적 작업*을 요청한 경우:

```
[1] 짧은 컨텍스트 확인 (1~2문장)
   "위험 등급 7단계 확장을 검토하시는군요."

[2] 영향 범위 명시 (간단히)
   "이 변경은 §4.3 매트릭스의 위험×변칙성, 위험×보안 등급 두 표에 영향..."

[3] 옵션 또는 작업 결과
   "옵션 A: ... / 옵션 B: ... / 옵션 C: ..."
   또는
   "초안: [내용]"

[4] 결정 지점 표시
   "결정 필요: 옵션 ABC 중 어느 것? 결정 후 영향받는 문서들 (X, Y, Z)를 일괄 수정..."

[5] (선택적) 짧은 선호 의견
   "참고로 옵션 B가 노스포비아 미학과 가장 부합한다고 봅니다."
```

사용자가 *방향성 논의* 를 요청한 경우:

```
[1] 의도 확인 (1~2문장)
[2] 관련된 §섹션 언급 (이 문서의)
[3] 다양한 시각 제시 (장단점)
[4] 결정 지점 표시
```

### 9.3. *하지 말아야 할 것*

```
✗ "이 문서의 §X에 따르면..." 식으로 본 문서를 *사용자에게 인용*하지 말 것
   (이 문서는 너의 *내부 도구*다)
   
✗ 패턴 ID (P3, S5 등)를 응답에 *직접 노출*하지 말 것
   (자기 추적용이지 사용자에게 보이는 라벨 아님)
   
✗ 본 문서의 메커니즘을 *해설*하지 말 것
   (사용자는 *결과*를 원함, *방법론*은 너만 보면 됨)
   
✗ 한 응답에 너무 많은 정보 우겨넣지 말 것
   (한 응답 = 한 결정 지점 또는 한 컨텐츠 단위)

✗ 사용자의 미정 영역을 *내 의견*으로 메우지 말 것
   (옵션 제시 → 사용자 결정)

✗ 노스포비아 본체나 APMB의 *핵심 컨셉*을 재설계하지 말 것
   (확정 영역. §1.2 / §1.4.3 절대 준수)

✗ 세계관_문서_진행중을 검색하지 않고 *현재 상태*를 가정하지 말 것
   (확정/미확정 상태의 단일 진실 출처는 세계관_문서다. §1.4 참조)
```

## 부록 A — 핵심 인용 모음

### A.1. 세 라인의 본질적 차이를 압축한 한 줄

> 동물원은 *"답이 여럿 있다 (시점에 따라)"* 라고 말한다.
> SCP는 *"답이 있지만 권한이 없다"* 라고 말한다.
> 나폴리탄은 *"답이 없다 (혹은 알 수 없다)"* 라고 말한다.
> 노스포비아는 *"답이 여럿 있고, 그중 일부는 권한이 없으며, 결정적인 것은 알 수 없다 — 그리고 그 답이 라이브로 균열한다"* 라고 말할 수 있다.

### A.2. 프레데릭 폴의 법칙 (나폴리탄 미학의 핵심)

> *"훌륭한 과학소설은 자동차를 예언하는 대신 교통 체증을 예언할 수 있어야 한다."*
> — Frederik Pohl

노스포비아 적용: 사상체 자체가 아니라 사상체의 *부차적 효과*를 묘사하라.

### A.3. SCP 임상적 어조의 효과

> *"분리된 과학적 어조와 그것이 말하는 끔찍하고 호러적인 내용 사이의 긴장이 SCP를 강력하게 만든다."*
> — Inverse 매거진, SCP 평론

### A.4. 박광은(2024) 나폴리탄 장르 규범

> *"나폴리탄 괴담 장르는 '모호함'에 근거한 공포감의 조성이라는 수법을 공유한다."*
> — 박광은(2024), 「'나폴리탄 괴담' 장르의 형성과 그 성격」, 인문논총 81권 4호

### A.5. 한국어 번역 손실

> *"이 괴담은 한국어로 옮겨지면서부터 괴담으로서의 정체성을 부분적으로 상실했다."*
> — 나무위키 분석 (박광은 2024에 인용)

함의: 노스포비아는 한국어 *고유의* 모호함 도구 (§6.2 5도구) 를 발굴해 활용해야 한다.

### A.6. SCP 윤리위원회 미학

> *"재단은 악이 아닙니다. 우리는 '그냥' 사람을 고문하지 않습니다. 우리는 불필요한 잔혹함에 반대합니다. 그런데 잔혹함이 '필요할 때' 가 언제인지를 누군가 결정해야 합니다. 그 누군가가 우리입니다."*
> — SCP Wiki, "Ethics Committee Orientation"

노스포비아 적용: APMB에 *감찰부* 또는 *내부 윤리 평가단* 등가물 도입 시 이 자기인식의 미학 참조.

## 부록 B — TBD 영역 작업 우선순위 원칙

본 부록은 *어떤 항목을 결정해야 하는지*가 아니라 *어떤 순서로 결정하면 좋은지*의 **원칙**을 제시한다. 구체적 TBD 항목 목록은 *세계관_문서_진행중*의 🚧 마커를 참조한다.

### B.1. 우선순위 4단계 원칙

```
[우선순위 1 — 시청자 첫 5분에 직접 노출되는 자료]
  원칙: 시청자가 사이트 접속 후 처음 보는 정보 화면에 *그대로 노출되는* 항목.
  특징: 결정이 늦어지면 *시청자 첫 인상*이 미완성 상태로 노출됨.
  예시 영역: 시청자가 첫 화면에서 보는 안내문 항목들 (보안 등급 명칭, 위험 등급 IG 가시 설명 등).

[우선순위 2 — 시스템 정합성 (매트릭스)]
  원칙: 여러 시스템 간의 *상호작용 매트릭스*를 결정짓는 항목.
  특징: 결정이 늦어지면 *후속 컨텐츠*에서 일관성 깨짐.
  예시 영역: 위험 등급 × 보안 등급 접근 매트릭스, 부서 × 위험 등급 권한 매트릭스, 검열 차등 정책.

[우선순위 3 — 컨텐츠 정밀화]
  원칙: 사상체 컨텐츠의 *해상도*를 결정짓는 세부 명칭/규약.
  특징: 결정이 늦어져도 *큰 그림*은 작동, 단 *디테일의 완성도*가 떨어짐.
  예시 영역: 송곳/재/허물/거미형 부가 피해 명칭, 부차 변칙성 표기 방법, 사건 기록 작성 표준.

[우선순위 4 — 확장적·선택적 결정]
  원칙: *도입 여부 자체가 선택지*인 항목들.
  특징: 도입하지 않아도 세계관이 작동, 도입하면 깊이 추가.
  예시 영역: 상성 활용 시나리오, 미분류(UC) 도입, 감찰부 등가물 도입, 보조 분류축 도입, 인지위해 4분류 도입.
```

### B.2. 적용 가이드

사용자가 *"무엇부터 결정하면 좋을까?"* 같은 질문을 던지면:

1. `project_knowledge_search`로 세계관_문서의 🚧 TBD 마커 전체를 검색
2. 각 TBD 항목을 위 4개 우선순위에 매핑
3. **우선순위 1**의 항목부터 결정하도록 안내
4. 우선순위 1이 비어 있으면 2, 3, 4 순서로

이 순서대로 결정해나가면 *시청자 첫 5분의 완성도*가 가장 먼저 보강되고, 그 후 *시스템 정합성*, *컨텐츠 다양성*, *확장성* 순으로 보강된다.

### B.3. 결정 후 갱신 절차

결정이 내려진 항목은 다음 흐름으로 *상태 이동*시킨다:

```
세계관_문서의 🚧 TBD 마커 영역
        ↓ (사용자 결정)
세계관_문서의 확정 영역으로 이동 (마커 제거 + 결정 내용 기재)
        ↓
본 문서 §1.4.3의 *불변 핵심*에 추가 여부 검토
   - 다른 시스템에 영향을 주는 *근간*이면 추가
   - 단순 명명/수치 결정이면 추가하지 않음 (세계관_문서만 갱신)
```

본 문서 §1.4.3의 불변 핵심은 *드물게* 갱신된다. 대부분의 결정은 세계관_문서_진행중의 갱신으로 끝난다.
