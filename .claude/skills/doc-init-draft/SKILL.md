# doc-init-draft — 사상체 문서 초안 생성 스킬

## 목표

사용자의 *raw 컨셉·레퍼런스*를 *사상체 정의(`lore/사상체_정의_*.md`)의 표준을 따르는 사상체 문서의 5개 항목 초안*으로 변환한다. 초안은 *완벽한 최종본*이 아니라 *피드백 루프의 시작점*이다.

## 사전 조건

다음을 *반드시* 사전에 확인한다:

1. **방법론 문서 정독**: `patterns/방법론_통합방법론_*.md`의 최신 버전을 *읽지 않았다면* 먼저 정독한다. 특히:
   - §0~§1: 작업 방법론 도구상자 개요 및 패턴 체계
   - §3: 나폴리탄·격리픽션·규칙괴담 연출 패턴 (S 시리즈) — 변칙 현상·격리 절차·대응 지침 작성의 핵심 참조

2. **사상체 정의 문서 정독**: `lore/사상체_정의_*.md`의 최신 버전을 *읽지 않았다면* 먼저 정독한다. 특히:
   - §1~§5: 사상체 개념·변칙성 분류·위험 등급·식별 코드
   - §6.1: 사상체 문서 표준 frontmatter (12 필드)
   - §6.3: 변칙 현상 작성 6요소 권장 골격
   - §6.4: 인용 표기 규칙
   - §6.5: 문체 가이드
   - §6.5.1.1: 호명체 어미 변형 가이드
   - §6.6, §6.7: 사건 기록의 흔적 원칙·작성 표준
   - §7: 사상체 공식 문서의 톤과 미학

3. **세계관 설정 정독**: `lore/세계관_설정_*.md`의 최신 버전을 *읽지 않았다면* 먼저 정독한다. 특히 §2 (관리국 본질·표면/본질 거울 구조).

4. **프로젝트 의도 정독**: `planning/프로젝트_의도_*.md`의 §3 노스포비아 캐릭터 톤 — 신규 사상체도 *같은 미학 원리*를 공유한다.

5. **대응 지침 설계 표준 정독**: `patterns/대응지침_설계.md`의 최신 버전(v2.0 이상)을 *읽지 않았다면* 먼저 정독한다. *대응 지침 항목 전용 표준*이며, 다른 4항목은 본 문서의 적용 대상이 아니다. 특히:
   - §0: 본 문서의 정체 — *서사→플롯→번호* 3단계 변환 흐름 + 5대 원칙
   - §1: 세 장르의 서사 구조 (격리픽션·나폴리탄·규칙괴담의 합금) + §1.4.1 한국형 임상/일상 동거
   - §2: 매체적 특성 + §2.4 위반 결과 우회 4종 양태 + §2.5 이중 시간축 + 4종 시간차 양태
   - §3: 1단계 서사 설계 — 추론 표적 3층 분포 + §3.3.1 공간 = 의례 위계 분류
   - §4: 2단계 플롯 분해 — 4막 경계 / 사이드 3유형·2형식 / 시점 모듈 + §4.4.1 시점 위치 3종
   - §5: 3단계 번호 변환 — §5.2 호출 어휘 4종 표준 / §5.4.1 호명체 비율 차등 / §5.6 5종 음각 환기 도구함
   - §6.1: 플롯 시트 표준 템플릿
   - §7.6: 노스포비아 미학 대립 배제 자리 4항목
   - §7.7: 작성 완료 전 자기 점검 15항목

## 작업 단계

### 1단계: raw 분석

- 사용자가 지정한 raw 문서(또는 docs/raw/ 전체)를 정독.
- 핵심 컨셉 요소를 추출:
  - 형태 유형 (인간형/동물형/사물형/이계형/변화형/무형 중 하나)
  - 주요 변칙성 (나방/궤/송곳/재/허물/거미 중 하나)
  - 부차 변칙성 (있으면)
  - 위험 등급 (Ks/Bh/Aj/Ni/Ka — raw 분석에서 *피해 규모 추정*으로 판단)
  - 사상체의 *표면*과 *본질* (이중 구조 — 사상체_정의 §7.3 참조)

### 2단계: 폴더·파일 생성

- `docs/working/<순서코드>/` 폴더 생성
- 5개 항목 파일과 5개 빈 피드백 파일 생성

### 3단계: 5개 항목 작성

**개요 (`<순서코드>_개요.md`)**:
- frontmatter (사상체 정의 §6.1.1의 12 필드, 알 수 없는 필드는 검열 처리)
- `## 개요` 표 (메타정보)
- `### 파생 개체` (있을 시)
- `### 설명` (산문형 — 사상체 정의 §6.2.2의 4요소 권장 골격)

**변칙 현상 (`<순서코드>_변칙현상.md`)**:
- `## 변칙 현상` 헤더
- 각 양상마다 사상체 정의 §6.3의 6요소 권장 골격
- 사상체에 맞는 양상 수 (단순한 사상체는 2~3개, 복잡한 사상체는 5~8개)

**격리 절차 (`<순서코드>_격리절차.md`)**:
- `## 격리 절차` 헤더
- *현황 서술* 문단은 보고체, *지침* 문단은 호명체 (사상체 정의 §6.5.1.1 어미 변형)
- 격리 시설의 형태·접근 권한·상호작용 시간 제한 등

**대응 지침 (`<순서코드>_대응지침.md`)**:

대응 지침은 *5항목 중 유일하게 서사 곡선을 가지는 항목*이다. 다른 4항목과 *작성 방식이 본질적으로 다르며*, `patterns/대응지침_설계.md` v2.0의 *서사→플롯→번호* 3단계 흐름을 따른다.

**0단계 — 플롯 시트 작성 (필수 선행)**:

본문 작성 *전에* 플롯 시트를 먼저 작성한다. 대응지침_설계 §6.1의 표준 템플릿을 따라 `<순서코드>_대응지침_플롯시트.md`를 생성:

- frontmatter 9 필드: 사상체·일차 청자·작성 단계·시점 모듈·공간 유형·주력 시간차 양태·주력 검열 양태·주력 위반 결과 우회 양태·호명체 비율 가정
- §1 서사 설계: 추론 표적 3층 분포(60/30/10) + 3차원 분포(공간/시간/시리즈) 메모 + 1~4막(옵션 5막) 자유 서술 + 사이드 후보 + 시점 모듈 후보(시점 종 1·2·3 분류) + 시간축 명세
- §2 번호 분할: 4막 경계 §M₁~§M₄ + 메인 라인 항목 명세 표 + 사이드 분기 명세 + 시점 모듈 명세 + 검열 양태 명세 + 외부 시간 매체 배치

**1단계 — 서사 설계의 핵심 결정**:

플롯 시트의 §1 작성 시 다음 7가지를 결정 (대응지침_설계 §3.4 완성 신호):

1. *추론 표적 3층* (1층 표면 60% / 2층 대조 30% / 3층 미지 10%) + 3차원 분포(공간/시간/시리즈)
2. *공간 유형* (§3.3.1) — 학교·열차·마트·성당·병원·호텔·카지노/시험장 중 1종, 또는 비위계 공간 (방송 매체는 노스포비아 차별화 자리)
3. *주력 시간차 양태* — 다일자 누적 / 단일 일자 분할 / 응축 비선형 / 시간 정지 (디폴트=시간 정지)
4. *주력 위반 결과 우회 양태* — 반복 정형구 / 변주형 완곡어법 / 사례 누적형 / 결과 완전 부재형
5. *주력 검열 양태* — 5종 음각 환기 도구함(부분 검열·결번·메타 균열·부재형 군림·자모 깨짐·수치 ???)에서 2~3종 조합
6. *호명체 비율* — 메인 라인 디폴트 70~95%
7. *사이드 후보 1~2개* + (옵션) 시점 모듈 후보 + 시점 종 분류

**2단계 — 번호 분할**:

플롯 시트의 §2 작성:

- 4막 경계는 *번호 차수가 아닌 상황 전제로 위장* (§4.1) — 1막→2막: *"본 사상체 경계 안으로의 진입이 어떠한 사유로든 성립한 경우"* 양태
- 막별 분량·밀도 차등 (1막=1~2문장 → 4막=1문단 밀도 높게)
- 사이드 3유형(독립/보강/분기) × 2형식(파생 번호형 §N-1 / 플롯 점프형) 조합
- 시점 모듈 차수는 *홀수 차수* (§3001/§5001/§7001) — 짝수 차수는 *향후 자리*로 비움

**3단계 — 본문 작성**:

`<순서코드>_대응지침.md`에 다음 표준 적용:

- `## 대응 지침` 헤더
- 번호 형식: `§1`부터 자연 연속, **자릿수 패딩 없음** (`§001` X, `§1` O), 천 단위 구획 *없음*
- 메인 라인 §1~§M(자연 연속) + 사이드 영역은 *비연속 점프*로 건너뛰기 + 시점 모듈은 §3001+/§5001+/§7001+
- §1은 *진입 호명 + 시점 모듈 안내* 자리 (시점 모듈 진입 호출 어휘는 §1에만)
- 전체 *경어 명령형* (`~하십시오`) 디폴트, 시점 모듈 한정으로 보고체·회상체 진입 허용 (§5.4.1 비율 30% 이하 구간)
- 호출 어휘 4종 (§5.2) — 표준 양태:
  - 조건 분기 호출: *"[조건절 — 모호하게] §N번 지침으로 이동하십시오"*
  - 메인 플롯 점프 호출: *"본 지침까지 무사히 수행했다면 §N번 지침으로 이동하십시오"*
  - 사이드 복귀 호출: 메인 플롯 점프와 동일 형식
  - 시점 모듈 진입 호출: *"본국의 [시점 분류] 인원으로 본 문서를 열람하는 인원은 §N번 지침을 우선 참조하십시오"*
- 조건절은 *모호한 어휘* (§5.3) — *"§3을 따랐다면"* (X) → *"무사히 수행했다면"* (O). 부분 주관 의존(*인지 안에 안정적으로 형성된 시점부터*) 허용, 완전 주관 의존(*기분에 따라*) 배제
- 위반 결과는 *직접 명시 금지* — 4종 우회 양태로 환기 (§2.4)
- 외부 시간 매체 1~3종을 본문에 노출 (§2.5.3) — 갱신 메모·시각 스탬프·권위자 서명·수색 차수·후일담 각주 중 선택
- 검열 5종 도구함의 2~3종 조합 (§5.6) — 부분 검열이 기본, 결번 5~30% 권장 구간
- 4막 라벨·천 단위 차수·*"이제 비상 절차"* 같은 *서사 구조 자체의 본문 노출 금지*

초안 시 분량 권장: 단순 사상체 §1~§30, 표준 사상체 §1~§60, 복잡 사상체 §1~§100+. 1037 재배치는 60항목+결번3 규모가 기준점.

**초안 한정 자율 결정**: 위 7가지 1단계 결정은 raw 분석에서 *합리적 추정*으로 자율 결정 가능. 단 결정 사항을 *플롯 시트 frontmatter에 명시*해 사용자가 피드백으로 변경 가능하게 한다.

**사건 기록 (`<순서코드>_사건기록.md`)**:
- `## 사건 기록` 헤더
- 사건 기록 일람 표
- 최소 1개의 사건 기록 본문 (사상체 정의 §6.6 흔적 원칙)
- 사상체에 맞는 기록 수와 종류 (사건 로그/면담록/탐사자 보고/연구 메모)

### 4단계: 빈 피드백 파일 생성

각 항목별로 다음 표준 형식으로 빈 피드백 파일 작성:

```markdown
# <항목명> 피드백 (순서코드: <순서코드>)

## 처리 대기

## 처리 완료
```

### 5단계: 자기 점검

#### 5.1. 공통 자기 점검 (사상체 정의 §7.4)

전체 산출물(5개 항목)에 다음 점검 적용:

- [ ] frontmatter 12 필드가 모두 채워졌는가 (불명은 검열)
- [ ] 본문 4항목이 모두 존재하는가 (개요·변칙현상·격리절차·사건기록)
- [ ] 변칙 현상이 §6.3 6요소 권장 골격을 따르는가
- [ ] 인용 표기가 §6.4 규칙을 따르는가
- [ ] 문체가 §6.5 분리를 따르는가 (보고체 / 호명체 / 어미 변형)
- [ ] `~요` 체가 사용되지 않았는가
- [ ] 영단어 배제 (메커니즘/매트릭스/모니터링/프로토콜)가 자연스럽게 적용되었는가
- [ ] 사건 기록의 흔적이 최소 1개 존재하는가
- [ ] 검열 비율이 5~15% 범위인가 (시각적 추정)
- [ ] 관리국 본질의 미세 노출이 1~2회를 넘지 않는가
- [ ] 표면/본질 이중 구조가 흔적으로라도 존재하는가

#### 5.2. 대응 지침 한정 자기 점검 (대응지침_설계 §7.7)

대응 지침 항목과 플롯 시트에 다음 15항목 적용:

- [ ] 4막 구조가 *세계관 내적 위장 도구로 표현*되었는가 (번호 차수가 아닌 상황 전제로)
- [ ] 사이드 분기의 *3가지 유형 중 적어도 하나*가 의식적으로 적용되었는가
- [ ] 추론 표적 1·2·3층 분포가 *플롯 시트에 명시*되고 3차원 분포(공간/시간/시리즈) 메모가 작성되었는가
- [ ] 호출 어휘 4종의 *조건절*이 *모호한 어휘*인가
- [ ] 한 항목 전체가 *[기밀 분류]*로 가려진 자리가 *없는가*
- [ ] 시점 모듈이 있다면 *§1의 진입 호명*에서 명시 호출되고 시점 종(제1·2·3) 분류가 명시되는가
- [ ] 플롯 시트의 *2단계 번호 분할*과 본문의 *§번호*가 일치하는가
- [ ] 위반 결과가 *간접 표현*으로 우회되고 4종 양태(§2.4) 중 주력 1종이 일관 적용되었는가
- [ ] 4막의 *분량·밀도 차등*이 자연 곡선을 그리는가
- [ ] 공간 유형(§3.3.1)이 결정되고 *의례 위계 = 생존 통화*가 1막에 명시되는가 (비위계 공간은 대체 변수 명시)
- [ ] 주력 시간차 양태(§2.5.2)가 결정되고 외부 시간 매체 1~3종이 본문에 노출되는가
- [ ] 검열 양태가 *5종 도구함*의 *2~3종 조합*인가 (전 5종 동시 사용 회피)
- [ ] 결번 비율이 *5~30% 권장 구간*인가 (60% 초과는 안티 패턴)
- [ ] 호명체 비율이 사상체 매체체와 부합하는가 (메인 라인 디폴트 70~95%)
- [ ] §7.6 배제 자리 4항목이 모두 회피되었는가 (권위자 사적 관계·적측 권위 전유·직설 인터넷 어휘·완전 주관 의존)

자기 점검 결과는 *결과 보고에 통과/부분/미적용 분류로 명시*해 사용자가 피드백 자리를 식별 가능하게 한다.

## 작업 가이드

### 창작과 보충

raw 문서에 *모든 정보가 있는 것은 아니다*. 다음 정보는 *창작·보충*이 필요할 수 있다:

- 식별코드의 *순서코드 4자리* — 사용자 지정 또는 자동 랜덤
- 격리 시설의 *구체 형태* (raw에 없으면 사상체 유형에 맞게 창작)
- 사건 기록의 *최초 발견 경위* (raw에 없으면 컨셉에 맞게 창작)
- 위험 등급 *수치 평가* (raw의 *피해 규모 추정*으로 결정)

*외부 자료 조사*가 필요하다면 web 도구를 활용한다 (예: 사상체 컨셉의 유래가 되는 *민속·역사적 사례* 조사).

### 톤·미학의 일관성

신규 사상체는 *노스포비아와 같은 세계관에 속한다*. 따라서:

- 관리국 APMB의 *건조하고 형식적인 어조* (사상체 정의 §7.1)
- 검열의 미학적 사용 (§7.2)
- 관리국 본질의 미세 노출 (§7.3 — 1~2회)
- 표면/본질 이중 구조 (세계관 설정 §2.1의 거울 구조)

## 안티 패턴

다음을 *하지 말 것*:

### 공통 안티 패턴

- ❌ **완벽주의** — 초안은 피드백 루프의 시작점이다. *완벽한 최종본을 시도*하다가 작업이 지연되는 것은 시스템 의도에 반함.
- ❌ **표준 외 항목 추가** — 5개 항목 외에 자의적으로 다른 항목을 만들지 않는다. (단 대응 지침 플롯 시트는 *내부용 보조 파일*이므로 산출물에 포함된다.)
- ❌ **시스템 정의의 무시** — *창작 자유도*가 *형식 정합성*을 무시하는 것을 의미하지는 않는다. §6 표준을 준수.
- ❌ **노스포비아의 통째 모방** — 컨셉·구조·표현을 그대로 복사하지 않는다. 사상체별 *고유성*이 컨텐츠의 가치.
- ❌ **사용자 결정 권한 침해** — *🚧 TBD* 영역으로 두어야 할 미결정 사항을 임의로 결정하지 않는다. 모호한 영역은 *검열 처리* 또는 *불확정 어미*로 표현.

### 대응 지침 한정 안티 패턴 (대응지침_설계 §7.1~§7.6)

- ❌ **번호 자릿수 패딩** — `§001`·`§0150` 같은 패딩 사용 (`§1`·`§150`이 정답)
- ❌ **천 단위 구획 노출** — 메인 라인을 *§1000번대 = 2막* 같은 외부 라벨로 노출
- ❌ **막 전환의 명시적 안내문** — *"이제 본 사상체의 비상 시 절차를 안내한다"* 같은 서사 구조 자체의 본문 노출
- ❌ **사이드 분기 사전 통보** — *"다음 §150은 사이드 분기"* 같은 메타 안내
- ❌ **시점 모듈을 짝수 차수에 배치** — §2001·§4001 등은 *향후 추가 모듈의 잠재적 자리*로 비워둔다. 홀수 차수(§3001/§5001/§7001)에만 시점 모듈 배치.
- ❌ **분기 조건절의 명료화** — *"§3번을 따랐다면"*·*"§N의 조건이 충족되었다면"* 같은 측정 가능한 어휘. 모호한 어휘(*무사히 수행했다면*·*인지 안에 안정적으로 형성된 경우*)로 변환.
- ❌ **위반 결과 직접 명시** — *"~하면 사망합니다"*·*"끔찍한"*·*"~의 메메틱 효과로 인해"* 같은 직접 어휘. 4종 우회 양태로 환기.
- ❌ **완전 주관 의존 분기** — *관리인의 기분에 따라*·*분위기에 따라*·*그날의 운에 따라*. 부분 주관 의존(*인지 안정성·상식·사유·외형*)은 허용.
- ❌ **권위자 사적 관계의 본문 상세 노출** — *가죽끈 반지·부부 관계*·사적 친밀 묘사. *서명체 메모 한 줄*은 허용.
- ❌ **직설적 인터넷 어휘** — *미라클 모닝·대박좋다·고용노동부 신고 감·자본주의의 더러운 노예*. 완곡한 자조 어휘로 변환.
- ❌ **적측의 권위 매체 전유를 메인 라인에 도입** — 대응 지침의 권위 자체를 무력화하는 자리. 시점 모듈·사이드 한정 도입 가능.
- ❌ **전체 항목 [기밀 분류] 가림** — Level IG 탐사자가 *계약직으로서 대응 지침 숙지가 필요*하므로 세계관 내적 부자연. 부분 검열만 사용.
- ❌ **결번 비율 60% 초과** — *답안지 잔존 사료적 극단*. 5~30% 권장 구간.
- ❌ **5종 음각 환기 전 종 동시 사용** — 시각적 산만. 2~3종 조합이 권장.
- ❌ **호명체 비율 30% 미만의 메인 라인** — *임상 어조 위장이 무너짐*. 시점 모듈 한정 허용.
- ❌ **외부 시간 매체 부재** — 갱신 메모·시각 스탬프·권위자 서명·수색 차수·후일담 각주 중 *1종 이상은 본문에 노출* 필요. 단일 평탄 시간축은 *살아 있는 문서* 효과 부재.
- ❌ **1단계 자유 서술 생략** — 플롯 시트 §1 자유 서술 없이 §2 번호 분할부터 시작하면 *번호 분할이 추론 표적과 어긋남*.
