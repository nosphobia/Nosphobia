# /doc-init — 사상체 문서 초안 생성

## 인자

- `$1` *(선택)* — docs/raw 폴더 내 사용자 문서 경로 (예: `@docs/raw/강아지형.md`)
- `$2` *(선택)* — 4자리 순서코드 ID. `랜덤` 지정 시 자동 생성

## 인자 해석 규칙

| 입력 패턴 | 동작 |
|---|---|
| `/doc-init <경로> <4자리 숫자>` | 지정 문서 + 지정 ID |
| `/doc-init <경로> 랜덤` | 지정 문서 + 자동 랜덤 ID |
| `/doc-init <경로>` | 지정 문서 + 자동 랜덤 ID (ID 생략은 랜덤으로 해석) |
| `/doc-init` (인자 없음) | docs/raw/ 폴더의 모든 `.md` 파일 통합 분석 + 자동 랜덤 ID |

## 활성화할 스킬

**`doc-init-draft`** — 본 명령어가 호출되면 위 스킬이 활성화되어 LLM의 작업 흐름을 안내한다. 자세한 작업 단계·체크리스트·도구 호출 패턴은 스킬 정의 참조.

## 사용 모델

**Opus** — 대규모 창작 + 정합성 점검 + 외부 자료 조사가 한꺼번에 일어나므로.

명령어 실행 시점에 현재 모델이 Opus가 아니라면 사용자에게 모델 전환을 권장한 후 진행 여부 결정.

## 산출물

`docs/working/<순서코드>/` 폴더에 10개 파일:

| 항목 파일 | 피드백 파일 |
|---|---|
| `<순서코드>_개요.md` | `<순서코드>_개요_fb.md` |
| `<순서코드>_변칙현상.md` | `<순서코드>_변칙현상_fb.md` |
| `<순서코드>_격리절차.md` | `<순서코드>_격리절차_fb.md` |
| `<순서코드>_대응지침.md` | `<순서코드>_대응지침_fb.md` |
| `<순서코드>_사건기록.md` | `<순서코드>_사건기록_fb.md` |

## 예외 처리

- **docs/raw/ 폴더가 비어있고 인자도 없음**: 처리 중단. 사용자에게 raw 폴더에 컨셉 문서를 먼저 작성하도록 안내.
- **지정한 ID가 이미 존재하는 사상체와 충돌**: 처리 중단. 다른 ID 또는 `랜덤` 사용 권장.
- **docs/working/<순서코드>/가 이미 존재**: 처리 중단. 작업 중인 사상체가 있음을 알리고, 기존 작업 완료 후 재시도 또는 다른 ID 사용 권장.
- **지정한 raw 문서가 존재하지 않음**: 처리 중단. 정확한 경로 안내.
