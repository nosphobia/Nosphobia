# /doc-ig — 사상체 문서 확정·통합

## 인자

- `$1` *(필수)* — 4자리 순서코드 (예: `0341`)

## 사용 모델

**Sonnet** — 자동 검증 단계에서만 LLM 사용. 통합·인덱싱은 프로그램 단독.

## 실행 흐름

LLM은 다음을 순차 실행한다.

### 1. 입력 검증

- `$1`이 4자리 숫자인지 확인.
- `docs/working/<순서코드>/`가 존재하는지 확인. 없으면 중단.
- 5개 항목 파일이 모두 존재하는지 확인.

### 2. 정합성 검증 (validate.ts 호출)

`infra/tools/scripts/validate.ts` 실행 — `lore/사상체_정의_*.md` §7.4 자기 점검표의 자동 검증 항목을 점검:

- frontmatter 12 필드 충족 여부
- 본문 4항목 중 최소 1개 존재 여부
- 인용 표기 §6.4 규칙 (정규식)
- `~요` 체 미사용
- 영단어 배제 (메커니즘/매트릭스/모니터링/프로토콜 잔존 검색)
- 검열 비율 5~15%
- 사건 기록 흔적 최소 1개

**의미론적 점검** (LLM이 추가 수행):

- 표면/본질 이중 구조의 흔적 존재 여부
- 변칙 현상 §6.3 6요소 권장 골격 준수 여부
- 관리국 본질 노출 1~2회 범위 여부

### 3. 검증 실패 시 분기

- **자동 검증 실패**: 사용자에게 *실패 항목·위치·제안 수정*을 보고하고 *무시하고 진행할지 / 수정 후 재시도할지* 결정 요청.
- **의미론적 점검 경고**: 경고는 *블로커가 아님*. 사용자에게 표시하고 자동 진행.

### 4. 통합 (integrate.ts 호출)

`infra/tools/scripts/integrate.ts` 실행 — 5개 항목 파일을 *고정 순서*로 통합:

1. frontmatter (`<순서코드>_개요.md`에서 추출)
2. `# APMB 사상체 문서` 헤더
3. `## 개요` 영역 (`<순서코드>_개요.md` 본문 — 표 + `### 파생 개체` + `### 설명`)
4. `## 변칙 현상` (`<순서코드>_변칙현상.md`)
5. `## 격리 절차` (`<순서코드>_격리절차.md`)
6. `## 대응 지침` (`<순서코드>_대응지침.md`)
7. `## 사건 기록` (`<순서코드>_사건기록.md`)
8. 문서 종료 안내문

산출물: `docs/entities/사상체_<명칭>_v<X.Y>.md`

- 명칭은 frontmatter의 `사상체 명칭` 필드에서 추출
- 버전은 *기존 archive의 마지막 버전*을 기준으로 자동 증가. 신규 사상체는 v0.1.

### 5. 사상체 목록 갱신 (index-entities.ts 호출)

`infra/tools/scripts/index-entities.ts` 실행 — `docs/entities/사상체_목록.md`를 *완전 재생성*:

- `docs/entities/`의 모든 `사상체_*.md` 파일을 스캔
- 각 파일의 frontmatter를 읽어 메타데이터 추출
- 표 형식으로 일람 작성: 식별코드 / 명칭 / 위험 등급 / 주요·부차 변칙성 / 보안 등급 / 상태 / 마지막 갱신

### 6. 작업 공간 정리

`docs/working/<순서코드>/` 폴더를 다음 중 한 가지 방식으로 처리:

- **삭제** (기본): 작업 완료된 폴더 제거
- **archive 이동**: 사용자가 작업 이력 보존을 원할 때

기본 동작을 선택하되, 사용자에게 *작업 이력 보존 여부*를 한 번 묻고 진행.

### 7. 결과 보고

- 확정된 사상체 문서 경로 (`docs/entities/사상체_<명칭>_v<X.Y>.md`)
- 검증 결과 요약
- 사상체 목록 갱신 결과
- 다음 단계 안내: 향후 수정 필요 시 `/doc-div` 호출

## 예외 처리

- **자동 검증 실패 + 사용자가 진행 거부**: 처리 중단. working/ 폴더 그대로 유지하여 수정 후 재시도 가능.
- **integrate.ts 미구현 상태**: 도구 구현 전까지는 *수동 통합*이 필요함을 사용자에게 알리고, 본 명령어는 *기획만 정의된 상태*임을 명시.
- **명칭 추출 실패**: frontmatter의 `사상체 명칭` 필드 누락. 사용자에게 정정 후 재시도 요청.
- **버전 자동 증가 실패** (archive 누락 등): 사용자에게 *수동 버전 지정* 요청.
