# 나폴리탄 서사기획 파이프라인

> **본 문서의 위상**: 본 문서는 *작업 계획서*이며 *기획서가 아니다*. 무엇을 어떤 순서·단위·형식으로 수행해 어떤 산출물을 만들 것인가를 명세한다. 분석·창작의 *내용* 자체는 본 문서가 결정하지 않으며, 각 단계의 산출물에 위임한다.

---

## §0. 동기와 목표

### 0.1. 출발점

reference/ 폴더에 한국 인기 *나폴리탄/규칙괴담/격리픽션* 장르 작품들이 모여 있다. 본 프로젝트는 이를 *서사 기획 관점*으로 분석하고, 분석 결과를 본 프로젝트의 세계관과 정합시켜 **사상체 문서를 옴니버스 형태로 창작하기 위한 기준 지침서**를 만들고자 한다.

하나의 사상체 문서 = 하나의 옴니버스 작품으로 본다.

### 0.2. 기존 자산과의 차별점

| 자산 종류 | 기존 (`patterns/방법론_*`) | 본 작업 (신규) |
|---|---|---|
| 분석 시점 | *장르가 어떻게 작동하는가* | *우리가 이 장르의 작품을 어떻게 쓸 것인가* |
| 분석 결과 | 메커니즘 일반론 | 노스포비아 세계관 고유의 서사 형태 정의 |
| 활용 형태 | LLM 내부 도구·이해 자료 | *창작 지침* — 사용자와 LLM이 사상체 문서를 쓸 때 직접 참조 |

본 작업의 산출물은 *기존 방법론을 대체하지 않으며*, 그것들을 *전제로* 깔고 *그 위에 노스포비아 세계관 고유의 작법을 정립*한다.

### 0.3. 기존 자산 중 *대응지침_설계.md*와의 관계

`patterns/대응지침_설계.md`(v1.0, 1120줄)는 *사상체 문서의 5항목 중 대응 지침 항목 전용*의 설계 표준이다. 본 파이프라인은 *대응 지침을 포함한 사상체 문서 전체*를 다루므로, 대응지침_설계는 *부분 집합*이 된다. 본 파이프라인의 3단계 산출물(사상체 문서화 정의서)이 대응지침_설계와 *충돌하면 안 되며*, *대응 지침 부분은 대응지침_설계가 그대로 권위를 가진다*.

### 0.4. 매체 한계 선언

본 파이프라인은 *문서 매체에 한정*한다. 노스포비아 프로젝트의 라이브 방송·영상 매체 자산은 본 분석의 범위 밖이다. 영상 매체의 사상체 표현 방법은 별도의 정의서로 다룬다.

---

## §1. 4단계 파이프라인

```
[0단계] 분석 차원 정의서 작성
    ↓
[1단계] 작품별 개별 분석 (한 세션 = 한 작품)
    ↓
[2단계] 횡단 종합 분석
    ↓
[3단계] 사상체 문서화 정의서 (두 층의 한 쌍: 헌장 + 표준)
```

각 단계의 *입력·작업 단위·출력·세션 수*가 명확히 분리되어 있다. 한 단계가 완결되어야 다음 단계가 시작된다 (1단계 내부의 8개 작품 분석 세션들은 서로 독립이므로 병렬 가능).

## §2. 0단계 — 분석 차원 정의서

### 2.1. 산출물

`patterns/서사기획_나폴리탄/00_분석차원_정의.md`

### 2.2. 내용

다음 11개 차원 각각에 대한 *정의·관찰 포인트·예시 질문*을 명세한다. 그리고 1단계 작품별 분석 문서의 *템플릿*을 정의한다.

**합의된 11개 분석 차원**:

1. 화자·시점
2. 포맷·매체 의장
3. 서사 구조
4. 세계관 노출 방식
5. 위협의 형상
6. 인물 처리
7. 정서적 거리·톤 변조
8. 규칙·금기의 작동 방식
9. 시간 처리
10. 여백·모호함의 양
11. 문체·문법·리듬

본 11개 차원은 *11이라는 수가 본질이 아니다*. 1단계 분석 중 *차원의 추가·합병이 시사*되면 본 문서는 *갱신*된다. 차원의 *고정성*보다 *관찰의 일관성*이 우선이다.

### 2.3. 작품별 분석 문서 템플릿

각 1단계 산출물은 다음 구조를 따른다:

```
# [작품명] 분석

## 메타
- 작품: 
- 분량: 
- 매체:
- 분석 일자:

## 11개 차원별 분석
(차원 1)~(차원 11) 각각:
  - 정의/관찰 포인트 (0단계에서 명세된 가이드)
  - 본 작품에서의 양상
  - 인용·예시
  - 평가/메모

## 자유 관찰란 — 특이사항·인상적 메모
(고정 템플릿이 놓치는 자리를 포착)

## 3단계 정의서 시사점
(이 작품이 우리의 사상체 문서화 정의서에 어떤 기여를 할 수 있는가의 1차 메모)
```

### 2.4. 3단계 정의서 목차 초안 첨부

0단계 산출물 말미에 *3단계 정의서의 목차 초안*을 첨부한다. 이는 분석 작업자(인간 또는 LLM)가 *분석이 무엇을 향해 가는지* 인지하도록 돕는다. 초안이지 확정이 아니다 — 1·2단계의 결과에 따라 조정 가능.

### 2.5. 세션

1세션. 사용자와 함께 작성. 본 파이프라인 합의 이후 가장 먼저 착수.

## §3. 1단계 — 작품별 개별 분석

### 3.1. 작품 단위 (8개)

reference/ 폴더의 자료를 다음 8개 단위로 묶는다:

| # | 작품 단위 | 자료 파일 | 분량 (자) |
|---|---|---|---|
| 1 | 괴이현상_실종자수색연합_본편 | 본편.txt | ~70K |
| 2 | 괴이현상_실종자수색연합_외전 | 수색연_통합_소장본_외전.txt | ~194K |
| 3 | 괴이현상_실종자수색연합_해피에브리데이마트 | 해피에브리데이마트.txt | ~25K |
| 4 | 호텔 비다 (옴니버스 1편으로 통합) | 호텔 비다/*.txt (5개) | ~81K |

| 6 | 초자연현상처리반_귀하는순수한인간입니다 | 귀하는순수한인간입니다.txt | ~11K |

**총 8세션, 약 60만자.**

호텔 비다의 5개 파일은 하나의 옴니버스 안의 *다층 매체*이므로 단일 작품 단위로 본다. 초자연현상처리반은 본편/독립옴니버스/한국총력고등학교가 *서사적으로 분리*되므로 각각 별 작품으로 본다.

### 3.2. 작업 순서 권장

가장 짧고 구조가 명확한 자료부터, 점차 긴 자료로:

```
호텔비다 → 해피에브리데이마트 → 귀하는순수한인간입니다 → 
한국총력고등학교 → 수색연_본편 → 처리반_본편 → 
암흑생맹소탕작전 → 수색연_외전
```

초기 세션이 0단계의 템플릿 실용성을 검증한다.

### 3.3. 산출물

각 세션의 산출물: `patterns/서사기획_나폴리탄/작품분석/작품_<이름>.md` × 8

### 3.4. 한 세션의 입력·출력

- **입력**: 0단계 정의서 + 해당 작품 원문 전체
- **출력**: 11차원 + 자유 관찰란 + 3단계 시사점이 담긴 분석 문서 1개

### 3.5. 1단계 종료 조건

8개 작품 분석이 모두 완료되고, 분석 중 시사된 *차원 추가/조정*이 0단계 정의서에 반영된 시점.

## §4. 2단계 — 횡단 종합 분석

### 4.1. 산출물

`patterns/서사기획_나폴리탄/02_횡단종합.md`

### 4.2. 입력·출력

- **입력**: 1단계의 8개 작품 분석 문서 전체
- **출력**: 11개 차원 각각에 대한 *작품 간 공통점·차이점·스펙트럼* + *장르적 패턴·관습·금기* + *현저한 변주들* + *옴니버스의 정의 검증* (§5.3 참조)

### 4.3. 세션

1세션. 분석 문서들의 합산 분량은 한 세션에 충분히 들어간다 (작품당 분석 문서는 원문보다 짧음).

### 4.4. 옴니버스 정의 검증

본 단계는 *외부 세션 의견(§5.1)*에서 제기된 *옴니버스 정의의 모호성*을 해결한다. 8개 작품의 분석을 토대로, 노스포비아 사상체 문서의 옴니버스가 다음 세 해석을 *어떻게 중첩*하는지를 명시한다:

- 해석 A: 분리된 단편 모음
- 해석 B: 여러 시점·매체·형식의 묶음
- 해석 C: 단일 항목 내부의 메인+사이드 구조

본 파이프라인의 가설은 *세 해석이 층위별로 중첩*되는 것이지만, 이 가설은 *2단계에서 분석으로 검증*되어야 한다.

## §5. 3단계 — 사상체 문서화 정의서

### 5.1. 산출물 구조: 두 층의 한 쌍

3단계 산출물은 *단일 문서가 아닌 두 층의 한 쌍*이다. 이는 *인간 작가*와 *LLM*의 인지 구조 차이를 정직하게 인정하는 형태다.

```
patterns/서사기획_나폴리탄/
├─ 03a_사상체문서화_헌장.md     ← 인간 작가 우선
└─ 03b_사상체문서화_표준.md     ← LLM 우선
```

| 층 | 명칭 | 청자 | 형태 | 분량 목표 |
|---|---|---|---|---|
| 상위 | **헌장** | 인간 작가 | 원칙·근거·미학 진술 중심의 서술 (서술 60%) | 15~25KB |
| 하위 | **표준** | LLM | 체크리스트·표·예시·금기 중심 (서술 40% / 체크리스트 40% / 매트릭스 20%) | 25~40KB |

두 층은 *상호 참조*로 묶인다. 같은 결정을 *표현 방식만 달리해 반영*한다.

### 5.2. 두 층의 원본/참조 방향

*표준이 원본, 헌장이 참조* 또는 *헌장이 원본, 표준이 참조*를 결정해야 한다. 본 파이프라인은 **3단계 작업 시점에 사용자가 결정**하는 사항으로 남긴다. 단방향 의존 명시는 *갱신 시 어긋남 방지*의 핵심 장치다.

### 5.3. 헌장의 구성 요소

- **마스터 원칙** (수와 내용은 미결, 3단계 작업 시점에 결정)
  - 사상체 문서 전체를 관통하는 횡단 원리
  - 대응지침_설계.md의 5대 원칙(서사 우선·형식 위장·유동 분량·부분 검열 한정·추론 표적 분포)은 *부분 참조 가능하나 그대로 차용 금지*
- **변주 불가 자리** — 프로젝트 정체성의 핵을 명시적으로 잠금
  - 표면/본질 이중 구조
  - 위반 결과 미명시
  - APMB 시스템 정합
  - 모호함의 디폴트
  - (3단계 작업 시점에 항목 확정)
- **의도된 결함 자리** — 정의서가 자기 권위를 부분적으로 부정하는 자리
  - "본 정의서의 §X는 의도적으로 모호하게 둠. 이 자리에서 작성자의 비-정의서 직관이 작동해야 한다"
  - 정의서로부터 작품이 도출되는 *순환 정당화* 위험에 대한 안전판
- **갱신 정책** — 본 정의서가 *언제·어떻게* 갱신되는가
  - 예: "3~5개 새 사상체가 누적되면 경향성 진술 재검토"
- **매체 한계 선언** — 본 정의서는 문서 매체에 한정 (영상 매체는 별도)

### 5.4. 표준의 구성 요소

- **11차원 각각의 디폴트 + 변주 메뉴**
  - 11차원은 본 정의서의 *몸통*이다 (외부 세션 의견 §6의 *부록* 권고는 거부 — 파이프라인의 0→1→2→3 변환 흐름이 11차원을 척추로 삼으므로)
  - 각 차원에 대해: 디폴트 → 변주 메뉴 → 변주 한계
- **옴니버스 결합 유형 4가지**
  - 독립형 / 누적형 / 반향형 / 층위형 (외부 세션 §5.3 받아들임)
  - 분류 차원으로만 활용, 결정 도구 아님
- **APMB 매핑 — 경향성 진술**
  - 위험 등급 × 변칙성 × 형태의 합성 디폴트를 *예시로* 제시
  - 고정 매트릭스 금지 (자기 충족 예언 위험)
- **작성 체크리스트** — LLM의 자기 점검용
- **의도된 결함 자리에 대한 작동 지침**
  - 헌장의 *의도된 결함*이 표준에서 어떻게 *수행*되는가

### 5.5. 디폴트 + 변주의 구조

본 파이프라인은 *동등한 여러 패턴* 형태가 아닌 **디폴트 + 변주의 메뉴** 형태를 채택한다 (외부 세션 §4 받아들임).

근거:
- 노스포비아는 *단일 세계관*이므로 *통일된 미학 강령*이 우선
- 표면/본질 이중 구조 자체가 *디폴트 + 변주*의 형식
- LLM은 *디폴트가 있는 편이 작성 시작이 빠르고 일관성이 높음*
- 인간 작가는 *디폴트를 알고 의도적으로 이탈하는 것*이 *매번 선택*보다 통제감이 큼

디폴트의 *내용*은 1·2단계의 분석 결과에서 도출되며, *외부 세션이 §4.2에서 제시한 디폴트 후보*는 *가설*로만 활용한다 (검증/갱신 대상).

### 5.6. 세션

1~2세션. 헌장·표준이 한 쌍으로 작성됨. 사용자와 협업.
