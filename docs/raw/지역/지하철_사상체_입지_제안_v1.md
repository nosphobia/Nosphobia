# 지하철 사상체 — 지리적 입지 제안

> ⚠️ **제안**이다. 사용자가 선택한다.
> 콘셉 핵심: 실제 역과 역 *사이*에 끼어드는 *없는 역*. 인명 피해 비차용. 의식형 규칙괴담.

---

## 0. 입지가 콘셉에 기여하는 조건

지하철 사상체는 *없는 역*이 끼어드는 콘셉이다. 따라서 입지는 다음을 만족할수록 설득력이 커진다:

1. **틈의 여지** — 역간 거리가 길거나, 긴 터널/지하 구간이 있어 *역 하나가 더 끼어들* 물리적 여백.
2. **장시간 주행 설득력** — 키사라기역계 진입 조건(비정상적으로 긴 주행)을 쓰려면 *원래도 오래 걸리는 구간*.
3. **기존 괴담·유령역** — 이미 그 자리에 *없는 역의 그림자*가 있으면 현실감↑.
4. **검열 친화** — 실제 역명을 검열로 가려도 자연스러움.

---

## 1. 입지 후보

### 후보 A. 실존 유령역 활용 — 신설동역 지하 3층 ★
1974년 옛 5호선 승강장으로 미리 지었으나, 계획 백지화로 *버려진 승강장*. 일반인 출입 금지. 이미 귀신 목격 괴담이 떠도는 곳.

- **틈의 여지**: ★★★ — *이미 존재하는 없는 승강장.* 콘셉의 "없는 역"을 현실이 그대로 제공.
- **활용 방식**: 1호선/2호선 신설동 통과 시, *특정 조건*에서 차량이 *지하 3층 유령승강장*에 정차. "없는 역"이 아니라 *있지만 가서는 안 되는 역*.
- **강점**: 현실감 최강. "실제로 거기 버려진 승강장이 있다"는 사실이 괴담의 뿌리. 사진·영상도 실재.
- **차별점**: 미온신도시가 *간척 유령도시*라면, 이건 *지하 유령승강장* — 둘 다 "실재하는 버려진 공간"을 사상체화.
- **주의**: 실존 역명이라 검열 처리 필수 (`██동역 지하 ██층`). 신설동 자체를 특정하지 않고 *유형*만 차용하는 선도 가능.

### 후보 B. 장거리 구간 — 9호선 김포공항~디지털미디어시티 계열
역간 10.9km의 장거리 구간(마곡나루 개통 전 최장). 한강 하저터널 포함.

- **틈의 여지**: ★★★ — 10km 넘는 구간에 *역 하나 더 끼어들* 여백이 충분.
- **장시간 주행**: ★★★ — 원래도 오래 걸려 *비정상적으로 긴 주행*(키사라기역계 진입조건)이 자연스러움.
- **강점**: "이 구간은 원래 길다"는 일상 경험 → *조금 더 길어진 것*을 눈치채기 어려움. 콘셉의 "현장에선 너무 자연스럽다"와 정합.
- **차별점**: 한강 *하저*터널 = 물 밑을 지나는 어둠. 경계 공간의 미학.

### 후보 C. 최심부 역 — 7호선 숭실대입구(지하 45m) 계열
국내 최심 지하철역 중 하나. 깊은 지하 + 긴 에스컬레이터.

- **틈의 여지**: ★★ — 깊이가 *수직적 이면*의 여지. "더 깊은 층"이 끼어들 수 있음.
- **강점**: *지하 깊이 자체가 공포.* 내려갈수록 현실에서 멀어지는 감각. 후보 A(유령승강장)와 결합 가능.
- **차별점**: 수평(역 사이)이 아닌 *수직(더 깊은 곳)*으로 변주 가능.

### 후보 D. 장거리 노선 전체 — 7호선 (장암~석남, 2시간)
특정 역이 아니라 *노선 전체*가 무대. 2시간 걸리는 장거리 노선이라 어디서든 진입 가능.

- **틈의 여지**: ★★★ — 노선이 길어 *어느 구간에서든* 끼어들 수 있음.
- **강점**: 사상체가 *한 곳에 고정되지 않고 노선을 떠도는* 양태 가능. (공유무대 후보 4 '노선' 결과 연결)
- **주의**: 너무 광범위하면 사상체 발현 자리가 흐려짐. *특정 구간으로 좁히는* 게 나을 수 있음.

## 3. 에이전트 추천

**후보 A (신설동 유령승강장) 단독, 또는 A + B 결합.**

- **A**가 가장 강력하다 — 콘셉의 "없는 역"을 *현실의 실재하는 유령승강장*이 그대로 받쳐준다. 미온신도시가 "실재하는 간척 유령도시"를 차용했듯, 지하철은 "실재하는 지하 유령승강장"을 차용하면 *세계관 전체가 같은 미학 원리*(실재하는 버려진 공간 = 사상체)로 묶인다.
- 단 콘셉 원문은 "*없는* 역"인데 신설동은 "*있지만 버려진* 역"이라 미묘한 결 차이가 있다. 두 방향:
  - **(가) 유령승강장형**: 없는 역이 아니라 *지도에 있으나 가면 안 되는 버려진 승강장*. (신설동 직계)
  - **(나) 끼임역형**: 신설동 *근처 구간*에서, 실재 유령승강장의 "그림자"처럼 *진짜 없는 역*이 끼어듦. (콘셉 원문 유지 + 신설동을 떡밥으로)
- **A + B 결합**: 진입은 *장거리 구간(B)*에서 비정상적 주행으로 시작되고, 도착하는 없는 역이 *유령승강장(A)의 양태*를 띤다. 장시간 주행 설득력(B) + 유령승강장 현실감(A).

> 실존 역명은 APMB 관례대로 검열(`██동역`, `█호선 ██ 구간`). 신설동을 *특정*하지 않고 "1970년대 계획 백지화로 버려진 지하 승강장"이라는 *유형*만 차용하면 윤리·가상성 모두 안전.

## 4. 미온신도시와의 관계 (참고)

- 미온신도시 = *간척 유령도시* (지상·수평·거대)
- 지하철 사상체 = *지하 유령승강장/없는 역* (지하·수직·점)
- 두 사상체가 **"실재하는 버려진 공간을 사상체화"**라는 공통 미학으로 묶이면, 노스포비아 세계관에 *일관된 결*이 생긴다. (단 둘을 *직접 연결*할지는 별개 결정.)
