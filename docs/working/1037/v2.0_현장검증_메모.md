# v2.0 첫 현장 검증 메모

본 문서는 v2.0 대응 지침 설계 표준을 *실제 사상체(1037 학교)에 처음 적용*하는 재배치 작업 중에 발견된 *표준의 미진 자리·확장 후보·자기 점검의 작동 한계*를 기록한다. v2.0 §12.3의 *현장 검증으로 발견된 약점*에 해당.

본 메모는 *재배치 작업의 부산물이지 비판이 아니다*. v2.0의 *결정적 자리는 보존*하면서 *현장에서 발견된 작동 한계*만 기록한다.

---

## §0. 본 검증의 한계 자기 공개

- 본 검증은 *재배치*에 한정. *신규 사상체 처음부터 작성*에는 적용되지 않음. 신규 작성 시 발견될 자리는 별도 검증 필요.
- 본 검증은 *단일 사상체(학교)*. 7종 의례 공간 카탈로그 중 1종이므로 *공간 = 비위계 공간*이나 *방송 매체*(노스포비아 본체) 등 다른 공간 유형에서는 검증 자리가 다를 수 있음.
- 본 검증은 *시점 모듈 미도입* 선택. *§3001+ 시점 모듈을 도입한 자리*의 검증은 향후 작업 (예: 노스포비아 본체 대응 지침 재배치) 시 별도 수행.
- 본 검증은 *사이드 미도입*. v2.0의 *사이드 3유형 + 호출 어휘 4종*은 본 1037 재배치에서 한 번도 작동하지 않았음. *사이드 도입형 사상체*의 검증은 별도 사상체 작업 시 추가.

## §2. v2.0의 결정적 자리 — 보존 확인

## §3. v2.0 신설 자리의 *현장 적용 결과*

본 재배치에서 *처음 적용된 v2.0 신설 자리*의 작동 평가:

### §3.1. §2.4 위반 결과 우회 4종 양태 — **작동 양호**

- 주력 결정(반복 정형구 + 변주형 완곡어법)이 *플롯 시트 시점에 명확하게 결정 가능*
- 본문 작성 시 *상시 점검 도구로 작동*. 위반 결과 직접 명시 충동을 효과적으로 억제
- 4막 결과 완전 부재형(§49·§62)이 자연 매핑
- **발견**: 4종 양태 중 *변주형 완곡어법*은 *주력*보다 *전 작품 분산 보조*가 자연. v2.0이 *주력 1종 + 보조 1~2종*을 권장하나 *변주 완곡은 본질적으로 *전 작품 분산*되는 자리*임이 발견 → §10.1 확장 후보

### §3.2. §2.5 시간축 처리 — **작동 양호, 단 미진 자리**

- 이중 시간축 개념이 명료
- 외부 시간 매체 2종 도입(§63 권위자 서명 + §64·§65 갱신 메모)이 *살아 있는 문서* 효과 시연
- **발견 1**: *(4) 시간 정지 양태*는 *외부 시간 매체와 자연 동거하기 어려운 자리*. 본 작업에서는 *§63 권위자 서명을 작품 내부 시간의 마지막 자리(§63)에 배치 후 외부 시간 매체(§64·§65)는 그 후속*으로 분리하는 *문서 구조적 해법*을 발견 → §10.2 확장 후보
- **발견 2**: v2.0 §2.5.3의 *외부 시간 매체 5종*에 *서명체 메모의 시간 표지화*가 빠져 있음. 본 작업의 §64·§65는 *갱신 메모 형식 + 권위자 서명체 끝맺음*의 *합금체*. v2.0이 *갱신 메모*와 *권위자 서명*을 *별도 매체*로 분류하나, 실제 본문에서 *둘이 한 자리에서 결합*되는 경향 → §10.3 확장 후보

### §3.3. §3.3.1 공간 = 의례 위계 분류 — **부분 작동, 미진 자리**

- 학교 사상체이므로 *7종 카탈로그 명확 부합*. 결정 자체는 자동
- **발견**: v2.0 §3.3.1이 *의례 위계 = 생존 통화*를 *1막에 명시*하라는 가이드를 두지만, *학교*의 의례 위계는 *2막 행동 지침에 분산 시연*되는 게 자연. 1막에 *교사-학생 의례 위계*를 *어휘로 명시*하면 *임상적 행정 외형이 침식*됨. v2.0의 *1막 명시* 가이드와 *현장의 자연 분포* 사이의 충돌 → §10.4 확장 후보 (1막 *명시*보다 *전제로 깔기*로 가이드 수정 검토)

### §3.4. §4.4.1 시점 위치 3종 분류 — **본 작업에서 미도입, 단 §5.4.2 변종 발견**

- 시점 모듈 미도입 결정 → 제2종을 *메인 라인 안의 매체 위계 직조*로 처리
- **발견**: v2.0 §5.4.2의 *30% 이하 구간 = 매체 위계 직조*가 *시점 모듈 한정*으로 명시되어 있으나, 본 작업에서 *메인 라인 안의 부분 구간(3-b 외곽 광역)에 *30~50% 부분 적용**이 가능함이 발견됨. *시점 모듈 분리하지 않고 메인 안에서 부분 매체 위계*하는 *제3의 자리*가 v2.0에 부재 → §10.5 확장 후보 (메인 라인 안의 부분 매체 위계 가이드 신설)

### §3.5. §5.6 5종 음각 환기 도구함 — **작동 양호**

- 부분 검열 + 번호 결번 2종 조합이 *한국형 디폴트 조합*으로 자연 작동
- 번호 결번 3개(§43·§53·§60)의 *안내 부재형*(예시 b)이 *형식의 빈자리에 의한 환기*를 자연 시연
- **발견**: v2.0 §5.6.2의 *결번의 2종 의도성*에서 *작가 차원 결번 — 안내 부재형*이 *세계관 내적 부자연*과 충돌할 가능성. *지류 문서로서의 본 문서가 *번호를 누락시킬 권위*가 있는가*에 대한 *세계관 내적 자리*가 v2.0에 부재 → §10.6 확장 후보

### §3.6. §5.4.1 호명체 비율 차등 — **작동 양호**

- 1막·2막 90% / 3막 80% / 3-b 60% / 4막 80% / §64·§65 0%의 자연 분포
- **발견 없음** (단 §5.4.1의 비율 가정이 *플롯 시트 frontmatter*에 *단일 값*으로 명시되도록 템플릿이 강제하나, 실제로는 *막별 차등*. 템플릿이 *막별 비율 명세*를 옵션으로 두지 않음 → §10.7 확장 후보)

### §3.7. §7.6 노스포비아 미학 대립 배제 자리 — **작동 양호**

- 4항목 모두 자연 회피
- §63 권위자 서명 한 줄이 *서명체 메모 형식 도입 가능* 자리의 정합 적용. 사적 묘사 회피 성공
- **발견 없음**

## §4. v2.0의 *부재 자리* — 본 작업에서 발견된 v2.0이 다루지 않는 새 자리

다음은 본 재배치에서 *v2.0이 명시적으로 다루지 않는 자리*를 만나 *작업자(LLM)가 자체 판단*한 자리들. v2.x에서 추가 검토 후보.

### §4.1. 진입 호명(§1)에 *시점 매체 레이터링 안내*를 도입할지

본 작업의 §1에는 *후반부에서 본문 어조가 보고체로 일부 전환됨이 본 문서의 매체 외형*에 해당함을 사전 인지하는 *메타-안내*가 들어갔다. 이는 v2.0의 §5.2(4) 시점 모듈 진입 호출과 *형식이 유사하나 다른 자리* — *모듈 호출이 아닌 매체 분리 안내*.

v2.0은 *§1의 진입 호명*이 *시점 모듈이 있을 때만* 명시 호출하라고 함. 시점 모듈이 없고 *메인 안의 매체 위계 직조*가 있는 경우의 §1 안내 처리는 v2.0에 부재.

**v2.x 검토**: §1 진입 호명의 3종 형식 — (a) 시점 모듈 없음·매체 단층 / (b) 시점 모듈 있음 / (c) 시점 모듈 없으나 메인 안 매체 위계 직조 있음. (c)의 어휘 표준화 검토.

### §4.2. *지류 문서* 자체의 권위 자기 한정 어휘

본 작업의 도입부에는 현행 원본의 *본 지침은 ████ 지부의 지류 문서로 배포된다 / 본 문서의 전자 매체 복제 금지 / 부차 변칙성에 의해 본 지침의 전자 형태가 유입되는 사례가 보고된 바 있습니다*가 보존되었다. 이는 v2.0이 *§1.4.1 한국형 변종 — 권위의 자기 한정*에서 시사하는 자리이나, *본 문서의 권위 자체에 대한 한정 어휘*가 v2.0에 *별도 자원으로 명시되지 않음*.

본 한정 어휘는 *지류 문서·매체적 자기 한정·부차 변칙성 영향 시인*의 3종 요소가 결합. *기관 권위의 한국형 자기 한정*의 *구체적 어휘 자원*으로 v2.x에서 추가 검토 가능.

**v2.x 검토**: §1.4의 *임상 어조* 자리 또는 *§2.4의 위반 결과 우회*의 보조 자원으로 *문서 자체의 권위 한정 어휘 4~5종*의 도구함을 신설 검토.

### §4.3. *(4) 시간 정지 양태에서의 *외부 시간 매체와의 거리*

§3.2에서 언급된 자리. v2.0 §2.5.2는 *4종 시간차 양태*를 명시하나, *(4) 시간 정지가 *외부 시간 매체와 어떤 거리에 있을 때 자연*한지*의 가이드 없음.

본 작업의 해법: 작품 내부 시간의 *마지막 자리*(§63 — 본국 안내 닫힘)는 *본 사상체의 정지된 외형* 자체를 시연하고, 외부 시간 매체는 §63 *이후의 자리*(§64·§65)로 분리 — *경계가 시간축에서 진행되는* 구조적 해법.

**v2.x 검토**: 시간 정지 양태의 *외부 시간 매체 처리* 가이드 신설. *작품 시간 내부에 외부 시간 매체를 끼우지 말고 작품 시간 종료 자리 이후로 분리*하는 디폴트 권장 검토.

### §4.4. *시점 매체 레이터링 자리에 진입 호명·종결 어휘의 처리*

본 작업의 §36~§59 자리에서 *차단/회수 처치 구역 인원* 호명을 *보고체로 매체 레이터링*했다. 이 자리의 *어미 변환*은:
- 기존 *~하십시오 / ~받으십시오 / ~보고하십시오* → *~하는 것으로 처리된다 / ~수행된다 / ~한다*

이 *어미 변환의 표준*이 v2.0의 §5.4.2(30% 이하 구간) 또는 §1.4(임상 어조)에서 명시되지 않음. *어떻게 변환할지*를 LLM이 자체 판단해야 했다.

**v2.x 검토**: 보고체로의 *어미 변환 표준* 5~7종을 §5.4 또는 §10 짧은 예시에서 도구함화. 현행 변환 형식의 예시:
- 1인칭·2인칭 호명체 → 3인칭 객관 보고체
- *~하십시오* → *~하는 것으로 처리된다 / ~수행된다*
- *~받으십시오* → *~받는다 / 받게 된다*
- *~보고하십시오* → *~보고하는 것으로 처리된다 / 보고된다*
- *~~지 마십시오* → *~~하지 않는 것으로 처리된다 / ~~지 않는다*

### §4.5. *plotsheet의 *분량 가이드*와 *작성 시점의 *분량 예측* 사이의 거리*

v2.0 §4.2의 막별 분량·밀도 차등표가 *항목당 분량*만 명시하고 *항목 수의 막별 비율*은 명시하지 않음. 본 작업에서 *2막이 23항목으로 다소 길어진* 자리에 대해 *비율이 권장 안에 있는지* 판정 불가.

**v2.x 검토**: 막별 *항목 수 비율 권장*을 §4.2에 부속 가이드로 추가. 예: 1막 10~15% / 2막 30~40% / 3막 30~40% / 4막 15~20%. 단 *유동 분량 원칙*과 충돌하므로 *권장*에 한정.

### §4.6. *재배치 작업의 *전용 절차*가 v2.0에 부재

v2.0 §9.2가 *기존 사상체 대응 지침 수정*의 절차를 명시하나, *v1.0 → v2.0의 표준 변경에 따른 재배치*(본 작업의 자리)는 *일반 [창작]·[정합] 피드백*과 다른 *전용 자리*. *번호 체계 전면 재할당 + 시점 모듈 미도입 시 메인 안 매체 위계 직조 + 외부 시간 매체 신설*의 3종 작업이 *한 세션에서 동시 수행*되어야 함.

**v2.x 검토**: §9에 *§9.4 표준 변경에 따른 재배치 절차*를 신설. 본 메모 자체가 그 절차의 *현장 예시*가 될 수 있음.

## §5. v2.0의 *템플릿 작성 부담* — 작업자(LLM) 부담 평가

§12.3에서 v2.0이 *플롯 시트 v2.0 템플릿의 작성 부담 — 간소화 옵션 검토*를 명시했다. 본 작업에서 평가:

### §5.1. 부담이 큰 자리

- **frontmatter 8항목 동시 결정**: 공간 유형 / 주력 시간차 양태 / 주력 검열 양태 / 주력 위반 결과 우회 양태 / 호명체 비율 가정 — 5종 결정을 *플롯 시트 1단계 시작 시 한꺼번에* 요구. 본 작업에서는 사용자에게 *옵션 제시 후 결정*하는 흐름으로 분산 처리. *LLM 자율 작성 시*에는 *5종 동시 결정*이 *서사 설계 전*에 위치해 *서사 설계가 결정에 종속*되는 역전 위험.

- **시리즈 차원 메타 (§1.8)**: *APMB 사상체 시리즈 미설계*이므로 *전 항목이 향후 자원*. 본 자리가 *현재 작업에서는 비어 있는 자리*로 남음.

### §5.2. 부담이 작은 자리

- 4막 경계 자체는 *상황 전제 변화*로 자연 결정. 부담 작음.
- 추론 표적 1·2·3층 분포는 *서사 설계의 자연 부산물*로 결정 가능. 부담 작음.
- 사이드·시점 모듈 후보는 *없음으로 결정*이 *옵션*. 부담 작음.

### §5.3. v2.x 간소화 후보

- **단일 사상체용 *축약 템플릿*** 신설 검토. 시리즈 차원 메타·3차원 분포 메모·옴니버스 결합 4유형 자리를 *옵션*으로 분리. 본 작업의 플롯 시트에서 *§1.8 시리즈 차원 메타*가 *전 항목 향후 자원*으로 남은 자리가 *축약 템플릿 정당화*의 근거.
