# 1037 (학교) 대응 지침 플롯 시트

본 문서는 v2.0의 *플롯 시트 표준 템플릿*에 따라 작성된 *작가 내부용* 설계도다. v2.0의 *첫 현장 검증* 작업의 입력이다.

## 1. 서사 설계

### 1.0. 추론 표적 (3층 분포)

**1층 — 표면** (전 항목의 약 60%)

본 사상체는 *시골 폐교 중학교* 외관의 광역형 이계 영역이며, 내부에 진입한 인원은 *학생*의 양식으로 변형되어 *수업 5교시*의 누적에 의해 본래 정체성이 *학생 신분으로 치환*된다. 본 사상체 내부의 학생·교사·교칙은 인간 기준에 부합하지 않으며, *야간 고정·외부 단절·교칙 처벌·수업 동화*의 다섯 변칙성이 본 사상체의 작동 원리다. 본 지침은 *진입 차단·진입 후 회수·회수 후 잔여·비상 시 대응*의 네 구간으로 청자를 인도한다.

**2층 — 항목 간 대조** (전 항목의 약 30%)

다음 대조 자리에서 2층 정보가 추론된다:
- *학생 [-01]*의 *일시 무력화 가능*과 *교사 [-02]*의 *물리적 제압 시도조차 성립하지 않음*의 비대칭(개요+변칙 §6 + 대응 §1003+§1021+§3003)
- *진입자가 친구로 호명되는 양상*이 §1014·§1020·§3007에서 *3 자리에 분산 노출*되어, *학생 [-01]이 진입자를 *기존 친구 관계의 부정*으로 분류하는 자기-등록 메커니즘*이 추론됨
- *교칙*이 *진입자가 인지하지 못한 상태에서도 위반이 성립*(변칙 §4)되는 한편, *대응 지침의 §1003·§1023*에서 *직접 조우의 행동 지침은 본 문서에 게재되지 않으며*가 반복되어, *교칙 전모가 본국에 의해 완전히 파악되지 않은 자리*가 *대응 지침의 부재로 환기*

**3층 — 미지** (전 항목의 약 10% — 절대 비공개)

- 교사 [Ni-04-EV-1037-02]의 본질·기원·본 사상체와의 위계 관계 = *[기밀 분류]*
- 교칙 [Ni-04-EV-1037-03]의 전모·작성자·정확한 조항 수 = *[기록 보류]*
- 운영 방침 *[데이터 말소] 단계로 이행*(현행 §3014)의 정체와 *[기밀 분류 — Level 5 인가 한정]* 문서의 내용
- 본 사상체 경계 안 *화장실·탈의실·기숙사*의 회수 사례 부재 자리(현행 §1015)

**3차원 분포 메모**:
- *공간 분포*: 1막에 1층 표면 다수, 2~3막에 2층 대조 자리 분산, 4막에 3층 비공개 집중 (자연 분포)
- *시간 분포*: 3층 비공개 자리가 *4막 비상의 후반*에 집중. *작품 시간 후반 = 운영 방침 [데이터 말소] 이행 자리*. 단 *합금형 반전*(1막 브리핑이 4막 폭로로 사후 재해석)은 강하게 도입하지 않음 — 본 사상체의 *모호함의 균형*은 *기관 권위의 자기 한정*에 위치
- *시리즈/옴니버스 분산*: *본 v2.0 시점에 APMB 사상체 시리즈 미설계*이므로 미적용. 단 *공유 인물군 후보*로 *보안 통제부 ████*과 *회수 처치 구역 ████*의 행정 단위 호명을 향후 시리즈에서 재사용 가능

### 1.1. 1막 — 진입 이전

**공간 = 의례 위계 = 생존 통화**: 본 사상체는 *시골 폐교 중학교*의 형식적 외관을 유지하나, *교사-학생 의례 위계*가 변칙성 작동의 핵심 통화다. *예의 위반(=교칙 위반) = 교칙 처벌의 발현*의 등식이 본 사상체 내부의 모든 행위에 적용된다. 단 *교칙 자체가 인간 기준의 학교 규범과 일치하지 않는 별도의 체계*(변칙 §4)이므로, *위계의 외형은 한국 사회 학교 의례의 모방*이되 *위계의 내용은 미상*. 1막은 *그 모방 외관이 인지되는 자리에서의 차단*을 다룬다.

탐사자가 본 사상체를 *처음 인지하는 징후*는 *야간에도 외부 조명이 가시되지 않는 시골 폐교 중학교*와 *진입로의 통신 신호가 단절되는 부지*의 두 표면 양상. 본 사상체의 *경계*는 *부지 외곽선*으로 정의되되, 외곽선의 *정확한 위치*는 본국에 의해 [기밀 분류]로 처리되어 탐사자에게는 공개되지 않는다 — 즉 탐사자는 *우발적 조우 시점의 외관 양상*만으로 *진입 차단의 자기 분류*를 수행해야 한다. *진입 차단의 책임자*는 본국 차단 구역 인원이나, *탐사자가 우발적으로 외곽선에 인접한 자리*는 차단의 *실패 자리*. 이 실패 자리에서 1막의 *시선 접촉·음향 방향 식별·교복 단편 접촉* 등의 *진입 유도 양상*이 작동한다.

본 사상체의 *주요 변칙성*(EV)이 *진입자를 학생의 양식으로 변형*하는 자리에서 작동하므로, 1막은 *진입의 성립 자체를 차단*하는 데 자원을 집중한다. 1막의 어휘는 *임상적 외형*이 우세하고, *행정 정형구의 반복 후렴*이 1막 말미부터 누적되기 시작한다.

### 1.2. 2막 — 조우

**핵심 변수**: 진입의 성립.

*경계 안으로의 진입이 어떠한 사유로든 성립한 경우*(v2.0 §4.1의 자연 위장 도구의 1막→2막 표준 어휘 직접 응용)에 본 막이 시작된다. 2막은 *경계 내부의 변칙성에 노출된 진입자*가 *학생 변형의 진행*과 *교칙 위반 회피*의 두 압력 사이에서 *회수반의 도착을 기다리는* 자리다.

막의 *내부 플롯 구조*:

- **플롯 a — 정지·대기·시간 신뢰 금지**: 경계 안 의식 회복 시점부터 *회전·이동 없이 그 자리에 정지*, 본 사상체 내부 시간계에 대한 자체적 판단 신뢰 금지. *외부 시간 매체*와의 단절을 *진입자가 자기 분류로 인지*해야 함.
- **플롯 b — 학생 변형의 외형적·인지적 진행 차단**: *교복 단편·교과서·반·번호 정보·이름·외부 사회적 관계*에 대한 자발적 발화·표기·인지가 *학생 [-01] 집합 개체군에 대한 본인의 등록 신청*으로 처리된다. *발화 자동 변환 양상*에 즉시 중지.
- **플롯 c — 교칙 위반 회피와 학생·교사 개체 응대**: *학생 [-01]*의 호명·인사·요청·*친구 호명*에 무응답. *교사 [-02]*의 *직접 조우*는 *행동 지침 본 문서 미게재 — [기밀 분류 — Level 4 이상 열람 가능] 참조*. *교무실 출입문 시야 노출*도 §1003 직접 조우와 동일 효력.
- **플롯 d — 본 사상체 내부 공간의 위계와 금지**: *복도 우측 벽면 인지·거울·화장실·탈의실·기숙사·교문 외부 통과*의 5종 공간 금지 + *조회·종례·청소 시간 호명에의 응답 금지*.

### 1.3. 3막 — 사후

**핵심 변수**: 회수 시점·잔여 양상·2차 영향.

회수는 *자력*이 아니라 *본국 회수반에 의한 외부 회수*가 디폴트. *자력 탈출 시도는 (4) 교칙 위반*으로 분류되어 *처벌 임계 단계 상승*. 본 막은 두 자리로 나뉜다:

- **3-a 회수 후 잔여 (회수된 본인)**: *학교 시간표·교과서 음운·급식* 어휘에 비정상적 친밀감, *학교 양식 물품* 잔존, *본래 이름의 망각*. 모두 즉시 본국에 보고.
- **3-b 외곽 광역의 2차 영향**: *차단 구역 인원의 근무 기록 공백*, *본국 문서 매체에 대한 사후 변경*, *차단 구역 인원군의 시골 학교 어휘 자발 발화·동시 회상의 광역 작용*, *회수 인원의 동일 학생 이름 자발 발화*, *회수 처치 격실 인근의 교실 음향의 외부 음원 없는 인지*, *지부 인근 일반 교육 시설의 비정상 사건 보고*. 본 자리에서 *시점이 보고체로 매체 레이터링*되어 *차단/회수 처치 구역 인원의 외곽 응대 자리*가 *메인 라인 안의 보고체 자리*로 동거.

### 1.4. 4막 — 비상

**핵심 변수**: 본 사상체의 변칙성이 *예상 작동 범위를 초과*하는 자리.

초과의 *최초 양상*은 *경계 외부 방향 확장*과 *야간 환경의 외부 가시화*. 본 막에서 *교사 [-02]*가 *경계 외곽선 너머에 출현*하거나, *학생 [-01]*이 *차단 구역 인원의 가족·지인 외형 모방으로 출현*하거나, *교칙 조항이 본국 인원의 행동에 외부 자동 적용*되는 자리에서 *대응의 부재*가 발현된다 — *후속 절차는 [데이터 말소]·[기밀 분류 — Level 5 인가 한정]·후속 절차 본 문서 미게재*. *본국이 대응을 결정하지 못한 자리*가 본 막의 *3층 미지의 결정적 지점*.

본 막에서 *번호 결번 2~3개*를 *부분 검열과 동거*시켜 *형식의 빈자리에 의한 환기*를 시연. 4막 말미에는 *권위자 서명* + *갱신 메모 1~2회*가 끼어 *살아 있는 문서*의 자리를 만든다. 단 *서명의 내용은 행정 단위*에 한정 — *권위자 사적 관계의 본문 진입은 §7.6 배제 자리*.

### 1.4.1. (옵션) 5막 — 외부 시간 누적

본 사상체는 *(4) 시간 정지*가 주력 시간차 양태이므로 *5막 변종은 미채택*. 외부 시간 매체는 4막 안에서 *갱신 메모 + 권위자 서명*으로 시연. 다만 v2.x 후속 갱신에서 *본 사상체의 격리 운영 방침 변경*(현행 §3014 = 재배치 4막 비상의 자리) *이후의 외부 시간 누적*을 5막으로 분리할 가능성은 향후 자원.

### 1.5. 사이드 후보

본 v2.0 첫 현장 검증에서는 *사이드 영역 미도입*. 이유:
- 현행본에 사이드 영역 부재 + 호출 어휘 4종 전면 부재
- *재배치*가 작업 자리이므로 *새 분기 창작*은 *재배치의 범위 초과*
- v2.0의 *5종 음각 환기 도구함·외부 시간 매체·번호 체계*만 도입해도 *현장 검증의 의의는 충분*

단 잠재 사이드 후보는 *향후 [창작] 피드백 시점*에 도입 가능:
- **SB-1 (잠재)**: 교사 [Ni-04-EV-1037-02] 직접 조우 사이드 — *§1003의 [기밀 분류 — Level 4 이상]* 자리를 *분기형 + 플롯 점프형 사이드*로 분리해 *시점 위치 = 제2종 (조직체 1인칭 복수의 일원)*으로 도입. 호명체 비율 30% 이하로 낮춰 *매체 위계 직조*로 본문과 분리(§5.4.2).
- **SB-2 (잠재)**: 학생 [Ni-04-EV-1037-01]에 의한 *친구 호명* 사이드 — *§1014·§1020·§3007*의 누적 분산을 *플롯 점프형 사이드*로 응축. *진입자의 학창 시절 친구 이름과 일치*하는 양상의 *공명* 자리(현행 §1028) 강조.

### 1.6. 시점 모듈 후보

본 v2.0 첫 현장 검증에서 *시점 모듈은 미도입*. 사용자 결정: 메인 라인에 *차단 구역 인원*·*회수 처치 구역 인원* 호명을 *보고체로 매체 레이터링*해 한 파일 안에 시연 (§5.4.2 30% 이하 구간의 매체 위계 직조).

향후 자원 (v2.x 갱신 시):
- **§3001~ (예정)**: 차단 구역 인원 시점 모듈. 시점 종 = 제2종. 호명체 비율 30~50%. 경계 외곽 동적 대응·외부 야간 환경 누출 조치 등.
- **§5001~ (예정)**: 회수 처치 구역 인원 시점 모듈. 시점 종 = 제2종. 잔여 변칙성 전이·2차 동화·격실 환경 분리 등.

### 1.7. 시간축 명세

- **주력 시간차 양태**: (4) 시간 정지 — *야간 고정 + 외부 시간계 단절*이 본 사상체의 자연 매핑
- **외부 시간 매체** (2종 선택):
  - **갱신 메모**: 4막 후반 1~2회. *YYYY.MM.DD. 갱신: ...* 양태. 본 사상체의 *변칙성 작동 범위에 대한 본국의 검토*가 외부 시간으로 흐름을 시연
  - **권위자 서명**: *— 보안 통제부 ████* / *— 본국 ████ 본부*의 행정 단위 서명. 4막 말미와 갱신 메모 자리에 동반 배치
- **작품 내부 시간 — 외부 시간의 간격**:
  - 작품 내부 시간 = *야간 고정의 정지된 한 장면* (외부 시간과 동기되지 않음)
  - 외부 시간 = *본국의 본 문서 갱신·검토 시점* (현행 문서가 *2026년대 본국에 의해 운영 중*임을 갱신 메모로 표지)

**결번 비율 검증**: 60항목 중 3 결번 = 5% (§5.6.2 권장 구간 5~30%의 하한). 본 사상체의 *임상적 행정 외형*을 유지하면서 *음각 환기를 의도적으로 가벼움 자리*에 위치. 4막 후반·3막→4막 경계·4막 중반의 3 결번이 *형식의 빈자리에 의한 환기*를 *분산 배치*. 작가 차원 결번 — 안내 부재형 (§5.6.2 예시 b).
