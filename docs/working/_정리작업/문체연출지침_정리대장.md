## ⭐ 창작자 의도 (2026-06-06 확정 — 모든 판단의 기준)

기존의 *외부 자료 분석 → 패턴 추출 → 창작 지시* 방식을 폐기한다. 앞으로는 **창작자가 직접 작품을 쓰고 그것을 분석해 자기 문체를 역으로 일반화**한다. 따라서:

- 🔴 **작성·연출 지시문**("이렇게 써라 / 이 어휘 피해라 / 이 패턴 적용") → **삭제 대상.** 연출·작성법은 창작자가 다시 정의한다.
- 🔵 **분석 관찰**(여러 자료를 보고 발견한 장르 공통 요소) → **보존 대상.** 단 '지시'가 아니라 '분석'으로 남겨야 함.
- 문제: 현재 문서들은 이 둘이 한 문장에 엉켜 있고, 분석을 *지시로* 쓰고 있다.

### 분석 자료의 계보 (창작자 설명)
```
실제 배포 소설 텍스트
  → 분석자료/서사구조분석_*.md (개별 작품 분석, 10편)
  → 분석자료/시리즈통합_*.md (시리즈별 통합 분석, 2편)
  → 분석자료/횡단종합_대응지침설계_보강자료.md (3개 통합의 횡단 종합)
  → patterns/archive/대응지침_설계_v2.0.md (분석 + 작성가이드 + 창작 파이프라인)
  → [파이프라인 삭제] → patterns/대응지침_연출가이드.md (현재, 잔존물)
```
별도로 patterns/방법론_통합방법론.md는 *장르 자체*(SCP/나폴리탄/규칙괴담)를 분석한 다른 계열.

# 문체·연출 지침 정리 작업대장

## 배경

창작자는 기존의 *외부 자료(SCP·나폴리탄·규칙괴담) 분석 → 패턴 추출* 방식으로 만든 문체·어휘·문법·연출 지침이 자기 취향과 맞지 않는다고 판단했다. 앞으로는 *본인이 직접 여러 작품을 쓴 뒤 그것을 분석해 자기 문체를 역으로 일반화*하는 방식으로 전환한다. 따라서 현재 문서들에 흩어진 표현 지침을 대체로 삭제하되, 일부 필요한 것은 하나씩 확인 후 결정한다.

## ⭐ 검열(censorship) 처리 기준 (2026-06-06 창작자 확정 — 모든 문서 공통 적용)

검열 관련 내용은 다음으로 갈라 처리한다:

| 종류 | 예시 | 처리 |
|---|---|---|
| 🔵 검열의 **규칙/조건** | "열람 인원 보안 등급이 문서 등급보다 낮으면 검열될 수 있다" | **유지** (설정) |
| 🔵 검열 기호의 **정의** | `█`/`[기밀 분류]`/`[데이터 말소]`/`[기록 보류]`가 각각 무엇을 뜻하는가 | **유지** (설정, 해석 B) |
| 🔴 검열의 **표현 방식·연출 지시** | "█로 대체하라 / 길이를 비례시켜라 / 본문 5~15% 비율 / 윤곽이 보이게 가려라 / 미학적으로 운용하라" | **삭제** |
| 🔗 위 표현·미학을 **위임하는 포인터** | "검열 미학·비율은 X 문서 참조" (특히 삭제된 문서를 가리키면) | **정리/삭제** |

→ 핵심: "언제/왜 검열되는가(규칙)"와 "기호가 무엇인가(정의)"는 남기고, "어떻게 표기·연출하는가(방식)"는 지운다.

세계관_설정 §2(표면/본질 미학)의 노출 강도 지시(L176·L182후반)는 *문체 지시보다 세계관 운용 원리에 가까워* 이번 정리 대상에서 **보존**(창작자 결정).
