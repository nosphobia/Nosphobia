# 학교 사상체 — 개요·변칙현상 구상 초안

> ⚠️ 본 문서는 **제안 초안**이다. 사용자(창작자)가 검토 후 확정·수정한다.

---

## 콘셉의 두 축 (출발점)

`콘셉1.md`에서 추출한 핵심 구조:

- **공간 = 의례 위계** — "학교"는 *교사-학생* 위계가 한국인에게 각인된 공간. 이 위계 자체가 생존 규칙이 된다. (노스포비아가 "방송 시청"을 생존 통화로 삼은 것과 동형.)
- **동화의 카운트다운** — "5개 수업을 들으면 학생이 됨". 되돌릴 수 없는 시계. 공포의 엔진.

## 3. 변칙현상 분해 제안

콘셉을 노스포비아처럼 항목으로 쪼갠 제안:

1. **영원한 밤 / 외부 단절** — 진입하면 시간이 밤에 고정, 통신 두절. 바깥으로 나가는 문이 닫힘. (AK)
2. **학생-됨의 진행** — 의복→소지품→신체 순으로 학생화. 단계적·비가역. (EV)
3. **교칙의 처벌** — 미상의 교칙. 위반 시 처벌(체벌·반성문·청소의 외형을 쓴 죽음). *교칙 내용을 인간이 다 알 수 없다는 게 핵심.* (FG+EV)
4. **수업 = 동화의 계단** — 1교시마다 정체성 한 겹 상실. 5교시 = 완전 동화. (EV+FG)
5. **교사와 학생의 비대칭** — 학생은 잠시 제압 가능, 교사는 손도 못 댐. *위계의 물리적 구현.* (EV+AK)

### 추가 제안 — "전학생"이라는 호명 (콘셉엔 없던 장치)

진입자는 처음엔 *전학생*으로 불린다. "전학생"으로 호명되는 동안은 아직 외부인 — 하지만 어느 순간 그냥 이름(혹은 출석번호)으로 불리기 시작하면, 그것이 *동화가 임계를 넘었다는 외적 신호*다.

> **왜 이 장치인가**: 노스포비아의 "포비라고 불리기 시작하면 위험"과 동일한 *호명=위험 눈금* 기법의 변주. 창작자가 노스포비아 대응지침에서 이미 쓴 스타일의 재사용.

## 4. 대응지침으로의 연결 고리 (메모)

위 변칙현상이 대응지침(규칙괴담)으로 갈 때의 자연스러운 수칙 씨앗:

- 영원한 밤 → "시간을 확인하려 하지 마라 / 밖을 내다보지 마라"
- 학생-됨 → "거울을 보지 마라 / 교복을 입었음을 자각하지 마라"
- 교칙 → "모르는 규칙을 어겼을 때의 처벌 회피" (규칙괴담의 핵심 모순)
- 수업 → "몇 교시까지 버텼는지 세지 마라 / 5교시 전에 이탈"
- 비대칭 → "교사에게 저항하지 마라, 학생에게서 도망쳐라"
- 호명 → "전학생이 아닌 이름으로 불리면 그때가 마지막 신호"

## 5. 대안 해석 (미결 — 사용자 결정)

- **위험 등급**: Ni(거의 회수 불가)로 볼지, Aj(규명 미완·예측 불가)로 볼지. 동화가 *확실히* 비가역이면 Ni, 작동 원리가 *미지*인 점을 강조하면 Aj.
- **교사 vs 학생의 본질**: "둘 다 위계의 표면 모방"인지, "교사가 본체에 더 가까운 개체"인지 — 이 해석이 대응지침의 톤을 바꾼다. (미결로 열어둠)
- **동화 진행 변수**: 수업이 *시간 단위*인지, *진입자별 누적 횟수*인지, *우연히 그 자리에 있었는지* — 이 모호함 자체를 미학으로 둘 수 있다.
