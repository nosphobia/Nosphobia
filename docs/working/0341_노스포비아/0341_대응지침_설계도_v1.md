# 0341 대응 지침 — 7~50번 소통 구간 설계도

> 본 문서는 `0341_대응지침_v2.md`의 7번 이후 집필을 위한 설계도다.
> 6번까지는 작성 완료(진입 깔때기). 7~50번은 **시청자와 노스포비아의 일반적 소통** 구간으로 채운다.

---

## 0. 절대 원칙

새 요소를 임의로 만들지 않는다. 모든 수칙의 *내용*은 반드시 `사상체_노스포비아_v0.6.md`에 확정된 설정(아래 §1 자산 목록) 안에서만 구체화한다.
조사한 장르 자료(규칙 유형 분류, 에스컬레이션 3단, 공략집화)는 *규칙의 형식적 틀*로만 사용하며, 본체에 근거 없는 소재(예: 시간 조작 등)는 도입하지 않는다.

## 2. 지칭·호명 체계 (확정)

- **서두**: 귀하
- **본문 수칙**: 당신
- **노스의 호명**: 일반 시청자 = 닉네임 / 친해진 시청자 = '포비'

### 호명을 유대 곡선의 눈금으로 사용

| 구간 | 노스의 호명 방식 | 의미 |
|---|---|---|
| 7~15 입장 | (대개 호명 안 함 / 군중의 일부) | 안전 |
| 16~28 지속 | 닉네임으로 호명 시작 (자산⑤·⑧) | 개별 인식의 시작 = 첫 위험 신호 |
| 29~40 교감 | 닉네임 + "그 색 잘 어울리네" 류 맞춤 발언 | 정밀 관측 |
| 41~50 경계 | **'포비'로 부르기 시작** | 유대 임계 = 변칙현상(3) 권역 진입 |

→ 41번("일반 범위를 넘을 때")의 구체적 판정 기준 = **노스의 호칭이 닉네임에서 '포비'로 바뀌는 시점**. 시청자가 "내가 선을 넘었는지" 스스로 판정할 수 있는 단 하나의 외적 지표.

## 3. 전체 50번 스켈레톤

각 항목 = [다루는 것] + (근거 자산) + 〔규칙 유형〕.
규칙 유형: 조=조건부 / 시=시간·시점 / 모=모순 / 함=함정. 온도 = 1단(일상) 내 긴장도.
★ = 모순/함정 규칙 (4개 모두 유지 확정).

## 4. 설계 의도 (집필 시 견지할 것)

1. **온도 = 유대 = 호칭** 세 곡선이 7→50번 동시 상승. 본체 v0.6의 "유대 정도에 따라 변칙성이 좌우된다"를 규칙 배열 자체로 구현.
2. **모순/함정 규칙 4개를 전략적 위치에**: 20(군집동기화) · 32(관측자인지) · 46(표면본질) · 49(메타의심). 본체 핵심 설정 4개에 정확히 대응.
3. **기존 수칙과의 가교**: 36·37·38·43·44·45·48·49번이 이미 작성된 1006·1007·1008·2002 등과 연결. 소통 구간이 전체 지침의 *입구*가 되도록.
4. **49번 메타 의심은 씨앗만** (사용자 결정). 50번까지는 일반 소통 톤 유지. 명시적 함정 규칙은 51번 이후 전용.
