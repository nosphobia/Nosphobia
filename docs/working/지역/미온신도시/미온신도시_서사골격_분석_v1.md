# 미온신도시 서사 골격 — 분석 및 보강 제안

> 사용자가 작성한 8단계 골격을 분석하고, 사실관계 확인 + 보강 방향을 제안한다.
> 사용자 아이디어를 *대체*하지 않고 *날카롭게* 다듬는 것이 목적이다.

---

## 0. 사용자 골격 요약 (원형 보존)

1. 간척 일부 진행 중 신도시 건축 동시 시작
2. 간척 중 기이한 사건 발생 (콘셉: 일제강점기 역사적 비극이 간척 과정에서 발견 → 사상체 사건)
3. 정부가 관리국에 위임했으나 완전 해결 실패
4. 정부가 사건·사업을 대대적으로 은폐
5. 정보 조작 + 관리국의 은폐(통제 가능 사상체의 변칙성 활용) + 인지 재해로 신도시가 *기억에서 말소*됨
6. 현재: 그 자리엔 간척·건축이 중단되고 철거마저 취소된 폐허만. 정부가 접근 통제
7. 특수한 방법으로 접근하면 완성된 미온신도시 등장 — 도시 자체가 사상체, 내부 시설들이 각각 고유 변칙성
8. 당시 인부·관계인·민간인의 흔적 — 잠식되어 사상체화됐거나, 생존하려던 일지·흔적

## 1. 사실관계 확인 (사용자 질문)

### Q. 간척을 다 끝내야 건축 가능? 아니면 일부 완료분부터 건축 가능?

**A. 일부 완료분부터 건축 가능 — 오히려 그게 정석.** (송도 실증)

- 송도는 **1~8공구로 분할**, 매립 끝난 공구부터 도시 건설 + 옆 공구는 계속 매립. "동시 진행"이 한국 간척 신도시의 표준.
- → 사용자 1번 설정은 **공학적으로 정확**. 수정 불필요.

### 보강 발견 — 공학에서 건진 호러 모티브 2개

| 공학 현상 | 실제 내용 | 호러 활용 |
|---|---|---|
| **연약지반 압밀** | 매립 직후 땅은 물러서, 건축 전 *하중을 얹어 수개월~수년 가라앉혀 굳힘* | *무언가를 눌러 가라앉히는 땅.* 압밀 기간 = 사건이 묻힌 시간 |
| **연동침하** | 옆 구역 새 매립 때문에 *이미 지은 건물 밑 땅이 추가로 가라앉음* | *도시가 스스로 내려앉는다.* 미온신도시가 가라앉는 불길함의 공학적 근거 |

> 제안: 미온신도시의 *지반이 계속 가라앉는다*는 설정을 변칙성과 연결. "이 땅은 무언가를 계속 묻으려 한다."

## 2. 강점 분석 (이 골격이 잘 작동하는 자리)

- **③④⑤의 3중 은폐 구조가 탁월하다.** 단일 은폐가 아니라 *정부 정보조작 + 관리국 변칙성 + 인지재해*의 3겹. 이게 "왜 아무도 기억 못 하나"에 대한 **다층 알리바이**를 만든다. 세광은 "인덱스에서 빠짐" 단일 메커니즘인데, 미온은 *3주체가 각자의 방식으로 지운* 구조라 훨씬 두껍다.
- **⑥의 이중 상태가 핵심 자산.** 현실=중단된 폐허 / 이면=완성된 도시. 이 대비가 콘셉(A+D 결합)의 정수. **"건설이 멈춘 곳에, 멈추지 않고 완성된 도시가 겹쳐 있다."**
- **②의 일제강점기 비극 = 한국형 코즈믹의 정석.** 간척지 아래 묻힌 역사. *땅을 파다 과거를 깨운다*는 구조는 한국 정서에 깊게 닿는다.

## 3. 보강·교정 제안 (날카롭게 다듬기)

### 제안 A — ②의 "발견"을 "깨움"으로
사용자 표현 "역사적 비극이 *발견됐다*"는 수동적이다. 더 강하게:
> 간척이 그 비극의 현장(또는 그 위)을 *건드려* 잠들어 있던 무언가를 *깨웠다.*
- 간척 = 바다를 메워 *덮는* 행위인데, 역설적으로 *그 아래 것을 끌어올림*. "묻으려다 깨운다."
- 일제강점기 비극의 성격은 미정이나, *바다·물과 연관*되면 간척과 정합 (예: 해안 강제노역·수몰·해상 학살 등 — 구체는 사용자 구상 영역. 윤리 검토 필요).

### 제안 B — ⑤ 인지재해 말소의 *구체적 메커니즘* (사용자가 미정으로 둔 자리)
"기억 자체가 말소"의 원리 후보 3안:
- **(가) 관리국 사상체 차용형**: 관리국이 격리 중인 *기억·인지 간섭형 사상체*의 변칙성을 *역이용*해 대중 기억을 지움. (사용자 ⑤에 이미 암시됨 — 이걸 명문화)
- **(나) 미온신도시 자체 변칙형**: 미온신도시(사상체)의 변칙성 일부가 *외부로 새어* 그 도시를 인지·기억하는 능력을 차단. 도시가 *스스로를 숨김*.
- **(다) 합작형**: 정부 정보조작이 *물리 기록*을 지우고(공문서·지도·뉴스), 사상체 변칙성이 *인간 기억*을 지움. 둘이 맞물려야 완전 말소. — **추천**: 둘 중 하나만으론 구멍이 생기는데, 합작이라 완벽해지고, *구멍(우연히 기억하는 자)*이 서사 진입점이 됨.

### 제안 C — ⑥ "접근 통제"의 표면 명분
현실의 폐허를 정부가 통제하는 *공개 명분*이 필요(표면/본질). 후보:
- 토양·해양 오염 (간척 부실 → 환경 위험 구역)
- 지반 침하 위험 (연동침하 활용 — 공학적으로 진짜 위험하기도 함)
- 군사 보호구역 / 사고 위험 산업단지
- → **지반 침하 위험**이 가장 정합적. 진짜 가라앉는 땅 + 변칙성 은폐를 한 명분으로.

### 제안 D — ⑦ "도시 = 사상체 + 내부 시설 = 개별 사상체"의 위계 정리
세광과 겹치지 않으려면 *관계*를 명확히:
- **미온신도시 = 모(母)사상체** (공간형, 거대 단일 개체). 도시 전체의 시공간 고정·이면화를 담당.
- **내부 시설들 = 자(子)사상체** — 단 *완전 독립*이 아니라 *미온신도시의 장기(臟器)*. 각 시설이 도시라는 한 몸의 기관처럼 기능.
- 차별점: 세광은 괴담들이 *각자 독립*해 한 도시에 *세 들어 산다*. 미온은 *도시가 곧 생물*이고 시설들은 *그 생물의 장기*. → 응집력↑, 코즈믹↑.

### 제안 E — ⑧ 흔적의 두 층위 분리
사용자가 "잠식되어 사상체화 / 생존하려던 일지"로 이미 잘 나눴다. 한 겹 더:
- **잠식층** = 이미 도시의 일부 (배경처럼 존재하는 옛 인부·주민. 말을 걸면 위험)
- **저항 흔적층** = 생존하려던 자들의 일지·낙서·바리케이드 (탐사자가 *읽고 따라가는* 단서. 규칙괴담의 "선행자 기록")
- **제3층 제안 — 적응층**: 잠식도 저항도 아닌, *도시의 규칙을 익혀 살아남은* 소수. 양화터널의 "생존자"처럼 탐사자에게 의존·집착하거나, 거꾸로 *도시 편*일 수 있음. 가장 위험하고 가장 흥미로운 NPC군.

## 4. 세광특별시와의 최종 차별표 (이 골격 반영)

| 축 | 세광특별시 | 미온신도시 |
|---|---|---|
| 분리 메커니즘 | 인덱스에서 빠짐 (단일) | 정부 조작 + 사상체 변칙성 + 인지재해 (3중) |
| 현실 측 상태 | 정상 도시 위에 겹침 | *중단된 폐허* (이면엔 완성 도시) |
| 도시의 정체 | 배경(그릇)일 뿐 | *도시 = 모사상체*, 시설 = 장기(자사상체) |
| 기원 | (모호) | 간척이 일제강점기 비극을 *깨움* (명확한 인과) |
| 시간 | 현재 진행 | 완성된 그 시점에 *고정* + 지반은 계속 가라앉음 |
| 진입 | 이름 없는 역 | 특수 변칙적 방법 (사용자 구상 예정) |
