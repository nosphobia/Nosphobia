# 일본 괴담·도시전설 소재

> 일본의 유명 괴담·도시전설·2ch 인터넷 괴담을 *사상체 콘셉의 소재 풀*로 정리한 문서.
> 각 항목은 *짧은 원전 요약 + 사상체화 시 자산이 될 수 있는 결*을 표기. 본 문서는 영감 수집용이며, 노스포비아 세계관에 *그대로* 차용하는 것이 아니라 *결을 흡수해 한국형으로 재배치*하는 자료로 사용.

---

## I. 고전·민속 계열 (요괴·여귀)

### 1. 쿠치사케온나 (口裂け女, 입 찢어진 여자)
마스크를 쓴 여자가 *내가 예쁘니?*라고 묻고, 답에 따라 입을 같이 찢는다. 1979년 일본 전국에 사회 현상을 일으킨 *최초의 전국 도시전설*.
*사상체화 자산*: *답할 수 없는 질문* / *외형 매개의 의식* / *답변 분기형 규칙괴담*

### 2. 하나코상 (花子さん)
초등학교 3층 화장실 세 번째 칸의 문을 세 번 두드리며 호명하면 응답하는 어린 여자아이의 영. 잘못 응답하면 변기 속으로 끌려간다.
*사상체화 자산*: *호명형 의식* / *학교 화장실의 닫힌 공간* / *위치 정밀성(층/칸/노크 횟수)*

### 3. 테케테케 (テケテケ)
하반신을 잃은 여자의 영. 팔꿈치로 *테케테케* 소리를 내며 빠르게 추격, 잡힌 사람의 하반신을 자른다. 철로·역에 출몰.
*사상체화 자산*: *결손 신체* / *추격형* / *지하철·역의 자리*

### 4. 핫샤쿠사마 (八尺様, 팔척님)
2m 넘는 키에 챙 넓은 모자, *포포포* 웃음소리의 여인. 시골에 돌아온 손주에게 매혹되면 며칠 안에 죽는다. 신사·결계로 임시 방어.
*사상체화 자산*: *비정상 신장* / *시골 회귀* / *결계의 임시성* / *매혹 후 사망*

### 5. 유키온나 (雪女)
눈 속에서 만난 여자가 *입김으로 사람을 얼리거나*, 약속을 어긴 남편을 떠난다. 자연재해와 인간 욕망의 경계.
*사상체화 자산*: *자연환경 의인화* / *약속 위반 트리거* / *침묵의 미덕*

### 6. 로쿠로쿠비 (ろくろ首)
밤이 되면 *목이 길게 늘어나는* 여자. 평소에는 평범한 인간으로 살아간다.
*사상체화 자산*: *낮/밤 이중 정체* / *신체 변형* / *위장된 일상*

## II. 인터넷 2ch 신화 계열

### 7. 키사라기역 (きさらぎ駅)
졸음 → 무인역 도착, 정거장 간 장시간 주행, GPS 오류, 방울·북소리, 친절한 안내자. 2004년 2ch 실황. *지하철 괴담 콘셉*의 직계 자산.
*사상체화 자산*: *실황 형식 자체* / *경계 공간* / *친절한 안내자형*

### 8. 코토리바코 (子取り箱)
*아이를 잡는 상자*. 복잡한 퍼즐 구조의 저주 상자로 여자·아이가 만지면 죽음. 마을의 원한·기술이 응축된 *물리적 사상체*.
*사상체화 자산*: *물리적 저주 매체* / *접촉 트리거* / *대상 한정 저주(여자/아이)* / *기예가 깃든 저주물*

### 9. 쿠네쿠네 (くねくね)
멀리 논·들판에서 *쿠네쿠네 꿈틀거리는 흰 사람 모양*. 정체를 알면 미친다. 망원경·쌍안경으로 자세히 보면 끝.
*사상체화 자산*: *원거리 관측 / 자세히 보면 안 됨* / *인지 위해 그 자체* / *풍경 속의 한 점*

### 10. 야마노케 (山ノ怪)
산에서 *츠츠츠츠츠* 소리를 내며 따라오는 무엇. 잘못 마주치면 *데려간다*. 산악·등산 자리.
*사상체화 자산*: *산악의 음성 추적자* / *발음·소리 자체가 트리거* / *되돌아봄 금기*

### 11. 사토루상 (サトルさん)
지정된 시각, 지정된 방법으로 호명하면 *어떤 질문에든 답해주는* 존재. 단 *위반*하면 끔찍한 결과.
*사상체화 자산*: *질의응답형 의식* / *시각·절차 정밀성* / *위반의 대가*

### 12. 메리상 (メリーさん)
*나야 메리. 지금 너의 집 앞에 있어*로 시작해 점점 가까워지는 인형의 전화. 결국 *너의 뒤*에 있다.
*사상체화 자산*: *통신 매체의 위치 알림* / *거리 점진적 단축* / *물건(인형)의 자율*

### 13. 빨간 방 (赤い部屋)
*당신은 빨간 방을 좋아하나요?* 라는 광고 팝업을 본 사람은 며칠 안에 *방을 자신의 피로 빨갛게 만든 채* 발견된다. 인터넷 매체 본격 진입의 신호.
*사상체화 자산*: *광고 팝업/디지털 매체 침입* / *시청 = 감염* / *사후 자해형 결말*

### 14. 하스시마 (모기는 잘 자르나요)
*당신은 모기를 잘 자릅니까?* 라는 질문에 잘못 답하면 *너의 사지가 모기처럼 끊긴다*.
*사상체화 자산*: *질문 응답 분기형* / *신체 절단* / *언어 게임*

## III. 폐쇄 마을·터널·산 계열 (장소형)

### 15. 이누나키 마을 (犬鳴村)
*일본 국내법이 미치지 않는* 마을. 후쿠오카 옛 이누나키 터널 너머. 들어간 자는 살아 돌아오지 못한다. *외부 행정의 부재* 자체가 공포.
*사상체화 자산*: *법 외부 공간* / *터널 너머의 마을* / *돌아옴 부재*

### 16. 스기사와 마을 (杉沢村)
1938년 청년이 마을 전체를 도끼로 학살, 이후 *지도에서 사라진* 유령 마을. 입구에 *이곳에서 너머는 출입 금지* 표지.
*사상체화 자산*: *학살의 역사 잔존* / *지도 부재* / *경고 표지의 권위*

### 17. 9년마다의 의식
산속 마을에서 *9년 주기*로 *선택된 아이들*과 따르는 자들이 입산금지 산에서 *오마츠리*를 행한다. 외지인은 절대 알 수 없는 비밀.
*사상체화 자산*: *주기형 의식* / *선택된 아이* / *외지인 배제*

### 18. 이누나키 터널
폐쇄된 옛 터널. 차로 진입한 사람들이 *돌아오지 않거나*, *나왔어도 일생 불행*. 일본 *최강의 심령 명소*.
*사상체화 자산*: *터널 = 경계* / *차량 진입* / *돌아옴의 저주*

### 19. 키요타키 터널 (清滝トンネル)
교토. *터널 진입 전 백미러에 무엇이 보이면 돌아가야 한다*는 규칙. 입구 신호등이 *비정상으로 깜빡이면* 진입 금기.
*사상체화 자산*: *백미러의 신호* / *신호등 변칙* / *진입 전 금기 규칙*

### 20. 산속 *입산금지* 신사
지역민조차 가까이 가지 않는 작은 신사. 잘못 들어가면 *얼굴을 가린 신관*이 *예식을 시작*해 버린다.
*사상체화 자산*: *예식의 강제 시작* / *얼굴 가린 사제* / *외지인의 부주의*

## IV. 저주물·물건 계열

### 21. 소의 머리 (牛の首)
*들으면 미치거나 죽는다*는 이야기. 정작 *내용 자체는 누구도 모른다* — *내용 부재*가 공포의 본체.
*사상체화 자산*: *내용 부재 = 공포의 본체* / *나폴리탄 미학의 원형* / *전승의 불가능성*

### 22. 인면견·인면어
얼굴이 사람인 동물. 평범한 길거리·연못에서 발견. *인간성과 동물성의 경계 와해*.
*사상체화 자산*: *경계 와해* / *일상 풍경 속의 이질* / *목격자 한정 발현*

### 23. 카샤 (火車)
시체를 빼앗아 가는 요괴. 장례식·매장 직전의 시체가 갑자기 *사라진다*. 비·바람과 함께 등장.
*사상체화 자산*: *장례 의례 교란* / *시체의 소실* / *기후 변칙 동반*

### 24. 자시키와라시 (座敷童子)
집에 깃든 어린 영. *있는 동안* 가문이 번창, *떠나면* 가문이 망한다. *수호 + 저주의 양면성*.
*사상체화 자산*: *양면적 사상체* / *가문 단위 운명* / *떠남 = 파국*

### 25. 츠쿠모가미 (付喪神)
100년을 지난 *오래된 물건*에 깃든 영. 평범한 가구·도구가 자율 행동.
*사상체화 자산*: *시간 누적이 깃든 사물* / *일상 도구의 자율* / *연식 임계*

## V. 의례·행위 계열 (호출 게임)

### 26. 콕쿠리상 (こっくりさん)
종이 위의 동전과 글자판으로 호출하는 의식. 일본판 위자 보드. 잘못 끝내면 *영이 떠나지 않는다*.
*사상체화 자산*: *호출 의식* / *종료 절차의 정밀성* / *집단 의식*

### 27. 히토리 카쿠렌보 (一人かくれんぼ)
*혼자 하는 술래잡기*. 인형에 손톱·머리카락을 넣고 의식 절차를 거치면 *인형이 술래가 되어* 너를 찾아온다.
*사상체화 자산*: *혼자 + 인형* / *절차 정밀성* / *시작과 끝의 의식 분리*

### 28. 우시노 토키마이리 (丑の刻参り)
새벽 2시(축시) 신사에서 *짚 인형에 못을 박는* 저주 의식. 7일 연속, 본 사람에게 들키면 *저주가 본인에게* 돌아온다.
*사상체화 자산*: *연속 7일* / *목격자 발생 시 역류* / *시각·장소 정밀성*

### 29. 사츠키상 (3월 상순의 의식)
정해진 시각·장소에서 *거울 앞에 정해진 문장*을 외우면 거울 속에 다른 자가 나타난다.
*사상체화 자산*: *거울 의식* / *발화 정밀성* / *시간대 한정*

### 30. 13개 계단 (十三階段)
13단의 계단을 정확히 *세며 오르내리면* 14번째 계단이 나타나며 *다른 세계*로 통한다.
*사상체화 자산*: *숫자 임계* / *계단 = 경계* / *세는 행위의 의식화*

## VI. 일상 침입 계열

### 31. 토괴 (扉怪)
밤중 *현관문이 두드려지는데 인터폰에는 아무것도 없는* 경우. 응답하면 *너의 목소리*가 *다시 응답해 온다*.
*사상체화 자산*: *야간 노크* / *자기 목소리의 반향* / *응답 금기*

### 32. 옆자리 동승자
신칸센·심야버스에 *예매되지 않은 옆자리에 누군가가 앉아 있다*. 검표원은 *그 자리에 아무도 없다*고 본다.
*사상체화 자산*: *교통수단 동승자* / *검표 시스템 미인지* / *단독 가시성*

### 33. 자동판매기 앞의 한 명
새벽 자동판매기 앞에 *24시간 365일 서 있는 한 사람*. 동전을 넣고 누른 음료가 *그의 손에 먼저* 떨어진다.
*사상체화 자산*: *상시 출몰자* / *기계 매개* / *물건의 우선 분배*

### 34. 깊은 밤 *욕실 거울에 비치는 다른 천장*
새벽 욕실 거울에 비친 천장이 *우리 집 천장이 아니다*. 그 천장을 *기억해 둔 자*는 며칠 안에 *꿈속에서 그 천장 아래에 누워 있다*.
*사상체화 자산*: *거울 풍경 어긋남* / *기억 매개* / *꿈으로의 이행*

### 35. 엘리베이터 의식 (異世界エレベーター)
10층 건물 엘리베이터에서 *4→2→6→2→10→5*의 순서로 버튼을 누르면 *다른 세계*로 간다. 5층에서 *여자가 타면* 절대 보지 말 것.
*사상체화 자산*: *버튼 절차의 정밀성* / *동승자 금기* / *공간 전이*

## VII. 일본 특유의 *공간·문화 코드*

### 36. 신사·사당 (神社・祠)
*신토*의 공간. 외지인은 *어디까지 들어가도 되는지*의 경계 인지 불가. 표면의 평화 + 본질의 경계.
*사상체화 자산*: *경계 인지 불가* / *외지인 한정 위험* / *침묵의 의례*

### 37. 마츠리 (祭り)
지역 축제. *외지인이 참여하면 절대 안 되는 절차*가 일부에 끼어 있다. 모르고 참여한 자가 *제물*이 된다.
*사상체화 자산*: *축제의 표면 + 의식의 본질* / *지역민의 침묵* / *외지인 제물*

### 38. 오본 (お盆)
조상의 영이 돌아오는 시기. *돌아온 영이 떠나지 않는* 경우가 있다.
*사상체화 자산*: *영의 정기적 귀환* / *잔존 위험* / *시기 한정 사상체*

### 39. 시고센니치 (四十九日)
사후 49일. 영이 *현세를 떠도는* 기간. 잘못된 절차는 영을 *영영 머물게* 한다.
*사상체화 자산*: *49일의 정밀성* / *기간형 사상체* / *절차 위반의 영구화*

### 40. 신토 결계 (注連縄, 시메나와)
신성한 공간을 두르는 새끼줄. *외부와 내부*를 명확히 구분. 침범하면 *부정*이 옮는다.
*사상체화 자산*: *물리적 결계의 시각화* / *내·외 구분의 명료성* / *부정의 전염*

## 참고: 사상체 적용 시 주의

- *그대로 차용 금지*. 일본 고유 문화·지명·인명을 *한국형 등가물*로 치환해야 한다.
  - 신사 → 마을 사당·당산나무
  - 마츠리 → 한국 지역 축제·동제
  - 시메나와 → 금줄
  - 49일 → 한국 49재
- *결*만 흡수하고 *외피*는 재설계. 예: 핫샤쿠사마의 *비정상 신장 + 시골 회귀*는 살리되, 외형은 한국형으로 재구성.
- 표면/본질 이중 구조와의 정합: 일본 괴담은 *경계·결계·외지인 제물*의 결이 강해, APMB의 *외부/내부 인가 등급*과 자연스럽게 결합 가능.
